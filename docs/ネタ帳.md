# ネタ帳 (次やるかもリスト)

次に作る候補の置き場。**「あれどうしたっけ」を防ぐのが目的**なので、題名だけでなく
**筋 (ストーリーの背骨) ・冒頭のヒキ・保留の理由**まで書き残す。

## 使い方

- 新しいネタを思いついたら「候補」に1枚カードを足す
- やると決めたら「やる順」の表を書き換える
- 作り終えたら「作ったもの」に移し、`docs/作品カルテ.md` に本体の記録を書く
- **やらないと決めたものも消さずに「見送り・保留」に残す** (理由ごと残すのが肝心)

# 候補カード

## 1. 旅 ＋ お土産 ★次回作

- **筋**: 人は、出かけるための口実と、帰ったときの言い訳を、同時に発明した
- **ヒキ**: 「江戸時代、遊びに行きますとは言えませんでした。だから人々は、神様に会いに行くことにしたのです」
- **落ち**: 口実の発明は終わっていない (今の「自分へのご褒美」「リフレッシュ」)。お土産は今も、留守番した人への報告書

### なぜ2つを合流させるか

つなぎ目は **「講」と「御師」**。江戸の伊勢参りには村の代表が皆の代わりに参る*代参*があり、

- 代表で行くのだから **行く口実**が要る → 信仰
- 代表で行くのだから **全員分を持ち帰る義務**が生じる → お土産

つまり**旅の口実とお土産の義務は、同じ仕組みから生まれた双子**。別々に作るより強い。

### 章立て案 (11章・約215文)

| 章 | 内容 |
|---|---|
| 序 | 売り場で職場の人数を数えている自分。連休に理由を探している自分 |
| 1 | 旅は苦行だった — 移動は仕事か逃亡。道は危険 |
| 2 | 最初の口実は信仰 — 巡礼。熊野詣、サンティアゴ |
| 3 | 江戸の大発明 — 講と御師、道中記というガイドブック、抜け参り |
| 4 | **お土産の誕生** — 宮笥とお札、代参、義務の発生 |
| 5 | 口実その2は教育 — グランドツアー |
| 6 | 口実その3は療養 — 湯治と温泉 |
| 7 | 旅が商品になる — 1841年トマス・クック (禁酒運動の団体列車) |
| 8 | 鉄道が名物を作る — 時刻表、標準時、駅売り。**お札が菓子に変わる** |
| 9 | 戦後日本 — 新婚旅行、海外渡航自由化、団体旅行 |
| 10 | 個包装と脱酸素剤 — 「配れるお土産」の完成 ← 唯一のからくり図解 |
| 結 | 口実の発明は終わっていない。お土産は今も報告書 |

前半で旅の筋を通し、**4章で仕込んで8章・10章で回収**する。途中で話題が切り替わる感じにならない。

### 覚悟しておく点

**時代考証キットが6セット要る** (中世の巡礼路 / 江戸の街道・宿場・関所 / 18世紀の欧州 / 明治の鉄道と駅 / 昭和の団体旅行 / 現代の空港)。前作の4000年史より重い。

### 先に潰す俗説 (ファクトチェックの最優先)

筋が史実に耐えるかの一点を見る。網羅的な史実調査ではない。

- 「講と御師が、旅の口実とお土産の義務を同時に生んだ」は本当に言えるか
- 「宮笥 (みやげ)」語源説はどこまで断定してよいか (諸説あり)
- 「旅は苦行だった」は言い過ぎでないか
- トマス・クック「世界初のパッケージツアー」の表現
- 抜け参りの規模

## 2. トイレと下水

- **筋**: トイレを変えたのは、きれい好きではなく恐怖だった
- **ヒキ**: 「水洗トイレは、3回発明されて、2回忘れられました」
- **落ち**: 臭いを止めたのは配管ではなく、便器の下のわずかな溜まり水。その小さなフタのおかげで、私たちは下水のことを考えずに暮らせている

### 構成の方針 (2026-10-30 作者判断)

**前半は世界、中盤から日本に寄せる。** 理由は日本に強烈な別解があるから。

> **西洋が捨てていたものを、江戸は買っていた。**

西洋が窓から投げ捨てていた同じ時代、江戸は糞尿を農家が**買い取る**市場を持ち、長屋の大家の収入源にすらなっていた。結果、当時の世界で例外的に清潔な百万都市だった。

前半「世界は3回発明して2回忘れた」→ 中盤「日本は別の答えを持っていた」→ 後半「明治のコレラでその答えが崩れる」→ 下水道、汲み取りから水洗へ、ウォシュレット。

### からくり図解の見せ場

S字トラップの断面 (水のフタ)、下肥を運ぶ桶と船、ジョン・スノウのコレラ地図、汲み取りと浄化槽

### 注意

題材の品。下品に寄らない線引きが要る。仕組みと衛生史に寄せる。

## 3. 冷凍技術

- **筋**: 冷蔵庫が変えたのは食べ物ではなく、買い物の回数だった
- **ヒキ**: 「1806年、ボストンの商人が船いっぱいの氷をカリブ海へ送りました。正気を疑われました」
- **落ち**: 冷蔵庫は台所の家電ではなく、**都市の設計装置**だった
- **尺**: **15分 (約165文) で引き締める。** 20分に伸ばすと中だるみする

人類は**氷を作れるようになる前に、氷を売っていた**。天然氷の貿易 → 製氷機 → 家庭用冷蔵庫 → 毎日の買い物が週1回に → まとめ買い、スーパー、郊外。

日本側の素材: 氷室、函館の天然氷でボストン氷に対抗した中川嘉兵衛、戦後の電気冷蔵庫と三種の神器。

**弱点**: 冒頭のヒキが他より弱い。氷の貿易に興味を持たせるまでが勝負。

# 見送り・保留 (理由つき)

## ビル (エレベーター) — 保留 (2026-10-30)

- **筋**: エレベーターは上と下の値段をひっくり返した
- **ヒキ**: 「百年前まで、最上階は一番安い部屋でした」 ← ヒキは全候補中で最強クラス
- **落ち**: エレベーターは乗り物ではなく不動産の装置。都市が上に伸びたのは鉄骨ではなく、人が上を信じたから
- **保留の理由**: 作者判断で今回は見送り。**ネタの質が低いからではない。** 日本の話が少なく海外近代史に寄るのが弱点
- 1853年オーチスが万博で自分でロープを切ってみせた実演は、技術ではなく**信用**のデモ。絵の見せ場として非常に強い

## 外食 — 今回は見送り (2026-10-30)

- **筋**: 外食は家族のためではなく、家族のいない人のために生まれた
- **ヒキ**: 「古代ローマの庶民の家には、台所がありませんでした」
- **落ち**: 客席のないデリバリー専門店が増える今は、台所のなかった古代ローマへの出戻り。外食史は家族のかたちの歴史
- **絵の素材は全候補で一番多い** (屋台、回転寿司のレーン=1958年ビール工場のベルトコンベアが発想源、券売機、配膳ロボット)
- **注意**: 「レストランはフランス革命で失職した宮廷料理人が始めた」は**俗説**。革命前から restaurant (滋養スープの店) は存在する
