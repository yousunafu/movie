# ネタ帳 (次やるかもリスト)

次に作る候補の置き場。**「あれどうしたっけ」を防ぐのが目的**なので、題名だけでなく
**筋 (ストーリーの背骨) ・冒頭のヒキ・保留の理由**まで書き残す。

## 使い方

- 新しいネタを思いついたら「候補」に1枚カードを足す
- やると決めたら「やる順」の表を書き換える
- 作り終えたら「作ったもの」に移し、`docs/作品カルテ.md` に本体の記録を書く
- **やらないと決めたものも消さずに「見送り・保留」に残す** (理由ごと残すのが肝心)

## なぜ人は1番を目指すのか (2026-11-06 作者発案・**ファクトチェック済**)

- **筋**: 人は昔から勝ちたかった。けれど「自分が何位か」を気にしはじめたのは、測って・並べて・貼り出す仕組みができてからだった。**順位は発明品**
- **ヒキ**: 「古代オリンピックに、2位はいませんでした」(A判定・オリンピア限定の注意つき)
- **落ち**: 銀メダリストより銅メダリストのほうが笑っている (1995年研究・追試2本で再現済み)。人を苦しめるのは順位ではなく「ありえた自分」との比較。そしてケンブリッジ大は1909年に順位の公表を**やめた** — 順位表は発明品だから、設計も変えられる
- **学問の幅**: 歴史 (五輪・科挙・武士・江戸の番付) × 心理学 (社会的比較・反実仮想・井の中の蛙) × 社会学/経済学 (勝者総取り・地位財) × 生物学 (つつき順位)
- **強い断定素材**: 金銀銅は1904年から / **表彰台は1930年の発明 (96年前)** / 第1回近代五輪に金メダルは無い / 番付1757年・温泉番付 / 「学年1位は全員が頑張っても1人分しか増えない」(地位財)
- **前作との線引き**: 「私は何者?」は分類・診断の軸、本作は比較・順位の軸。重複チェック済み (**知能検査・IQは前作主役なので出さない**)
- **使用禁止3件**: 「平均より上は1835年まで存在しなかった」/「世界初ベストセラーリスト=1895年米」(正: 1891年ロンドン) /「偏差値は日本だけ」

## 織機とコンピュータ — 後回し (2026-11-02)
