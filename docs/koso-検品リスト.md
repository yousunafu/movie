# 「なぜ高層ビルは生まれたのか」全体検品リスト

2026-11-03 作成。8体の検品エージェントが連結シートのPNGだけを見て目視検品した結果。
形式: `#文番号 (element-NN) [重大/中/軽] 内容`

- **重大** = 徹夜で直す (字幕帯に文字が沈む / 隣と同じ絵 / 絵が壊れている / 言葉と絵が食い違う)
- **中・軽** = 作者が朝見てから判断

★全体を通じて最大の問題は **「同じ型の絵が隣り合う」**。作者の確認済み課題。
各章の末尾に「同じ型が続いている区間」をまとめた。
