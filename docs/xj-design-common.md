## 軸 (すべての絵はこの軸のどこかを担う)
**「日本はクリスマスを"食べて贈る前夜祭"に作り替えて、正月の手前にそっと置いた」**。明治の終わりから、時代ごとに飾りが**付け足されて**きた (かっぽれ → 三角帽 → ケーキ → 冬のイチゴ → チキン → 包み紙 → 恋人 → クリぼっち) のに、12月の主役の座は最後まで正月。
- 画面の背骨は**「日本のクリスマスツリー」**: 共有部品 `XmasTree` の上に、章ごとに日本の飾り (三角帽・ケーキの箱・イチゴ・チキンの骨・包み紙・ハート・ひとり用の小さいケーキ) が1つずつ吊るされていく。章の頭と終わりに出して進み具合を見せる。**ツリーのすぐ隣にはいつも門松が立っていて** (正月の気配)、章が進むほど少しずつ門松が画面に入ってくる。落ち (#210〜217) で、門松のほうが大きく主役だったと分かる
- **家計簿**: 共有ではなく B の装置 `Kakeibo` (日本の家庭の家計簿・12か月の棒)。導入 (#8〜9) と落ち (#203〜208) に出る
