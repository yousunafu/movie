## この章がどこの話か (扮装の方針)

### #219〜#221 は**寄席 (落語の高座)** ★ここがいちばん大事

この3文は**この動画の結論に近い場所**。「いまも出入り自由・飲食自由の場所が現に残っている」という、企画の核を支えるシーン。

高座の演者 = **落語家**。

- **着物 (無地か細い縞の落ち着いた色) + 羽織**。羽織は肩から前に垂れる
- **座布団の上に正座**している。`Person` は立ち姿前提なので、**腰から下を座布団と着物の裾で隠して座って見せる**
- 手に**扇子 (閉じた状態)** か**手ぬぐい**。どちらか一方
- 高座の後ろに**金屏風**か**めくり (演者名を書く紙の台。文字は書かず墨の筋だけ)**
- 顔は**穏やかに笑っている**。しかめ顔・怒り顔にしない
- 髪は短く整える。鬘・隈取は**つけない** (歌舞伎ではない)
- 高座の前に**出囃子の太鼓や三味線**を小さく置くと一気にそれらしくなる (入れなくてもよい)

★#220 #221 は「途中入場・途中退場・飲食が自由」が主題なので、**客席の自由さが主役**。演者は作り込みつつも小さめに。
客席には `PersonMini` で、弁当を広げる人・出入口から入ってくる人・立ち上がって出ていく人を混ぜる。

★**台本の引用文 (「途中からでも…」) を絵の中に文字で書かない。** 字幕が別レイヤーで出る。
壁の掲示として出すなら**墨の筋と短いラベル (「おねがい」程度) だけ**。

### #162 #174 は昭和の映画館

- 舞台に演者がいない可能性が高い。いるなら**幕間の実演 (アトラクション) の歌手・楽団**として描く
  - 歌手: スーツか和装、スタンドマイクの前。楽団: 譜面台とトランペット・太鼓
- 映写機・銀幕・二本立ての看板・吸い殻・自由席の木の椅子など、**昭和の映画館の作り込み**を優先する

## 全部に共通する注意

- 人物の土台は `KarakuriScenes.tsx` の `Person`。群衆用の `PersonMini` を演者に使わない
- 衣装を足しても**人物の画風 (大きな丸い目・線の太さ) は共通部品のまま**。新しい画風を作らない
- 衣装で `Person` の腕が隠れるなら、衣装を**体より奥**に描いて腕を前に出す
- 頭に物を乗せるときは共通の掟の「★ Person に帽子や小物を乗せるときの契約」を必ず守る
- **既存の舞台・客席・明かり・小物・札は残す。衣装だけを足す**のが原則。構図を変えない
- #164 #171 #223 の手配書 (`Tehaisho`) は**共有部品の側で別の人が色付けしている**。呼び出しを変えない
- `seg(f, a, b)` の **b は 42 以下**
- 画面に出してはいけない3つ: 幕の内弁当の語源 / 「本日は帝劇 明日は三越」 / 「サイコ世界初」
