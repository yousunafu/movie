# 別紙D ── boutou-d.tsx (#31〜#39)

担当は **#31〜#39** の9枚。全部直す。
**手本は `boutou-a.tsx` の #6 (1080行〜)。** 人の描き方の正本なので読んでから始める。

全景にしてよいのは **#31 と #38 の2枚だけ**。残り7枚は寄る。
顔が画面の高さの1/4以上になる寄りを、#35 と #39 で必ず作る。

舞台は**2026年のイラン・ホルムズ海峡・日本**。1988年の物を混ぜない。

## #31 山「アメリカとイスラエルが、イランを空爆しました。」(全景可)

683行「人の気配を影で置く」を**やめる**。夜でも人の顔と服の色を出す。
**構図** 夜のテヘラン。**屋上から**。カメラは低い位置から空へ煽る。
**出す物** 屋上の**給水タンク**と衛星アンテナの林 / 洗濯物のロープ /
室外機 / 迎撃の曳光が空に描く線 / 遠くの閃光に照らされる砂色の壁と水色のタイル /
停電した街区 / 携帯の画面の青い光
**人** 屋上に出てきた住民 ── パジャマの上にコートを羽織った男性 /
あわててルーサリーを被った女性 / 母にしがみつく子ども / 手すりを掴む老人。
**全員の顔が見える明るさにする。**
**事件** 一人が**携帯を空に向けて掲げる**。画面の光が顔を下から照らす。

## #32 山「最高指導者の公邸が攻撃され、36年以上頂点にいたアリー・ハメネイ師が死亡。」

**構図** 公邸の内部。崩れた部屋の**床の寄り**。人は出さず、**残された物**で死を言う。
**出す物** 床に落ちた**黒いターバン** / 割れた**眼鏡** (ハメネイ師の識別はこの2つで足りる) /
めくれたペルシア絨毯 / 漆喰の粉 / 倒れた書見台と開いた書物 / 天井から下がる配線 /
斜めに差し込む光と舞う埃
**事件** 埃の中を光の筋が横切り、**眼鏡のレンズが一度光る**。
**禁止** 顔を描く。遺影を出す。× 印で死を表す。

## #33 並「イランの暦では、断食月ラマダンの10日目でした。」

**構図** 食卓の寄り。断食明けの食事 (イフタール) が**手つかずのまま**。
**出す物** ナツメヤシ (デーツ) の皿 / 平たいパン (サンギャク・表面に石の跡) /
スープの椀 / 水差し / 月の形を描いた暦の10日目 / 窓の外の**細い月** /
敷かれたソフレ (食卓布)
**事件** 湯気が**消えていく**。誰も箸をつけていないことを湯気で言う。
**補足** ラマダンの10日目はシーア派にとって特別ではない (特別なのはムハッラム月10日＝
アーシューラー)。だがここは台本どおり「ラマダン10日目」と描く。月の満ち欠けは**上弦前の細い月**。

## #35 並「後継に選ばれたのは、息子のモジタバ師です。」

788行〜「どちらも顔のない逆光の影」の系図を**作り直す**。
**構図 顔の寄り…ではなく「人を物で示す寄り」。** 系図は紙の上の図にする。
**出す物** 手書きの系図の紙 / 父の枠に貼られた**黒いターバンの小さな絵** /
子の枠に貼られた**同じ黒いターバン** (世襲を同じ物の反復で言う) / 父の枠の×印 /
枠をつなぐ縦線 / 定規と鉛筆 / 紙の折り目
**人** 系図を書いている**手だけ**。袖は現代の日本のシャツ (記者の手)。
**事件** 子の枠に線が引かれたあと、**鉛筆が止まる**。

## #37 山「イランは反撃し、ホルムズ海峡を封鎖しました。」

**構図** 海面すれすれ。**高速ボートの舳先から**タンカーを見上げる。
**出す物** イラン革命防衛隊の**小型高速ボート** (船外機・迷彩ではなく灰色・舷側の擦れ) /
乗っている兵の**顔** (ヘルメット・救命胴衣・日焼け・風で細めた目。男女混成にはしない ──
ここは軍なので男性のみで可) / 海面の白波 / 塩の跡 /
VLCCタンカーの巨大な黒い舷側と**喫水線の赤** / 甲板上の配管 / 船尾寄りの白い船橋
**事件** タンカーが**止まる**。航跡の泡が消える。
**禁止** 地図に×を描くだけで済ませる。

## #38 並「世界の石油のおよそ5分の1が通る、海の道です。」(全景可)

**事件** 1隻だけが**向きを変えて引き返す**。

## #39 山「日本のガソリンが補助金で170円前後に抑え込まれているのは、このためです。」

**冒頭3分の着地。** イランの話が視聴者の財布まで下りてくる1枚。
**構図 顔の寄り。** 日本のガソリンスタンド。給油する人の**顔**と、価格表示。
**出す物** 価格看板の「170」(レギュラー/ハイオク/軽油の3段) / 給油ノズルとホース /
計量機の液晶 / 国産の軽自動車 / 店員の制服とキャップ / 幟 / アスファルトの油染み /
夕方の空
**人** 給油しながら価格看板を見上げる40代の男性 (仕事帰りのシャツ) と、
後部座席の子ども、レシートを渡す20代の女性スタッフ。**老若男女を混ぜる。**
**事件** 価格表示の数字が**カタンと1つ上がる**。
**禁止** 円グラフ・棒グラフだけで済ませる。
