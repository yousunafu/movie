## 絶対に守ること

1. **export されている部品の props の形を変えない。追加の export をしない** (SGP のキーも変えない。足すのは禁止、色が足りなければ既存の KRP/SGP で工夫する)
2. ファイル末尾の `SaigoPartsPreview` は**変えない** (検品はこれで行う)
3. **絵の中の文字は、ラベル・数値・標識だけ。** 手配書に書いてよい文字は「指名手配」「御用」と名前 (静けさ/ワーグナー/マーラー/演劇改良会/ヒッチコック/シネコン) だけ。セリフ・引用・年号の断定を勝手に書かない
4. **必ず `f` で何かが動く。** 静止した絵は禁止 (炎のゆらぎ、音符の浮き沈み、紙の揺れなど)
5. **出そろうのは f=42 まで。** `seg(f, a, b)` の b は 42 以下 (検品は f=45 の瞬間を写す)
6. 色は `KRP` と `SGP` にある色だけ
7. 線の太さは山の絵と同じ (輪郭 6〜8、細部 3〜5)。細くして逃げない
8. 乱数が要るときはファイル内にローカルの `rnd(seed, i)` を書く (毎フレーム違う値になる `Math.random()` は禁止)

## 品質の基準 (作者の言葉)

> 「シンプルとか普通のやつも絵のクオリティは下げちゃだめなんだけどね。だけど、細かい作りこんだ絵が生きるのは、そのバランスがあってこそなんだよね」

# 装置1: Danmen 劇場断面図 (最重要。ここに一番時間をかける)

ドールハウスを縦に割ったような**劇場の断面図**。動画の中で5回登場し、ランプが1つずつ消えていくことで「客席が静かにされていく150年」を1枚で語ります。

## 共通の構造 (全状態で完全に同一。state で建物を描き直さない)

- 全体: 幅1700 × 高さ約620 の横長。x,y が中心 (デフォルト 960,560)
- **建物の外殻**: 木の梁と柱の枠。屋根は浅い三角。断面なので壁の切り口 (太い線) が見える
- **左1/3 = 舞台**: プロセニアム (額縁) のアーチ、赤い緞帳 (SGP.curtain) が左右に寄せてあり、ひだを5〜6本。床は板張り (目地を描く)。舞台上に**役者1人** (見得を切るポーズ。片腕を大きく上げる)。足元にフットライトの小さな灯の列
- **右2/3 = 客席**: 4段の段々。各段に**紙人形の客を合計12〜14人** (座る・立つ・振り向く、ポーズをばらす)。段の前縁は太線
- **天井のランプ5灯**: 客席の上に等間隔。各ランプ = 天井からの紐 + 笠 + 炎。**左から1,2,3,4,5と番号が決まっている** (消える順: B で1,2が消え、C で3,4も消え、D/E は全部消灯)
- **右端 = 出入口**: 木戸 (開き戸)。戸口の上に「⇄」の両向き矢印

## state ごとの差分 (変えてよいのはここだけ)

| state | ランプ | 出入口 | 客席の小物・様子 |
|---|---|---|---|
| A | 5灯点灯 (金色の光輪) | 戸は開放、⇄太い (strokeWidth 14) | 弁当箱2つ・徳利1本・おしゃべりの音符5〜6個が客の間に。客は好き勝手な向き |
| B | 3灯 (1,2が消灯。消えた笠から煙がひとすじ) | 開放、⇄そのまま | 音符を2〜3個に減らす。弁当は1つ |
| C | 1灯 (5番だけ点灯) | 開放、⇄細い (strokeWidth 6) | 小物なし。客の7割が舞台の方を向く |
| D | 0灯 | **戸が閉まる。⇄消滅** | 全員前向き・等間隔。音符ゼロ。客席全体をうっすら暗く (SGP.nightInk を opacity 0.25 で重ねる) |
| E | 0灯 (Dと同じ) | Dと同じ | Dの上に、**客の手元に小さな青い光 (SGP.phoneBlue) が8箇所**。`seg(f, 6, 42)` の間に1つずつ順にともる。光は客の顔をほんのり照らす (薄い光輪) |

## 動き (全状態共通)

- 点灯中の炎は `f` でゆらぐ (sinで±2px)
- 音符は浮き沈み (状態A/Bのみ)
- t: 0→1 で建物→舞台→客席→ランプの順に `easeOut` で出てくる (各パーツの opacity と少しのせり上がり)

| 2 ワーグナー | ベレー帽・ふくよかな頬・もみあげ。眉が強い |
| 3 マーラー | 丸眼鏡・細面・立てた襟。神経質な目 |
| 4 演劇改良会 | 個人ではなく団体: 紋付の肩が2つ並ぶ+開いた扇子。顔は豆粒で複数 |

# 装置4: NenpyoEmaki 絵巻年表

広げた巻物の上の年表。s=1 で幅約1700、帯の高さ約340。

- 両端に軸木 (丸棒・軸先の飾り)。紙は SGP.paperOld。上下の縁に巻物らしい線
- **左〜中央 (幅の85%強) = 数千年の帯**: 小さな紙人形の観客が帯の中にぎっしり (20人以上)。食べる人・しゃべる人 (音符)・歩いて出入りする人を3〜4種のポーズの繰り返し+左右反転で。にぎやかで温かい
- **右端 (幅の約13%) = 150年の帯**: SGP.aoshizuka の青。座って同じ方向を向く人形が整列 (8人)。静か
- 境目にはっきりした縦線
- openT: 0→1 で右へ開いていく (紙の幅が伸び、先端の軸木が転がる)
- highlight: "long"なら長い帯、"short"なら青い帯に、ふわっと明るい光 (薄い黄色の楕円 opacity 0.25) + 細い囲い線
- 動き: 人形の音符が浮く、光がゆっくり脈打つ

# 装置5: Fuda3 三枚札

「黙って」「座って」「最初から最後まで」の木札3枚。s=1 で全幅約1100。

- 各札: 厚みのある木札 (側面の厚みを描く)。上辺に紐穴2つ+麻縄。木目2〜3本。文字は札の中央に大きく (FONT)。3枚目は文字が長いので札の幅を広く (約520)
- 上の横棒 (吊り元の竿) も描く
- t: 0→1 で左から順にトン、トン、トンと下りてくる (overshootして少し揺れて止まる)
- 動き: 止まったあとも微小にスイング (f で rotate ±1.2度)

# 進め方

1. `SaigoParts.tsx` を Read。`KosoShared.tsx` を Read (TagPlate の引数確認)。`KarakuriScenes.tsx` は grep→部分 Read で `KRP` / `seg` / `easeOut` / `clamp01` / `pop` / `FONT` を確認
2. 5装置を一気に書く (Danmen から)。ローカル部品 (ランプ1灯、客1人、など) はファイル内に自由に作ってよい
3. 型チェック: `node_modules/.bin/tsc --noEmit`
4. 静止画書き出し (1回のビルドで10枚):
   ```
   node_modules/.bin/remotion render src/remotion/index.ts SaigoParts tmp/saigo/parts --sequence --frames=0-9 --image-format=png --log=error
   ```
   出てくるのは `tmp/saigo/parts/element-0.png`〜`element-9.png` (0詰めで `element-00.png` の場合もあるので ls で確認)。コマ0〜4=断面図A〜E、5=手配書6枚、6=御用印つき、7=再生バー、8=絵巻年表、9=三枚札
5. 10枚を Read して自分で検品: 主役が小さすぎないか / A〜Eで建物がずれていないか (重ねて見比べる) / 手配書6枚の顔が描き分けられているか / 文字がはみ出ていないか
6. 直して、もう1回だけ書き出して確認
7. 報告: 各装置1〜2行 + 検品で直した点 (400語以内)

わからないことがあっても質問せず、この指示に沿って判断して描き切ってください。
