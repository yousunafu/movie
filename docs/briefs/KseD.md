## 絶対に守ること

1. **1文 = 1シーン = 1枚の絵。** 5文だから5枚。増やさない減らさない
2. **札 (TagPlate) の y + size*0.85 を 830 以下にする。** 画面の下には字幕の黒帯 (上端854) が別レイヤーで乗ります。検品プレビューには字幕が出ないので、目で見ても気づけません。必ず計算で守ること
3. **絵の中の文字は、ラベル・数値・標識だけ。** 台本の文章をそのまま絵に書かない (字幕が出るので二重になる)。**札は字幕と同じ言葉の繰り返しも禁止** (例: #19 の字幕に「60秒」「おさらい」があるので、札にどちらも書かない)。札に読点「、」を入れない
4. **必ず `f` で何かが動く。** 静止した絵は禁止
5. **出そろうのは f=42 まで。** 検品プレビューは全シーンを f=45 の瞬間で描きます。`seg(f, a, b)` の b は 42 以下にすること
6. 色は `KRP` と `SP` にある色だけを使う。新しい色が要るなら、担当ファイル上部の `C` に物の名前で足す
7. seed は 714〜718 を1シーンに1つずつ (もう骨組みに書いてあります。変えない)
8. 対応表 `KSE_D_SCENES` は**変えない**。motif 名も変えない
9. **`KseNotify` は HTML なので svg の中に入れない。** #15 と #18 の骨組みにはもう `Frame` の `over={...}` に渡してあります。そこは触らず、**svg 側 (children) の「背景の世界」だけを描いてください**

## 使える部品

`import` 行はもうファイルに書いてあります (#16 で使う `DokuHai` だけ、`KseParts` の import に自分で足してください)。

**`KseShared.tsx` から**
- `<Frame f={f} seed={714} bg={KRP.cream}>…</Frame>` — 手描きのゆらぎ。全シーンの外枠。必ず使う。children は svg 要素
- `<TagPlate x y text size t color fill rot />` — 木札。`t` は 0→1 で出てくる。幅 ≈ text.length*size+40
- `<QMark x y s f t />` `<XMark x y s t />` `<Arrow x y s rot t />`
- `W`=1920 `H`=1080 `FONT`

**`KarakuriScenes` から**
- `<Person x={x} y={y} s={s} cloth clothDark face gaze lean f phase still pose pointDir />` — x,y は**足元**。頭のてっぺんは y - 292*s (担当Dでは出番が少ない。#17 で手だけ描く等はせず、人なしでよい)
- `<PersonMini x y s cloth face arms f phase />` — 群衆用の小さい人
- `<Stamp …/>` — 朱印。#15 の背景書類の「制裁」跡に使ってよい。使う前に `grep -n "export const Stamp" src/remotion/karakuri/KarakuriScenes.tsx` で引数を確認
- `seg(f, a, b)` → f が a〜b の間で 0→1 / `easeOut(t)` / `clamp01(x)` / `pop(t)`
- `KRP` — 共通の色 (ink, cream, white, red, green, orange, yellow, gray, grayDark, blue, blueDeep, silver, floor …)

**`KseParts.tsx` から**
- `SP` — 考証ずみの物の色 (radioWood, radioCloth, lantern, brass …)
- `<DokuHai x y s t f poison />` — ペルシアの脚付き毒杯。**#16 の地図の上で小さく使う** (s≈0.4〜0.5)。見た目を描き直さない (#7・#13 と同じ杯が出ることに意味がある)
- `<KseNotify f t text y w />` — 通知カード (HTML)。**#15・#18 の骨組みで over に渡し済み。触らない・svg に入れない**

## 「図」の見本 (これと同じ作りこみ・同じ大きさで描く)

```tsx
// 見本: 机に置いた砂時計の図 (世界=木の机+敷き紙。主役は画面の半分。必ず f で動く)
const Sample: React.FC<{ f: number }> = ({ f }) => {
  const t1 = easeOut(clamp01(seg(f, 4, 20)));
  const fall = clamp01(seg(f, 10, 42)); // 砂が落ちる進み
  const GX = 820, GY = 880, GH = 620;   // 砂時計の接地中央と高さ
  return (
    <Frame f={f} seed={999} bg={KRP.cream}>
      {/* 世界: 机の天板と敷き紙。画面の端から端まで */}
      <rect x={-20} y={700} width={W + 40} height={H - 680} fill={KRP.floor} stroke={KRP.ink} strokeWidth={7} />
      <rect x={240} y={740} width={1440} height={300} rx={8} fill={KRP.white} stroke={KRP.ink} strokeWidth={5} opacity={0.9} />
      {/* 主役: 砂時計。枠・柱・ガラス・砂・くびれまで作り込む */}
      <g transform={`translate(${GX} ${GY}) scale(${0.6 + t1 * 0.4})`}>
        <ellipse cx={0} cy={0} rx={230} ry={34} fill={KRP.bronze} stroke={KRP.ink} strokeWidth={7} />
        <ellipse cx={0} cy={-GH} rx={230} ry={34} fill={KRP.bronze} stroke={KRP.ink} strokeWidth={7} />
        {[-200, 200].map((px) => (
          <rect key={px} x={px - 14} y={-GH + 10} width={28} height={GH - 20} rx={12}
            fill={KRP.bronze} stroke={KRP.ink} strokeWidth={6} />
        ))}
        <path d={`M -150 -40 C -150 -200 -22 -250 -22 -${GH / 2} C -22 -380 -150 -420 -150 -${GH - 40}
                  L 150 -${GH - 40} C 150 -420 22 -380 22 -${GH / 2} C 22 -250 150 -200 150 -40 Z`}
          fill="#EAF2F5" stroke={KRP.ink} strokeWidth={7} opacity={0.85} />
        {/* 砂: 下に積もる山が f で育つ。上の残りは減る */}
        <path d={`M ${-120 * fall} -44 Q 0 ${-44 - 90 * fall} ${120 * fall} -44 Z`}
          fill={KRP.yellow} stroke={KRP.ink} strokeWidth={5} />
        <rect x={-6} y={-GH / 2 - 60} width={12} height={110} fill={KRP.yellow} opacity={fall > 0 && fall < 1 ? 0.9 : 0} />
      </g>
      <TagPlate x={1430} y={330} text="砂時計" size={56} t={seg(f, 8, 22)} />
      <TagPlate x={1430} y={450} text="上の砂は戻らない" size={34} t={seg(f, 18, 32)} />
      <Arrow x={1180} y={620} rot={180} t={seg(f, 24, 38)} />
    </Frame>
  );
};
```

要点: **主役を大きく / 画面の端まで使う / 部品の内部まで描く / 札で意味を言う / 必ず f で動く**。

## 進め方

1. まず `KseD.tsx` を Read して骨組みを把握する。次に `KseParts.tsx` と `KseShared.tsx` を Read する (この3つだけ最初に読む)
2. 骨組みの各シーンにある `// どこ: // 演出: // 動き:` のコメントに沿って、5枚を**一気に書く**。Edit で `{/* TODO */}` を置き換えていく
3. 書けたら型チェック: `node_modules/.bin/tsc --noEmit`
4. 札の検査: `npx tsx scripts/koso-plate-check.ts KseD` — **NG 0件になるまで直す**
5. 静止画を書き出す (**1枚ずつ `remotion still` を呼ばないこと。1回のビルドで5枚出せます**):
   ```
   node_modules/.bin/remotion render src/remotion/index.ts KseP tmp/kse/d --sequence --frames=14-18 --image-format=png --log=error
   ```
   出てくるのは `tmp/kse/d/element-14.png` 〜 `element-18.png` (0詰めになることもある。`ls tmp/kse/d` で確認)。**element-N の N + 1 が文番号**です
6. 5枚を Read して自分で検品する。見るところ: 主役が小さすぎないか / 物が重なって読めなくなっていないか / 画面の下1/4に大事なものを置いていないか / 通知カードと背景の世界がケンカしていないか (#15・#18 は背景が濃すぎるとカードが読めない) / 真ん中にポツンと置いていないか / 物同士の関係 (糸が品にめり込んでいないか等)
7. 直して、もう1回だけ書き出して確認する
8. 終わったら、5枚それぞれを1行で説明した報告を返す (400語以内)
