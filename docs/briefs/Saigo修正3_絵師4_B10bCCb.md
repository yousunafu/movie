## #211 (SaigoB10b・`Sg211`) 「150年かけて組み上げられた『最初から最後まで』が、ほどけていきます。」
作者: **「もっと台本に適したイラストが良いな」**

→ いまは巻物 (客の絵) から青い縄が垂れて結び目になり「最初から最後まで」の札が付いている。意味がつかみにくい。作り直してよい。
- 第10章の題は「茶の間は、縛れない」。この動画は「客席を**縛る**ルールが150年かけて積み上がった」話なので、**縄 (組紐) のモチーフ**を活かすと筋が通る
- 案: 画面を左から右へ横切る**太い組紐**。何本もの撚り糸を150年かけて編み上げたもので、撚り糸ごとに**この動画に出てきたルール**の小札 (年号つき)。例:
  - 「1876 消灯」(ワーグナー・バイロイト) / 「1911 椅子席」(帝国劇場) / 「1960 途中入場お断り」(ニューヨーク) / 「1993 入替制」(シネコン) — 年号とルール名は**台本 `docs/saigomade-script-v1.txt` で確かめてから**使う。台本にないルールを足さない
  - 左端は固く編まれ (古い時代)、**右端 (現在) へ行くほど撚りがほどけて**糸がばらけ、ふわっと広がる。ほどけた糸の先には倍速ボタン「2×」・スキップ「⏭」・スマホの小さなアイコンが軽く触れている
- ほどける動きを f で: 右端の糸が少しずつ離れていく
- **倍速・スキップを悪者にも英雄にもしない** (淡々と「ほどけていく」)
- 小札は小さく・読める大きさ (28px 以上)・読点なし

## #216 (SaigoB10b・`Sg216`) 「飛ばして観る人は、観ていないのではない。観方が、変わっただけかもしれません。」
作者: **「現在の構図はいいけど、メインキャラクターを使ったやつに変更しよう」**

- 背景・小物・光は今のものを活かす

## #222 (SaigoC・`Sg222`) 「江戸から続く寄席のルールは、150年の規律化を、素通りしてきました。」
作者: **「演出とイラストはとてもいいけど、各時代の規制の様子を表すイラストに差し替えるとなお良い」**

→ **「寄席の提灯が時代の関所を素通りしていく」演出はそのまま**。いまは明治・昭和・現代の3つとも**同じ踏切のような関所+門番**で、時代ごとの違いがない。ここを**時代ごとの規制の様子**に差し替える。
- 各時代の「規律化」は**台本に出てきたもの**で描く (台本 `docs/saigomade-script-v1.txt` で確認):
  - **明治**: 演劇改良会 (1886) / 帝国劇場 (1911) の**椅子席・切符の窓口** — 洋装の紳士が茶屋ののれんに×、整然と並んだ椅子
  - **昭和**: 名画座の**入替制** (1984) / 「途中入場お断り」の立て札 — 入口で係員が止める、上映時刻の時計
  - **現代**: シネコンの**全席指定・入替制**・暗い客席 — 座席番号の付いた券、発券機
  - **江戸**: 規制なし (寄席の出発点)。にぎやかな町並みのまま
- それぞれの区画の主役は **`Person` の係員・紳士**。時代の服装で (明治=フロックコート、昭和=制帽の係員、現代=制服のスタッフ)
- **寄席の赤い提灯 (寄席の行灯でもよい) は、どの関所にも止められずに左から右へ流れていく**。関所の人がぽかんと見送る、などの反応があると「素通り」が伝わる
- 時代の札 (江戸・明治・昭和・現代) は残す

## #230 (SaigoCb・`Sg230`) 「江戸の桟敷と、やっていることは、ほとんど同じです。」
作者: **「現在の演出とイラストもいいけど、もっとブラッシュアップして」**

→ **発想 (今の部屋と江戸の桟敷を重ね、弁当=スナック・おしゃべり=コメント・出入り=タブ切替 と対応させる) は残す**。作り込みを上げる。
- いまは今の部屋の上に江戸の桟敷が**薄く半透明で重なって**いて、江戸側がほとんど見えない
- **左右の鏡写し**か**上下2段**にして、**江戸の桟敷 (左/上)** と **今の部屋 (右/下)** を同じ密度で描く。対応するしぐさを**同じ位置・同じポーズ**で並べると「ほとんど同じ」が一目で伝わる
  - 弁当を広げる江戸の客 ↔ スナックをつまむ今の人
  - 隣としゃべる江戸の客 ↔ スマホでコメントを打つ今の人
  - 桟敷を出入りする江戸の客 ↔ タブを切り替える今の人
- 人物は全員 `Person`。江戸側は和装 (Kasane で着物を重ねる)
- 3つの対応ラベルは残し、左右を結ぶ点線で対応を示す
