# 第6章「高いほど、安い部屋だった。」設計書 (文#217〜#282 / 66文)

## この章の役割
最後の章。**高さの値段がひっくり返った歴史**を見せ、そのうえで**代金はいまも払われている**ことを示して終わる。
#233「高さは、買うものではなく、払うものでした」と #249「代金を誰が払うか、で決まるんです」が軸。
#262「電気の柱を1本抜くと、水の柱も一緒に倒れます」が**装置の最後の使いどころ**。#277「停電した日に、あの部屋は本当に1850年に戻ります」が**序章の巻き戻しへの回収**。

**語らないもの**: 特定の住民・企業の責任追及。
**語るもの**: パリの階の序列 / 何が消えて何が残ったか / 武蔵小杉で何が起きたか (事実だけ) / 代金を払っているのは誰か。

## ★この章の色の設計
**4つに割る。章がいちばん長いので、色で段落を作る。**

- #217〜#233 (パリ) = 石のクリーム・亜鉛の灰・飴色の木・蝋燭の橙
- #234〜#249 (ひっくり返る〜ペントハウス) = 夜景の紺・金色。**いちばん華やかに**
- #250〜#268 (武蔵小杉) = 雨の灰青・濁った水の緑茶・非常灯の緑。**暗く、冷たく**
- #269〜#282 (結び) = 5本柱の装置の色に戻し、最後の #282 だけ**静かに明るく**終わる

#277 は**序章とまったく同じ構図**にすること (巻き戻しの回収なので、構図が違うと効かない)。
