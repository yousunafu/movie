# 第4章「灯りと、空気。」設計書 (文#147〜#178 / 32文)

## この章の役割
5本柱のうち **「灯り」** と **「空気」** の2本を立てて、**5本ぜんぶを立て終える**章。
軸は変わらず「高さに住むコストを、誰が払っているのか」。
#159「上の階が、やっと『いい部屋』になりました」が灯りの決着、#177「空気も、勝手には入ってこないんです」が章題への呼応、#178「これで、柱が5本立ちました」が**装置の完成**。

**語らないもの**: エジソンの人物像・企業の争い (#156 は発電所という建物と機械だけを描く)。
**語るもの**: 煤と熱と一酸化炭素がどう部屋を支配していたか / 電気で何が消えたか / 高いところの空気はなぜ勝手に入らないか。

短いのは賑やかさを削ったからで、雑に描いたからではない。線・色・札・フォントは山と完全に同じ。必ず `f` で動く。図そのものを作り込む。**大きく置いて画面を使い切る。**

## ★この章の色の設計 (3章との差をつける)
3章は水色と木の茶。**4章は前半を「火の色」、後半を「空気の色」にする。**

- #148〜#155 (ガスの時代) = 橙の炎・煤の黒・飴色の壁。**暗い室内**
- #156〜#162 (電気と暖房) = 白熱球の黄・鋳鉄の黒。**明るくなっていく**
- #163〜#178 (空調と空気) = 灰青・ガラス・白。**冷たく乾いた色**

同じ茶色が続くと章が平らに見える (2章の反省)。章の中で**色が3回変わる**ように。
