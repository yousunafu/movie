# rekishi 作風メモ (あとで docs/制作ガイド.md に統合する)

新プリセット `rekishi` (お手本: 世界史裏探訪) で決めたルールの覚え書き。
制作ガイド本体は競合回避のためここでは編集していない。統合時は §2 の表と専用セクションに反映する。

## チャンネル

- チャンネル名 (仮): **歴史と時間の資料室** (`src/channel.ts` の `REKISHI_CHANNEL`)
- アイコン文字: 史 / 締めの一言は closingLine 参照

## レイアウト (お手本の核)

- **上約8割 (864px) = 資料画像風の絵 / 下約2割 (216px) = 真っ黒の帯**。帯は `RekishiSceneView` 側が全シーンで描く
- 字幕は黒帯の中央に**白ゴシック 48px・太字 700・全文1〜2行** (帯なし・影なし。`Video.tsx` の Subtitle rekishi 分岐)
- カードが全文を見せるときは字幕を重ねない (`rekishiCardShowsFullText`。箇条書きスライドは要点しか見せないので字幕を出す)

## 色 (RP / src/remotion/rekishi/RekishiScenes.tsx)

| 役割 | 値 |
|---|---|
| 紙 (絵エリア背景) | `#E8DCC4` 羊皮紙セピア (ムラ `#D6C3A0` + ビネット) |
| インク (線画・文字) | `#3B2A1E` 焦茶 (薄い線は `#6B5540`) |
| 差し色 (強調) | `#8B3A2E` 錆朱 (補助 `#A0522D`) |

- フォント: 本文・字幕はゴシック (`REKISHI_FONT`)、スライド・カード・図版見出しは明朝 (`REKISHI_SERIF`)

## 演出ルール

- **銅版画調**: 細い平行ハッチング (SVG pattern `rkHatch` 系5種) で陰影。AI画像休止中の資料画像の代用
- **額装**: 絵の周囲に細い**二重枠** (inset 22px/36px の焦茶線) + 古紙のビネットで「資料画像のスライド」感
- **Ken Burns**: 全図版をゆっくりズーム (scale 1.0→1.06 / 300フレーム)。chart だけズームなし (数字がぶれないように)
- **図版キャプション**: 「Fig. N ─ ◯◯」を明朝で絵の下部に (博物図版風)
- **倍率チャート**: 1マス (丸囲み・錆朱) vs 同じ大きさのマスN個の壁。**N=10000でも収まるようセルを自動縮小** (幅880×高さ470に収まるまで cell を16→3pxへ縮める)。「約10,000倍」は錆朱でカウントアップ。大きさはごまかさず数で見せる
- **card**: 紙白 `#F5F0E6` の全面スライド (上80%) に黒明朝。items があれば見出し+箇条書き (・が錆朱、1行ずつ順に出る)、無ければ1行の結論。emphasis の語だけ錆朱
- **motif優先ルーティング**: type より motif で先に分岐 (manabi と同じAIブレ対策)
- enforce は manabi と同等の最小限 (最後の実質シーンを結論カードにするだけ)

## motif 一覧 (src/motifs.ts REKISHI_MOTIFS)

- `city` 廃墟になる都市の遠景 / `ruin` ツタに覆われるビル (ツタが伸びるアニメ) / `decay` 錆と砂 (歯車・鉄骨)
- `dinosaur` 恐竜骨格の博物図版 / `fossilize` 埋没→地層→化石化の3段階図解 (左から順に出る)
- `strata` 地層断面と薄い一枚の錆朱の線 (左から引かれる) / `future_fossil` ペットボトルと鶏の骨の図版
- `moon_footprint` 月面の足跡 (空は焦茶ベタ+星) / `question` 大きな「?」の図版 / `concept` 砂時計 (汎用)

## 台本のコツ (manabi と同様)

- 「〜は…の1万倍」の数字の文 → チャート / 「〜でしょうか」の問い → question /
  「つまり〜」「答えは〜」の結論 → カード (要点を列挙できる文は items で箇条書きスライドに)
