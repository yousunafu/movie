# 自販機2000年史 絵づけ設計書 (台本v5・239シーン対応)

台本: `docs/jihanki2000-script-v2.txt` ではなく **`jihanki2000-script-v5.txt`** (12章・239文)。
シーン番号 = 台本の文の順番 (1行目の「作風:」を除く)。

## 0. 共通演出ルール

- karakuri標準 (制作ガイド§7-5): クラフト紙 / 焦げ茶線 wobble2.5 / 3層常時動き (人物アイドル+図解ループ+ホコリ) / 黒ピルBadge / LabelPill / 赤ハンコStamp / 下部黒帯字幕
- **地球儀トランジション** (`GlobeHop`): 章扉で使用。地球儀が回る→目的地で止まる→前の地点から点線の弧→ピンがポトン (easeOutBack)→国旗ポン+赤ハンコで「年号 地名」→章タイトル
  - 第1章: エジプト (国旗なし→壺とパピルスの紋章)
  - 第2章: イギリス (ユニオンジャック)
  - 第3章: イギリス→(章内でアメリカへ弧)
  - 第4章: アメリカ (星条旗)
  - 第5章: 日本 (日の丸) — **ここで地球儀→日本地図にズームイン**
  - 第6章以降: 日本地図上をピンが移動 (下関→東京→名古屋→全国→国道→夜道)
- **進化の縦糸の色**: ヘロン系の仕掛け (シーソー/弁/歯車) が再登場するときは、初出と同じ構図を再利用して「同じものの進化」と分からせる
- 絵の流用方針: 連続する文は「同じ舞台+カメラ寄り/書き込み/画中変化」で絵を持たせ、新規絵は文の意味が変わる時だけ (キラキラ回の教訓: 絵のブレ防止・部品流用優先)
