# つながる世界史 冒頭3分 設計書 (文#1〜#39 / 39文 / 推定3分06秒)

台本: `台本_つながる世界史_冒頭3分.md` (リポジトリの1つ上の階層)
作風: `sekai`。`lineMode` なので **1行 = 1文 = 1絵**。

## この冒頭の役割
上司に見せる比較見本。**廉価版**と**作り込み版**の2本を、この同じ39文で作る。
A/B比較が成立するのは**キャラ・色・線・声が完全に同一**のときだけなので、
2本の差は **机の上の密度 / 背景の作り込み / カメラの動き** の3つだけに閉じ込める。

着地は #39「日本のガソリンが補助金で170円前後に抑え込まれているのは、このためです」。
イランの話が視聴者の財布まで下りてくる文なので、ここで切ると見本として一番強い。

## 配色
`world.tsx` の `WP` パレット (障子を光源にした逆光) を全編の**基準**にする。
**光源をひとつ決めて逆光にする**のがこの作風の約束。逆光だと人物が黒い影になるので、
実在の人物 (天皇・ホメイニ・ハメネイ・モジタバ・トランプ・バンス) の顔を描かずに済む。

### ★色は「物の色」で入れる — 2026-11-09 作者指摘で全面改修

作者評 (1回目)「**チャンネルの色味が全てのスライドに出過ぎてメリハリがない。場面が変わってる気がしない。ちゃんとカラフルな絵遣いにしたい**」。
基準色 (墨＋琥珀＋錆朱) を39枚すべてに敷いたので、1945年の日本も1988年のイランも2026年の空爆も**同じ茶色の部屋**に見えていた。

直し方として一度、画面全体に `feColorMatrix` を掛けて区間ごとに色相をまわした。**これは却下された。**

作者評 (2回目)「**ちがう全然違う。全体の色を変えろってのはそうじゃないんだよ。ちゃんと写真に撮ったように、適切なものに適切な色を入れろって言ってんの**」

**結論: 全体フィルタは掛けない。物ごとに本当の色を置く。**
夜空は紺、海は青、炎は橙、煙は灰、雪は白、現代の書類は白、古文書は生成りの和紙、鉄は鋼色、石油は黒、看板は赤と緑。
物の色の台帳は `src/remotion/sekai/world.tsx` の `WP` (`nightSky` `seaBlue` `fire` `snow` `paperWhite` `steel` `signRed` …)。
1枚ごとの色の指示は `docs/briefs/sekai-color.md` にある。

区間 (`SEKAI_ZONES`) はもう色を決めない。**場面の目次**として残してある。

| 区間 | 文 | その場にある物と色 |
|---|---|---|
| 導入 夜の地球 | #1–3 | 宇宙の黒・紺の地球・青い大気・琥珀の灯・白い新聞 |
| **1945 日本 玉音放送** | #4–8 | **変更なし**。座敷・障子の琥珀が正解 (作者「玉音のスライドになったらこのスライドで良い」) |
| 1988 イラン 毒の杯 | #9–14 | 夕空の紫紺と橙・朱の横断幕・真鍮の杯・深緑の毒・麻の綱 |
| 2026 戦争と忠臣蔵 | #15–22 | **紺の夜空に橙の炎** (#16) → **冷たい青白の空の演説台** (#17) → 白い文書 → 雪の白と提灯の橙 (#22) |
| 前置き 断りと問い | #23–29 | **白い書類**で画面を明るくする。朱の伏字・銀の枠・砂時計の砂 |
| 60秒おさらい 報道 | #30–39 | 暗い青＋白＋速報の赤。#33 だけイスラムの緑。**#39 の着地で夕空の橙と看板の赤緑に戻す** |

隣り合う2枚の温度差が「場面が変わった」の正体。
一番強い切り替えは **#16 (炎の赤) → #17 (冷たい青白)** と **#29「60秒でおさらいします。」の直後** (物語 → 報道)。

## ★共通部品3つ (6点法③ 作り込んで何度も使う)

作者指示「**世界地図とか場所とか時系列もわかりやすく**」への答え。
毎回ちがう図を発明せず、**同じ3つの部品を、違う場所だけ光らせて使い回す**。
こうすると視聴者は2回目から図の読み方を覚えなくて済む。

### 部品1: 世界地図 `SekaiMap`
初登場 #10、再登場 #31 / #37 / #39。
- 墨の海に、生成りの線で陸の輪郭。緯度経度の罫は薄く (opacity 0.07)
- **その回で話している国だけが琥珀色に灯る**。他は灰のまま
- 国と国の関係は**錆朱の弧**で結ぶ (攻撃・影響・つながり)
- 扱う土地は5つだけ: 日本 / イラン / イスラエル / アメリカ / 江戸(日本の中)
- 弧は必ず `f` で端から端へ伸びる。出しっぱなしにしない

### 部品2: 年表の帯 `SekaiChrono`
初登場 #9、再登場 #15 / #30 / #34。
- 画面の下寄りに水平な1本の錆朱の線。左が古く、右が新しい
- **2段ある**。上段 = 大きな時代 (1701 / 1945 / 1988 / 2026)、下段 = 2026年の月日
- 今いる時点に**縦書きの札**が立つ (`YearTag` と同じ字形にして同じ物だと分かるように)
- 時代が飛ぶときは、朱の点がスーッと走ってから札が立つ。これで「飛んだ」と分かる

### 部品3: 年号札 `YearTag` (実装済み)
**全シーンに常設**。右上に縦書きで「年・月」と「国」。
地図と年表を出さない文でも、ここだけは必ず出す。
「いま、いつの、どこの話か」を一瞬も迷わせないための保険。

## 絵の「格」の配分

| 格 | 枚数 | 割合 |
|---|---|---|
| **山** | 16枚 | 41% |
| **並** | 8枚 | 21% |
| **図** | 15枚 | 38% |

**格の逸脱: 作者指示「今回は並は少なめ山は多めがいいかもね」。** 目安 (山20〜35%) を超えて山41%・並21%にしている。
理由は2つ。(1) これは本編ではなく**上司に見せる作り込み版の見本**なので、作り込みの上限を見せる必要がある。
(2) 3分39文しかなく、この冒頭だけで1945/1988/2026/江戸の4つの時代と4か国を開くので、
**場所と時代が変わる文がそもそも多い**。場所が変わる文を並や図で流すと、どこの話か分からなくなる。
