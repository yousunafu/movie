次に作る候補の置き場。**「あれどうしたっけ」を防ぐのが目的**なので、題名だけでなく
**筋 (ストーリーの背骨) ・冒頭のヒキ・保留の理由**まで書き残す。

## 使い方

- 新しいネタを思いついたら「候補」に1枚カードを足す
- やると決めたら「やる順」の表を書き換える
- 作り終えたら「作ったもの」に移し、`docs/作品カルテ.md` に本体の記録を書く
- **やらないと決めたものも消さずに「見送り・保留」に残す** (理由ごと残すのが肝心)

## 2. トイレと下水 (作るのは確定・エレベーターの次)

- **筋**: トイレを変えたのは、きれい好きではなく恐怖だった
- **ヒキ**: 「水洗トイレは、3回発明されて、2回忘れられました」
- **落ち**: 臭いを止めたのは配管ではなく、便器の下のわずかな溜まり水。その小さなフタのおかげで、私たちは下水のことを考えずに暮らせている

### 構成の方針 (2026-10-30 作者判断)

**前半は世界、中盤から日本に寄せる。** 理由は日本に強烈な別解があるから。

> **西洋が捨てていたものを、江戸は買っていた。**

西洋が窓から投げ捨てていた同じ時代、江戸は糞尿を農家が**買い取る**市場を持ち、長屋の大家の収入源にすらなっていた。結果、当時の世界で例外的に清潔な百万都市だった。

前半「世界は3回発明して2回忘れた」→ 中盤「日本は別の答えを持っていた」→ 後半「明治のコレラでその答えが崩れる」→ 下水道、汲み取りから水洗へ、ウォシュレット。

### からくり図解の見せ場

S字トラップの断面 (水のフタ)、下肥を運ぶ桶と船、ジョン・スノウのコレラ地図、汲み取りと浄化槽

題材の品。下品に寄らない線引きが要る。仕組みと衛生史に寄せる。

## 1. ビル (エレベーター) ★次回作 (2026-11-02 保留から一気に昇格)

**作者の方向づけ (2026-11-02)**:
- 後半に**現代の日本のエレベーター技術**を盛り込む
- 台本は中学生〜高校生で分かる内容。ただし**大人も感心して見続けられる、ユーモアたっぷり**のものに

- **筋**: エレベーターは上と下の値段をひっくり返した
- **ヒキ**: 「百年前まで、最上階は一番安い部屋でした」 ← **ヒキは全候補中で最強クラス**。説明ゼロで成立する
- **落ち**: エレベーターは乗り物ではなく**不動産の装置**。都市が上に伸びたのは鉄骨ではなく、人が上を信じたから

### 仕組みの一文 (ここが分かれば回が成立する)

> 「エレベーターは、箱を**持ち上げていません**。反対側に同じ重さのおもりがぶら下がっている。**天秤**です。モーターは差額のぶんだけ働いています」

釣り合いおもり (カウンターウェイト) の断面。シーソー → 滑車 → ロープ → 箱とおもり、の順で組み上げる。
**「あ、持ち上げてないのか」** の体感が来る。トイレのS字トラップと同じ種類の分かりやすさ。

### いちばんの見せ場 — 1853年オーチスの実演

自分が乗った台のロープを、その場で切ってみせた。落ちなかった。
**技術のデモではなく信用のデモ** という読み替えがこの回の背骨。安全装置はその前からあった。足りなかったのは装置ではなく信じる気持ち。
歯止めの仕組み (ロープが切れるとばねが開いて爪がレールに噛む) は、ばね1個と爪2個の図解で終わる。**絵で完結する。**

### 章立て案 (15〜18分 / 165〜195文)

| 章 | 内容 | 図解の山 |
|---|---|---|
| 1 | 最上階は安かった | 階段を登る絵・家賃表 |
| 2 | 人は昔から物を上げていた (井戸・滑車・荷物用) | 滑車 |
| 3 | 人は乗らなかった — 落ちるから | 切れたロープ |
| 4 | **釣り合いおもり** | ★天秤の断面 |
| 5 | **1853年、ロープを切る** | ★斧・歯止めの爪 |
| 6 | 値段がさかさまになる | 家賃表がひっくり返る |
| 7 | 日本に来る | 凌雲閣 |
| 8 | 速くするには止め方が問題 (調速機) | ★おもりが遠心で開く |
| 9 | 地震の国のエレベーター (管制運転) | 揺れ→最寄り階で開く |
| 結 | 都市が上に伸びたのは鉄骨ではなく、人が上を信じたから | — |

### 保留の理由は解消できる見込み

元の保留理由は「日本の話が少なく海外近代史に寄る」。**埋められる見込みが立った** (すべて要確認):

- 浅草・凌雲閣の日本で早い時期のエレベーター (短期間で止まった経緯あり)
- 霞が関ビルと高層ビル解禁
- **地震のときの管制運転** ← 日本固有・絵が強い・仕組みの話として入る (付け足しにならない)
- 日本メーカーの世界最速エレベーター

### 要ファクトチェック (危ない順)

1. 「最上階がいちばん安かった」を**断定で言えるか** (都市・時期によるはず)

## 3. 冷凍技術

- **筋**: 冷蔵庫が変えたのは食べ物ではなく、買い物の回数だった
- **ヒキ**: 「1806年、ボストンの商人が船いっぱいの氷をカリブ海へ送りました。正気を疑われました」

## 電池

- **筋**: 電気を**溜める**のではなく、金属が錆びる力をせき止めて取り出している
- **ヒキ**: 「電池の中に、電気は入っていません」
- **一文テスト**: 「違う2種類の金属を塩水に浸すだけで電気が出ます。レモンでも動きます」
- **図解**: 2枚の金属板と塩水の断面。電子が片方へ流れる矢印。ボルタの電堆の積み重ね
- **強み**: 手に取れる物 / 自分ごと / 仕組みが絵で終わる。**理系寄りの中でいちばん分かりやすい**
- 日本の話: 屋井先蔵の乾電池、リチウムイオン電池 (吉野彰)

## 織機とコンピュータ — 後回し (2026-11-02)

- **筋**: 模様を記録した紙が、計算を記録する紙になった
- **ヒキ**: 「世界で最初にプログラムを読んだ機械は、布を織っていました」
- 入り方は**編み図** (ますめを塗るか塗らないか) から。「1と0」「デジタル」という言葉は**使わない**
- 主役は織機ではなく**穴のあいた紙**。バベッジは出さず、1880年の米国国勢調査 (集計7年 → 穴の紙で2年半 → IBM) で入る
- **後回しの理由**: 台本は分かりやすく作れる。ただし効く快感が「へえ、つながってるのか」という**頭の納得**で、トイレやエレベーターの「あ、そうなってたのか」という**体の納得**には届かない。これは書き方では直らない。視聴者が育ってから効く回
