## #1 山「時代が違っても、国が違っても、人の心は変わらない。」

**構図** 夜。**窓を2つ横に並べる**。左＝1945年の日本の茶の間、右＝2026年テヘランの台所。
同じ姿勢の女性が2人、同じ角度で前かがみになっている。これが「人の心は変わらない」の絵。
カメラは窓の高さ、少し煽り。外は夜の路地 (地球は出さない)。

**左の窓に出す物** 卓袱台 / 真空管ラジオ (布張りのスピーカー・丸ダイヤル2つ・つまみ) /
裸電球に**黒い布の笠** (灯火管制) / 畳の縁 / 湯呑み / 柱時計
**左の人** 30代の女性。紺のもんぺ＋白い割烹着 (`WP.monpe` `WP.kappogi`)。正座、膝に手。

**右の窓に出す物** ステンレスのガスコンロ / **estekan** (細腰のチャイグラス) とソーサー /
角砂糖の皿 / 電気ポット / 伏せて置いたスマートフォン / 壁の模様タイル
**右の人** 30代の女性。柄入りのルーサリー (前髪が少し出ている) ＋ 長いマントー。椅子に浅く座る。

**事件** 2つの窓の明かりが**同じ瞬間にまたたく**。
**禁止** 地球儀・世界地図・黒い人影。

## #8 山「一億玉砕を叫んでいた国が、この日、戦争をやめました。」(全景可)

**構図** 俯瞰ぎみ。**宮城前広場 (二重橋前)**。1779・1780行の黒い影を全部描き直す。
**出す物** 明るい灰白色の**玉砂利** (`#CFC9BC`。芝ではない) / 濠の水 / 松原 /
二重橋の石橋とその奥の**伏見櫓** / 楠木正成の騎馬銅像 / 立てかけられた竹槍 /
「撃ちてし止まむ」の白地に墨の立看板 / 脱いだ**防空頭巾** / 巻脚絆

**★姿勢の考証 (ここを間違えないこと)**
調べた結果、人々は**まず立ったまま聞き、放送が終わってから玉砂利に膝をついた**。
有名な「一斉に土下座する群衆」の写真は**8月16日撮影のものが多く、カメラマンが
跪くよう指示したという証言もある**。だから**全員が一斉に土下座している絵にしない**。
**放送が終わった直後の、姿勢がばらけ始めた瞬間**を描く ── まだ立っている人、
今まさに膝をつこうとしている人、もう地面に手をついている人が同じ画面にいる。

**人 (老若男女を必ず混ぜる)**
- まだ直立不動のまま動けない中年男性 (国民服・戦闘帽を手に・巻脚絆)
- 膝をつきかけている勤め人 (白い開襟シャツ)
- 立ったまま声を上げずに泣く40代女性 (もんぺ・筒袖の上衣・防空頭巾を外して手に持つ)
- 空を見上げたまま動かない老人 (着流し・杖)
- 母の背の赤ん坊 (ねんねこ半纏) と、母を見上げる女の子
**事件** 一人だけが**防空頭巾を脱いで玉砂利の上に置く**。もう空襲は来ない、という意味。
**禁止** 全員同じ向き・同じ大きさ・同じ姿勢で並べる (前回これをやった)。
