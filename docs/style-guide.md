# 作風の基準 (スタイルガイド)

お手本チャンネル (高齢者向け食事・健康系) の動画5本・791コマを実測して導いた基準。
**印象で直さず、この実測値を基準にする。** 変えるときは `src/style.ts` と本書の両方を更新する。

測定日: 2026-10-05 / 測定方法: 各動画のストーリーボード画像 (322x180) を全コマ取得し、輝度・彩度・色相を計測

## 実測値

| 測ったもの | 結果 | どう読むか |
|---|---|---|
| 平均輝度 | 235 / 255 | ほぼ白。画面の92% |
| 明るいコマ (輝度160以上) | 100% | 暗い場面は存在しない |
| 平均彩度 | 3.7% | 極めて淡い。水彩パステル調 |
| 暖色優位のコマ | 95.2% | ベージュ・赤・オレンジが基調 |
| 寒色優位のコマ | 3.9% | 青は服などの差し色のみ |
| 有彩色ピクセル | 8.5% | 画面の9割は白〜クリーム |

## 目視で読み取った構図の型

- クリーム色の白背景に、フラットな手描き風イラストが中央に1つ
- 白髪のシニア人物の日常場面 (台所・食卓・スーパー) が約6割
- 食品・物のアップ (白背景中央 + 足元に淡い楕円) が約2割
- ラベル付き図解 (体の部位・仕組み) が約1〜2割
- 字幕は画面下部中央・濃いグレーの太字・帯なし・常時表示
- 強調は赤系の暖色のみ。寒色で強調しない

## プログラムに反映した条件 (src/style.ts)

| 実測 | 条件に直すと |
|---|---|
| 明るいコマ100% | 背景は常に #FAF6F0 (クリーム白)。暗い背景は使わない |
| 暖色95% / 寒色4% | 基調は暖色。青は服・魚など少量のみ |
| 人物場面 約6割 | character を45〜65%に収める |
| 物のアップ 約2割 | object を15%以上 |
| 図解 約1〜2割 | diagram+chart を10%以上 |
| 場面の呼吸 | 6〜10シーンに1回は location (全景) を入れる |
| 終盤の締め | 最後の実質シーンは必ず結論カード (card) |

## 線引き (学んだもの / 流用しないもの)

- 学んだもの: 明るさ・配色の比率、構図、字幕の位置、場面の切り替えテンポ → 上記の数値
- 流用しないもの: お手本のチャンネル名・アイコン・決まり文句・固有の言い回し
- チャンネル名と締めの文句は `src/channel.ts` だけで管理する (お手本の名前を入れない)
