## 書くもの
担当範囲の全文について、次の表の行を1文1行で書く。保存先は指示されたファイル (表の見出し行も含める)。

```
| # | 台本の文 | 格 | 絵 |
|---|---|---|---|
| 12 | (台本の文をそのまま全文) | 山 | どこ: …。演出: …。動き: … |
```

- 「台本の文」は台本の行を**一字一句そのまま**写す (機械が照合する)
- 「格」は 山 / 並 / 図 のどれか。**山を多めに** (作者指示)。格は手抜きの段階ではなく画面の設計の区別: 山 = 舞台・人・事件・カメラ全部入り / 並 = 舞台はあるが主役は1つ / 図 = 図解が主役 (ただし図にも必ず世界を敷く: 古い紙・黒板・石板・展示パネル・体の中の壁など。素の方眼・クリーム地は0枚)
- 「絵」は 1行 250〜500字。必ず「どこ:」「演出:」「動き:」の3つを書く。章扉 (第N章、…) は「章扉。」で始め、ChapterDoor num=N title="…" を画面の右寄りに置くと書く
- 共有装置 (meza-design-common.md の「共有装置」) を使う文では、部品名と props の値を書く (例: `Shinshitsu (sky=0, sleeper=1, alarms=2)`)。同じ場所の続きの文は、前の文と同じ部品の続きとして状態だけ進める
- 繰り返しモチーフ「起こす人を、誰が起こすのか」の文では `NazoBell` を置く (common の指定の文番号)

## 1文ずつ必ず確かめる6点法 (欠けたら書き直す)
1. **寄る**: 主役を画面いっぱい (短辺の1/2以上)。全体像は章に1枚だけ。小さい物を真ん中にポツンは最悪の失敗
2. **世界を置く**: 何もない背景に図を浮かせない。その時代・その場所の舞台を書く
3. **部品を作り込む**: 共有装置は同じ物を何度も使う。小物は細部まで (時計ならベル・ハンマー・脚・ゼンマイのつまみ・文字盤の数字)
4. **カメラが動く**: 1枚の中で寄る / 引く / パン / 上へスクロールのどれか
5. **事件を起こす**: 説明ではなく出来事。「○○の図。各部に札」で終わる行は失格
6. **人が反応する**: 棒立ちさせない。驚く・あくびする・飛び起きる・首をかしげる

## そのほかの決まり
- 札 (文字のラベル) は短く、字幕と同じ文を絵の中に書かない。年号・数字の札はよい
- 実在の人物 (プラトン・ハッチンズ・MITの大学院生・ロンドンの豆鉄砲の女性・GE などの会社の人) は顔を描かない (背中・手元)。会社名・商品名のロゴは描かない (クロッキーの名前の札はよい)
- **男女が台本上意味を持つ場面は、common の「男女の描き分けの決まり」をそのまま書き写す**。「人たち」の場面は男女を混ぜてどちらもひと目で分かる姿で
- **腕は2本**。人が何かを持つ・指す場面では「腕は2本 (pose=… で描く)」と書き添える
- 笑いどころ (common の一覧と、それ以外でも台本の冗談の文) は、絵の事件で受ける。説明の札で受けない
- 事実は report の範囲だけ。B 判定の事実を絵で断定しない (例: 「とされる」話は、絵に「?」や点線を添えてもよい)
- 1文の絵の長さは約3〜6秒 (30fps で 90〜180フレーム)。動きは f (フレーム) で「f0-20 ○○ / f20 △△」のように書く
