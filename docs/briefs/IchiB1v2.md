## 大原則
1. **図の明快さは殺さない。** グラフの線・棒・札の読みやすさ最優先。背景は彩度低め・薄めに「敷く」。
2. **方眼 (GridPaper) を使うなら「何かの上」にする** (獣皮・岩壁・砂地・紙)。素のクリーム+方眼は禁止。
3. motif名・seed (920〜934)・SCENESキー・export 群は**一切変更しない**。#31/#32 の phase 共有も維持。
4. 札: TagPlate 下端 (y+size*0.85) ≤ 830。seg(f,a,b) の b ≤ 42。全シーン f で動く。
5. **札の読点の法 (新ルール)**: 札・タイトルに読点「、」禁止。間は半角スペース。章扉「獲物をけなす。」は修正済みなので戻さない。
6. 山・並のシーン (#21,#23,#24,#25,#27,#30,#33) はすでに舞台があるので**手を入れすぎない** (被り確認のみでよい)。主戦場は図シーン (#22,#26,#28,#29,#31,#32,#34,#35)。
