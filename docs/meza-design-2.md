## 共有装置の使いどころ
- `MP` 色: you 水色 / youDark / night 夜の紺 / dawn 夜明けの橙 / bell 目覚ましの赤 / brass 真鍮 / habit 修道服の黒 / stone 石 / mist 朝もや
- `Shinshitsu` (あなたの寝室): ベッド・枕・掛け布団・窓 (カーテン、外の空の色は `sky` で夜→夜明け→朝)・ナイトテーブル・スマホ・壁の時計。props: `f, sky (0=夜,1=夜明け,2=朝), sleeper (寝ている姿勢 0〜1), alarms (鳴っているスマホのアラーム数)`。**#1・#2・#3・#4・#5・#9・#10・#11・#16・#36・#152・#153・#211・#212・#213** で使う (同じ部屋の続き)
- `SumahoAlarm` (スマホのアラーム画面): 5分おきの5個のアラームの一覧 (6:00 / 6:05 / 6:10 / 6:15 / 6:20)。props: `f, on (鳴っているもの), off (止めたもの)`
- `TainaiDokei` (体内時計): 脳の奥にある小さな時計。文字盤は24時間・針は1本・**1周した先に11分ぶんの「はみ出し」の赤い区画**がある。中で小人が歯車を回す。props: `f, lag (はみ出しの量 0〜1), reset (光で合わせ直す 0〜1), x, y, s`。**#18〜#24・#29・#37・#128・#129・#199** で使う
- `Kobito` (体の中の小人の作業員): Person s≈0.3 + 黄色ヘルメット。props: `x, y, s, pose, face, f`
- `Shudouin` (修道院の寝室): 石のアーチ天井・細長い窓・ろうそく・木のベッドが並ぶ。props: `f, dark (夜の暗さ), candle (ろうそくの数), bell (鈴が鳴る 0〜1)`。**#50〜#58・#61〜#64・#206〜#208** で使う
- `TokiNoKane` (江戸の時の鐘): 木の鐘楼・釣り鐘・撞木・瓦屋根・町並みの屋根。props: `f, swing (撞木の振り 0〜1), sky`。**#65〜#72・#201** で使う
- `BanninTou` (ウィーンの塔と番人の部屋): 石の塔の最上階・大きな鐘・番人のわら布団・**番人を起こす小さなベル付きの鉄の時計**。props: `f, ring (時計のベル 0〜1), wake (番人が起きる 0〜1)`。**#84〜#88・#203** で使う
- `KoujouMon` (イギリスの工場の門): れんがの工場・高い煙突・鉄の門・**門の上の大きな時計**。props: `f, gate (門の開き 1=開 0=閉), hands (時計の時刻 分), smoke`。**#104〜#113・#127・#201・#213 (会社の門として色だけ変えて)** で使う
- `MachiNami` (イギリスの工業の町の連続住宅、夜明け前): 2階建てのれんがの長屋・2階の寝室の窓・石畳・ガス灯・遠くに工場の煙突。窓ごとに `lit` (明かりがつく)。props: `f, windows (各窓の状態), sky`。**#132・#134〜#143・#147・#154・#155・#158〜#161・#183・#195** で使う
- `KnockerUp` (ノッカー・アップ): 上の見た目の人物部品。props: `x, y, s, f, pose ("walk"|"knock"|"shoot"|"sleep"|"jump"), female, old, face`。棒は pose="knock" で窓まで届く長さ
- `BellClock` (ベル式目覚まし時計): 丸い文字盤・上に2つのベル・その間のハンマー・2本の脚・後ろのゼンマイのつまみ。props: `x, y, s, f, ring (鳴る 0〜1。ハンマーが左右に高速で打つ+音の線), snooze (上にスヌーズボタンがある版)`。**#145〜#153・#166・#167・#170〜#182・#209〜#212** で使う
- `Clocky` (逃げる目覚まし): 丸い時計の左右に大きな車輪が2つ。props: `x, y, s, f, run (走る 0〜1), face`。**#189〜#196** で使う
- `NazoBell` (ナゾベル): 「?」付きの小さな目覚ましベルのマーク。props: `x, y, s, f, solved (true で ? が外れて ! になる)`。#15・#45・#58・#88・#158・#168 で使う
