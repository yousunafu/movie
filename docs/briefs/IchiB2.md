# 仕事

`src/remotion/karakuri/IchiB2.tsx` の **12個のシーン (文#36〜#47)** を描き切ってください。今このファイルは骨組みだけで、中身が `Todo` プレースホルダになっています。Todo を12個とも本物の絵に置き換えるのがゴールです。

作っている動画は「『2位』は、120年前に発明された」(順位の発明史)。あなたの担当は**第2章「一番槍は、書類仕事。」**。
戦国の武士の最高の名誉「一番槍」が、実は「軍忠状」という自己申告書+証人の署名で確定する**書類仕事**だった、というギャップで笑わせる章です。章の結論は「順位の歴史は、記録の歴史」「ただし土俵 (順位が通じる範囲) はまだ戦場1つぶんしかない」。
**この章のトーン**: 笑いの山。「命がけの武勇 → 事務処理」の落差で笑わせる。ただし武士を間抜けに描かない。笑うのは**状況**であって人ではない。
**語らないもの**: 実在の武将名・合戦名 (関ヶ原等を書かない)・家紋 (実在のものを使わない。旗の紋は丸や縞などの抽象柄にする)・血や死体 (戦場でも描かない。突入は土煙とスピード線で見せる)。

## 絶対に守ること

1. **1文 = 1シーン = 1枚の絵。** 12文だから12枚。増やさない減らさない
2. **札 (TagPlate) の y + size*0.85 を 830 以下にする。** 画面の下には字幕の黒帯 (上端854) が別レイヤーで乗ります。検品プレビューには字幕が出ないので、目で見ても気づけません。必ず計算で守ること。検査スクリプトもあります (進め方の手順5)
3. **絵の中の文字は、ラベル・数値・標識だけ。** 台本の文章をそのまま絵に書かない (字幕が別に出るので二重になる)。札の文言は**字幕の言い換え**にする (字幕と同じ文言の札は禁止)。軍忠状の中身も、読める文章は書かず**刻み線・波線で「字がある感じ」**を描く (「一番」「証人」などの欄名ラベルだけ可)
4. **必ず `f` で何かが動く。** 静止した絵は禁止
5. **出そろうのは f=42 まで。** 検品プレビューは全シーンを f=45 の瞬間で描きます。`seg(f, a, b)` の b は 42 以下にすること
6. 色は `KRP` と、ファイル上部の `C` にある色だけを使う。新しい色が要るなら `C` に足す (勝手な即値 #xxxxxx をシーン内に散らさない)
7. seed は 935〜946 を1シーンに1つずつ (もう骨組みに書いてあります。変えない)
8. 対応表 `SCENES` のキーと `I_B2_MOTIFS` は**変えない**。motif 名も並び順も変えない。Preview と dispatcher も変えない
9. **連番ペアは絵を複製しない。** #41/#43 は1つの `Gunchujo` 部品の `phase?: 1 | 2`、#45/#46/#47 は1つの `SenjoMap` 部品の `phase?: 1 | 2 | 3` で切り替える。同じ座標・同じ形のまま「何が増えるか」だけ変える。コピペで複数作ると形がズレて差し戻しになります

| 格 | 中身 | 目安 |
|---|---|---|

### ★「図」「並」も品質は落とさない (作者の指示そのまま)

> 「シンプルとか普通のやつも絵のクオリティは下げちゃだめなんだけどね。だけど、細かい作りこんだ絵が生きるのは、そのバランスがあってこそなんだよね」

短いのは**賑やかさを削ったから**であって、雑に描いたからではありません。

- 線・色・札・フォントは山と**完全に同じ**。`strokeWidth` を細くしない。ゆらぎフィルタ (`Frame`) を外さない
- **必ず動く。** 静止した図は禁止
- **図そのものを作り込む。** 軍忠状なら紙の折り目・端の巻き・墨の濃淡・花押まで。地図なら海岸線・山の記号・街道線まで
- **大きく置いて画面を使い切る。** 最悪の失敗は「小さい物を画面の真ん中にポツンと置く」。シンプル＝**1つを、大きく、正確に**。主役の装置は短辺で画面の1/2 (540px) 以上を使う
- 余白は「空っぽ」ではなく「寄り」。余白があるのは、そこに寄っているから

## 使える部品

`import` 行はもうファイルに書いてあります (`void` 行は未使用エラー避けなので、使い始めたら消してよい)。主なものの使い方:

**`IchiShared.tsx` から** (KosoShared の再輸出。必ずこちらから import)
- `<Frame f={f} seed={935} bg={KRP.cream}>…</Frame>` — 手描きのゆらぎ+バッジ+空気。全シーンの外枠。必ず使う
- `<TagPlate x y text size t color fill />` — 木札。`t` は 0→1 で pop。幅 ≈ text.length*size+40。**下端 y+size*0.85 ≤ 830**
- `<QMark x y s t f />` `<XMark x y s t />` `<Arrow x y s rot t />`
- `<ChapterDoor num={2} title="一番槍は、書類仕事。" t={…} />` — #36 の章扉で必ず使う (位置は left/top で調整可)
- `W`=1920 `H`=1080 `FONT`

**`KarakuriScenes` から**
- `<Person x y s ...>` — x,y は**足元**。頭のてっぺんは y - 292*s。grep して props (pose・color 等) を確認してから使う。甲冑は Person の上に兜・胴のパーツを自分で重ねて表現してよい
- `seg(f, a, b)` → f が a〜b の間で 0→1 (範囲外は0か1) / `easeOut(t)` / `clamp01(x)` / `pop(t)`
- `Stamp` (判子風の演出。#43 の「確定」に) / `Bolt` (衝撃線)
- `KRP` — 共通の色 (ink, cream, white, red, green, orange, yellow, gray, grayDark …)

**`KosoB2Parts.tsx` から** (**使う前に該当箇所を Read して引数を確認すること**。import 行は自分で足す)
`lerp` `rnd` `zoomAt` `bobOf` / `GridPaper` (図の方眼下地。「図」の下地に使う) / `Maru` `MaruBatsu` / `ForceArrow`

この範囲で要る物のうち既存部品にないもの (旗指物・陣幕・槍・甲冑武士・軍忠状・花押・日本の地図など) は、**自分のファイルの中にローカルな部品として書いてください** (共用ファイルには足さない)。**甲冑武士は #37・#38・#40・#42 で出るので、必ず `Bushi` ローカル部品に切り出して使い回す** (pose や向きの prop で変化をつける。4回別々に描くと形がブレて差し戻しになります)。

```tsx
  const SX = 760, SY = 330, SR = 210;          // 綱車の中心と半径

  const handY = 640 + pull * 130;
  return (
    <Frame f={f} seed={605} bg={KRP.cream}>
      <GridPaper />
      {/* 吊り元の梁。画面を端から端まで横切らせる */}

      {/* ロープ・綱車・手 … 部品の内部 (溝・スポーク・指の皺) まで描く */}

```

要点: **主役を大きく / 画面の端まで使う / 部品の内部まで描く / 矢印と札で意味を言う / 必ず f で動く**。

## 進め方

1. まず `src/remotion/karakuri/IchiB2.tsx` を Read して骨組みを把握する。次に `IchiShared.tsx` と `KosoShared.tsx` を Read する (最初に読むのはこの3つだけ)
2. 各シーンを書くとき、コンポーネントの頭に `// どこ: // 演出: // 動き:` のコメントを**先に書いてから**描く
3. **「山」(#36・#38) から先に描く。** 章の背骨なので、ここが決まれば残りが決まります。そのあと `Bushi` 部品、連番の図 (#41/#43、#45/#46/#47)、最後に並
4. 書けたら型チェック: `node_modules/.bin/tsc --noEmit`
5. 札の検査: `npx tsx scripts/koso-plate-check.ts IchiB2` — **NG 0件になるまで直す**
6. 静止画を書き出す (**1枚ずつ `remotion still` を呼ばないこと。1回のビルドで12枚出せます**):
   ```
   node_modules/.bin/remotion render src/remotion/index.ts IchiB2 tmp/ichiban/b2 --sequence --frames=0-11 --image-format=png --log=error
   ```
   出てくるのは `tmp/ichiban/b2/element-0.png` 〜 `element-11.png`。**element-N の N に 36 を足した数が文番号**です (element-0 = 文#36, element-11 = 文#47)
7. 12枚を Read して自分で検品する。見るところ: 主役が小さすぎないか / 物が重なって読めなくなっていないか / 画面の下1/4 (y>830) に大事なものを置いていないか / 人の手足や物のつながりが変でないか / 真ん中にポツンと置いていないか / #41と#43、#45〜#47がちゃんと同じ形・同じ座標か / TODO の文字が残っていないか
8. 直して、もう1回だけ書き出して確認する
9. 終わったら、12枚それぞれを1行で説明した報告を返す (400語以内)
