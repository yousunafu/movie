## 指示文 (プロンプト)

次の条件で、解説動画の台本を書いてください。

### テーマ・視聴者・尺

- テーマ: **あなたの先祖は、ほぼ確実に藤原道長である** (家系の収束 = pedigree collapse の数理)
- 想定視聴者: **教養ものを好む大人の男性**。煽らない。ユーモアは乾いた一言まで
- 尺: **10分前後**。ナレーション音声は**8分以上がマスト** = **約113文** (1分≈12文+余裕)
- 作風: 黒背景・白ピクトグラム・赤アクセントの数理図解 (おとなの数理室)

### 構成の指定

1. **導入のつかみ** (約11文): タイトルの主張をいきなり言い切る → 「うちは平凡ですけど」という視聴者の心の声に先回り → 「家柄の話ではなく数学の話」と宣言 → 4章の目次
2. **4章立て**:
   - 第1章 **先祖の数の倍々ゲーム**: 2人→4人→8人…10代前1,024席、20代前105万席、30代前10億席。身近な比較 (全校生徒・仙台市) を挟む
   - 第2章 **日本の人口が足りない**: 平安時代は約700万人。10億の席に700万人 → 同じ人が平均140席掛け持ち → 家系図は木ではなく**網**になる (家系の収束)
   - 第3章 **なぜよりによって道長なのか**: ポイント3つ (①千年前の人 ②子孫が大繁栄して絶滅の心配がない ③記録が残っている)。「千年前に子孫を残した人なら農民でも全員の先祖。道長は名前が残っているから代表に指名されているだけ」という種明かしまで
   - 第4章 **意地悪な種明かし**: 30代経るとDNAの寄与はほぼ0% / 家系図ビジネスは紙では証明できない (戦国系図は創作だらけ)
3. **クイズを2問** (第1章末・第3章末): 「さて、ここで問題です。」の決まり文句 → 出題 → 「答えは、〜、です。」→ 解説。演出は控えめ
4. **結論のまとめ** (約12文): 全章を言い直し → 「道長の子孫は特別な肩書きではない。隣の人もそうだから」とタイトル回収 → 「本当にすごいのは千年間途切れなかった名もなき先祖たち」の余韻 → 乾いた一言で締め (「年賀状は、道長に出さなくて大丈夫です。」)

### 文体ルール

- **1文 = 1シーン**。1行に1文。読み上げ3〜6秒
- です・ます調。数字はたとえで体感させる (1,024人=全校生徒、105万人=仙台市)
- **数字の文・問いの文・結論の文**を各章に入れる (グラフ・問いかけ・カードが自動で付く)
- ユーモアは各章に1つまで、乾いた一言 (「正月の親戚の集まりが苦手な方には、残念なお知らせでした。」)
- 科学・歴史は定説の範囲で誠実に: 「〜と考えられています」/ 怪しい説 (徳川=道長子孫など) は使わない
- 言い切るのは数学が保証する部分だけ。タイトルの「ほぼ確実に」を本文でも守る
