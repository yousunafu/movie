# 直し担当 FixA — HimaA.tsx の #1 #2 #5 #7 #8 #9 (と実験室の秒針)

ファイル: `src/remotion/karakuri/HimaA.tsx`。担当名 FixA。

## #1 「いまこの動画を観ているあなた。たぶん、何かを待っていますね。」(駅のホーム・EkiHome)
作者「1枚目のイラストは背中側の車線に電車（通過電車）が走って欲しい。で、電光掲示板は次の列車みたいな文字もほしいかも。」
- EkiHome に新しい引数がある (HimaParts.tsx の EkiHome の説明を読む): `pass` (0〜1 で通過電車が奥の線路を右から左へ駆け抜ける) と `next` (掲示の上の段の文字)
- 通過電車は「あなた」の**背中側** (ベンチの後ろの線路) を、f のどこかで勢いよく通過させる。f=45 の静止画でちょうど電車が画面を横切っている途中 (pass≈0.4〜0.6) になるように時間を組む (例: pass = seg(f, 28, 60))。風で「あなた」の髪や、鳩が少しよろける反応をつけてもよい
- `next` は「つぎ 普通 さくら台行」のような**架空の駅名**で (実在の駅名・路線名は使わない)。下の段の「5分」はそのまま

## #2 「電車か、お湯がわくのか、既読がつくのか。」(3コマ)
作者「2枚目の左の電車のイラストも電車が奥からこちらに来る形にしてほしい。」
- 左のコマ: 線路の奥 (消失点) から電車の正面 (ライト2つ) が**だんだん大きくなって手前に来る**。f=45 で正面の顔がはっきり見える大きさに

## #5 #9 ボタンでビリッ
- 共通ルールの「画面の揺れ」を入れる。#5 は押した瞬間1回。#9 は連打なので、小さめの揺れ (8px) を何度か
- 押した瞬間のコマ番号を報告 (#9 は音を鳴らしたいコマを3〜5個)

## #7 #8 結果の人形
作者「結果。男性は、18人のうち12人が、押しましたと女性のくだりは、メインキャラクターを使って、あと男女のイラストもわかりやすくすること。」「男女をわかりやすくデザインしてね」
- メインキャラクター = いつもの丸頭の `Person`。小さな人形 (PersonMini や自作の小人) をやめて、**Person で並べる** (s を小さくして 18人 / 24人を並べる。数は変えない: #7 は男性18人中12人、#8 は女性24人中6人)
- 男性: 短い黒髪 (hair="cap")・紺や青の服・ズボン
- 女性: Person に**肩まで届く茶色の長い髪 (左右に垂らす)・赤いリボン**を描き足し、服はピンク系で、**スカート** (腰から膝まで広がる台形) を足して脚を少し隠す。ひと目で女性と分かるように
- 押した人の頭の上に稲妻、押していない人は首をかしげる、などの今の演出は残す

## 実験室の秒針 (#3〜#10)
作者「アメリカの実験室のイラストは秒針をちゃんとしたスピードにしてみて」
- 共有部品 ShockRoom の壁時計はもう直してある (1秒に1目盛り)。**このファイルの実験室の場面 (#3〜#10) で、自分で描いた時計の秒針があれば**、同じ速さ `rotate(${Math.floor(f / 30) * 6})` にそろえる。ない場合は何もしない
