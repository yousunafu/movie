# 第6章 設計書 — 「2位が、発明された日。」(文#103〜#122・20枚)

舞台 = 1896年アテネ → 1904年セントルイス → 1912年 → 1930年カナダ。トーン = **驚きの山**。
背骨 = **「発明されたのは1位ではない。2位だ」**。笑いではなく「年号の若さ」で驚かせる。
★ #113→#114 が**全編の頂点**。2枚使って溜めて落とす。
オチ (銅>銀・順位をやめた実例) は**絶対に出さない**。

## 第16条「作り込みの床」この章での敷き方

- 素の方眼 + クリーム地だけの絵は **0枚**。
- 図の床は4種類だけに絞って使い回す:
  1. `Stadium` = 大理石の競技場 (空・観客席・トラック・土のフィールド)。1896/1904/1930 で色味だけ変える
  2. `VitrineWall` = 博物館の展示壁+展示台+キャプション板 (メダルを置く床)
  3. `DeskPaper` = 机に広げた図面紙 (方眼はこの紙に clip する)。定規・鉛筆・コンパスを添える
  4. `NightHall` = 式典会場 (緞帳・絨毯)。#113/#114 の頂点はここ
- 地面はベタ1色にせず、必ずトラックの白線・大理石の目地・絨毯の毛足・埃を一段敷く。

## 6点法の確認 (①寄る ②世界を置く ③部品を作り込む ④カメラが動く ⑤事件を起こす ⑥人が反応する)

- ①寄る: #104 (トラックへ寄る)・#110 (メダルの断面に寄る)・#114 (「2」が画面を占める)
- ②世界を置く: 全20枚に床 (競技場/展示壁/図面紙/式典会場/雪) を敷いた。素肌0枚
- ③部品: `Medal` の縁のギザ・リボンの織り・`Podium` の木目と天板・ストップウォッチの目盛り
- ④カメラ: #103→#104 で zoomAt がトラックへ降りる。#113→#114 で暗転が進む
- ⑤事件: #104 テープが切れる・#106 X が落ちる・#113 1が退く・#114 2が立つ・#119 台が組み上がる
- ⑥人が反応: #104 観客が立つ・#106 どよめく・#107 不思議そうな顔・#116 うつむく・#122 乗る

## 炎上回避のチェック

- #110 の金は**金張りの銀**。断面で層を見せ、純金の塊に描かない
- 選手を茶化さない。#116 の「惜しかった人」は**静かに**描く (泣き顔にしない)
- #113/#114 で結びのオチ (銅>銀) を**出さない**。「2位が発明された」までで止める
- 実在の選手名・国名・具体的な記録の数字は出さない (伏字と記号だけ)
