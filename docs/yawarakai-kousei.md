## 全体の背骨

**人類が好きなのは「柔らかさ」ではなく「抱かれること」。柔らかいものは、その代わりとして20万年かけて磨かれてきた。**

**柔らかさには最初から2つの役割がある: 体を守る (痛くない・負担が少ない) と、心を落ち着かせる (抱っこの代わり)。** (2026-11-19 作者指示で追加)
- 体を守る: 第1章 (草の寝床=地面から体を守る) → 第3章 (首を休める) → 第9章 (NASAの低反発・ドクターグリップ) → 第10章前半 (床ずれ・筆記の痛み)
- 心を落ち着かせる: 第6章 (竹夫人) → 第7章 (ハーロウ) → 第8章 (移行対象) → 第10章後半 (モノの抱っこ)
- 結びで2本が合流する: 握る理由は「手を守るため」と「心を落ち着かせるため」。体の理由はかなり確か、心の理由は「たぶん」

構成の型は **「柔らかさの出世と転落」**: 寝床 (生活必需品) → 高級品 (ローマ) → 悪徳 (中世の聖人) → 抱き相手 (竹夫人) → 正体判明 (ハーロウ) → 大量生産 (近代) → 手のひら (スクイーズ)。
裁定者ではなく観察者。「柔らかいものに頼るのは弱さか」を断罪も擁護もしない (中世の聖人も笑い者にしない)。

### 抽象軸「からだの地図」(同じ図が育つ)

**人の体の正面図** (棒立ちではなく、少し丸まった姿勢) を全編で使い回し、時代ごとに **柔らかいものが触れている場所が1カ所ずつ光る**。
saigomade回の「客席が1段ずつ暗くなる」と逆に、今回は **光る場所が体の下から手のひらへ登っていく**。リキャップ挿入箇所は5つ:

1. 第1章末: 「最初の柔らかさは、背中の下にありました」(背中が光る)
2. 第3章末: 「ローマでは、首の下に来ました」(首が光る。プリニウスの「首を休められない」を回収)
3. 第5章末: 「聖人は、首の下から柔らかさを追い出しました」(首の光が一度消える。ただし同時代の遺言の羽毛ベッドで背中は光ったまま)
4. 第6章末: 「柔らかくなくても、人は腕の中に何かを入れたかった」(腕と胸が光る。竹夫人)
5. 結び: 第9章で全身が光ったあと (ヨギボー)、**最後に光が手のひら1点に縮む** (スクイーズ)。全回収

## 仕掛け (この回だけの武器) — 「本当に欲しかったもの」を伏せて運ぶ

序で「人類が本当に欲しかったのは、柔らかさではなかったのかもしれない」とだけ言い、**答え (抱っこ) は第7章まで言わない**。

1. **第6章** (竹夫人): 硬い竹なのに「夫人」と名づけ、恋人のように詩に詠み、父のものは子に譲らず燃やす → 「柔らかさでないなら、何を抱いていたのか」で引く

3. **結び**: スクイーズ = 抱っこが手のひらサイズまで縮んだもの (比喩として言う。科学の説明にしない)

## 炎上回避 (レポート「★台本に書いてはいけないこと」の遵守)

- **C触覚線維でスクイーズを握る快感を説明しない** (手のひらにほぼない)。第8章で使うのは頬ずり・毛布・撫でられる場面だけ。第10章で「握る気持ちよさの仕組みはよくわかっていない」と言う

- 20万年前の寝床を「柔らかさを求めた」と言わない。「虫よけ」は推測と添える。「世界最古」と言わない (「今わかっている中で最古級」)
- パジリクの白鳥を「ぬいぐるみ」「おもちゃ」と言わない (自分から「おもちゃではない」と言う)
- 「中世の人は柔らかさを恐れた」と言わない。主語は修道士・聖人・道徳家。同時代の羽毛ベッド人気と必ずセット
- 竹夫人は「涼むための道具」と明言してから傍証に使う。漢の武帝の起源譚は使わない
- **だっこちゃんは使わない** (2026-11-19 作者判断で外した。初代の絵が描けない・差別表現の経緯に触れると本筋から外れる・「硬くても抱く」は竹夫人と役割がかぶる)
- 人をダメにするソファ=無印良品の「体にフィットするソファ」。ヨギボーと混同しない (ソファが先)
- 体の負担 (研究ノート05): ドクターグリップの「医師の協力」は二次資料のみ → 「とされます」。累計販売本数は出さない。「90年代のゲルグリップブーム」と言わない (90年代は太軸ラバー、ゲルは2003年〜)
- 「柔らかいほど体に良い」と言わない (腰痛は中くらいの硬さ、床ずれは体に沿う形が効く)。「柔らかいと力が減る」と言わない (工具の研究では増えた)。言うのは「痛くない・負担が分散する」
