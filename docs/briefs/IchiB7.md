## 第16条「作り込みの床」この章での敷き方

- 素の方眼 + クリーム地だけの絵は **0枚**。
- 図の床は4種類だけに絞って使い回す:
  1. `PressHall` = 新聞社の工場 (鉄骨の梁・輪転機・紙ロール・床のインク染み・吊りランプ)
  2. `Kokugikan` = 国技館の内部 (格天井・吊り屋根・幟・桟敷)。#126〜#128・#131
  3. `EditorDesk` = 編集机に広げた校正紙 (方眼はこの紙に clip する)。活字ケース・インク壺・ペン
  4. `MeijiStreet` = 明治の街 (煉瓦の建物・電信柱・瓦屋根・看板)。#125・#137
  5. ★2026-11-08 追加: #141 の**博物館の陳列室** (`MUS`) と #142 の**夜明けの平野** (`DAWN`)。
     この2つは #141/#142 専用。古地図の床 (`OldMapMarks`) は廃止した
- 地面はベタ1色にせず、必ず床板の目地・インクの染み・土間の斑・紙片を一段敷く。
- **イラスト内の情報は y≤830 に置く** (字幕帯の上端は 2行で y≈854)。
