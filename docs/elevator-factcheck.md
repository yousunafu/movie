# エレベーターは上と下の値段をひっくり返した、史実が支える範囲

調査日: 2026-11-02。台本執筆前のファクトチェック。判定は A=断定可 / B=「〜とされる」で使用可 / C=使用禁止。

**結論: 中核テーゼ「エレベーターは上と下の値段をひっくり返した」「エレベーターは乗り物ではなく不動産の装置」は、都市と時代を特定して語れば史実に耐える。** 「最上階が最安」側は19世紀パリの屋根裏使用人部屋 (chambre de bonne)・NYのウォークアップで裏付けが強く、「逆転」側は1920年代NYのペントハウス誕生 (建築家 Emery Roth、1925年の法改正) で年代まで特定できる。学術的裏付けには Andreas Bernard『Lifted: A Cultural History of the Elevator』(NYU Press) が立てられる——垂直ヒエラルキーの逆転がまさに同書の主題。クライマックスのオーチス実演も1854年NY万博 (バーナム興行) で裏付けられ、**「安全装置の発明者ではなく、公開実演で大衆に信用させたのが功績」という筋は学術的にも支持される**。ただし要注意が3つ: **①ロープを切ったのは本人ではなく助手とする資料が優勢** (絵の構図に直結)、**②「スカイツリーが日本最速」は誤り** (最速は横浜ランドマークタワー)、**③「日本初のオフィスビル用エレベーター」という表現は根拠薄弱** (日銀1896年は荷物用)。23項目の分布は **A=13 / B=8 / C=2** で、企画は成立する。※同日追補: 20分尺化で「ボタンとドア」章を追加し (24)〜(29) を検証、計29項目。

## 中核テーゼの判定 — 「値段の逆転」は年代・場所つきで語れる

テーゼを分解すると「①エレベーター以前、上の階ほど安かった → ②オーチスが安全を信用させた → ③上の階が最高額になり、都市が上に伸びた」となる。

①は19世紀パリで確実。最上階の屋根裏は使用人部屋 chambre de bonne で、格式が最も高いのは2階 (étage noble) ([Wikipedia: Chambre de bonne](https://en.wikipedia.org/wiki/Chambre_de_bonne) / [99% Invisible](https://99percentinvisible.org/episode/576-chambre-de-bonne/))。NYのウォークアップでも「高層の上部は低家賃ゾーンで、富裕層は低層階を好んだ」([Ephemeral New York](https://ephemeralnewyork.wordpress.com/2014/05/16/how-new-york-city-invented-the-penthouse/))。**注意: 1階は店舗・騒音で別扱いの都市があるため、「2階が最高・最上階が最安」の構図で語ると正確。** ヒキの「百年前まで、最上階は一番安い部屋でした」は、直後に「いちばん良い部屋は2階でした」と続けると嘘がない。

③の逆転は**1920年代のニューヨーク**で特定できる。屋根裏は「ペントハウス」と名を変え、1925年の法改正でペントハウス居住が本格化 ([HGTV](https://www.hgtv.com/lifestyle/real-estate/penthouse-101-the-history-behind-the-pricey-real-estate))。「鉄骨構造とエレベーターの両輪が超高層を可能にした」は建築史の標準的見解 ([Village Preservation](https://villagepreservation.org/2021/03/23/the-technological-breakthrough-in-our-midst-that-allowed-buildings-to-grow-tall/))。推奨の言い回し: 「1920年代のニューヨークで、屋根裏は『ペントハウス』と名を変え、最上階が最高額になりました」。

## 項目別判定 (1)〜(8): 西洋史

**(1) 「普及以前は最上階が最安」 — B (都市を特定すれば実質A)。** 上記の通り。「世界中どこでも」とは言わず「19世紀のパリやニューヨークでは」と都市を付ける。

**(2) オーチスの実演 — 年はA (1854年)、台詞はB、「本人が斧で切った」はC。** 会場はニューヨーク万国博覧会 (NY Crystal Palace、1853年開幕) だが、**実演はP.T.バーナム興行下の1854年** ([Otis社公式](https://www.otis.com/en/us/our-company/history) / [Britannica](https://www.britannica.com/biography/Elisha-Otis))。オーチス本人は台上に乗り、**ロープを切ったのは助手** ([American Heritage](https://www.americanheritage.com/all-safe-gentlemen-all-safe))。斧は定番の描写だが道具を特定する同時代記録は確認できず。名台詞 "All safe, gentlemen, all safe" は広く引用されるが同時代記録での実証は未確認——「『皆さん、ご安心を』と言ったと**伝えられています**」の形で。**絵の構図への影響大: 台の上のオーチス + 下でロープに斧を構える助手、の2人構図が正しい。** なお「あのバーナム (『グレイテスト・ショーマン』の) の興行だった」はユーモア素材として使える。

**(3) 安全装置の仕組み — A。** 荷馬車用ばね (wagon spring) + ラチェット。通常はロープの張力がばねを押さえており、ロープが切れて張力が消えるとばねが開き、爪が両側レールの歯に噛んで停止 ([Elevator Museum](https://theelevatormuseum.org/otis.php))。台本予定の説明「ロープが切れるとばねが開いて爪がレールに噛む」はそのまま使える。

**(4) 「安全装置はオーチスの発明ではない。信用させたのが功績」 — A (この回の背骨として安心して使える)。** 鉱山用に1807年 Prior の装置、1840年代 Fourdrinier の特許などが先行 ([PDHonline](https://pdhonline.com/courses/m541/m541handout.pdf))。「足りなかったのは装置ではなく、信じる気持ちだった」は史実に合う。

**(5) 1857年 Haughwout Building — A (限定句つき)。** 1857年3月23日、NYブロードウェイの5階建て百貨店に設置 ([Wikipedia](https://en.wikipedia.org/wiki/E._V._Haughwout_Building))。駆動は**蒸気** (油圧とする記事は誤り)。「世界初の乗客用」と裸で言わず「**世界初の安全装置付き乗客用エレベーター**」と言う。

**(6) 電動の最初 = ジーメンス1880年 — A。** マンハイムの博覧会で公開。約2か月で8,000人以上を約20mの高さへ ([ETHW](https://ethw.org/The_Electric_Elevator))。

**(7) ペントハウスの誕生 — A寄りのB。** 1920年代NY。上記テーゼ判定参照。

**(8) 冒頭用の逸話 — ヴェルサイユA / コロッセオA / アルキメデスB。** ①1743年ヴェルサイユ: ルイ15世が**愛人の部屋へ通うため**の私的昇降機「空飛ぶ椅子」。動力は煙突内の係員の人力 ([Live Science](https://www.livescience.com/57282-elevator-history.html))——ユーモア素材として最強。②ローマのコロッセオの猛獣用昇降機は考古学的裏付け・復元実験ありで断定可。③アルキメデスの巻上げ機は「ウィトルウィウスの記述によれば」を付ければB。

## 項目別判定 (9)〜(14): 日本史

**(9) 浅草・凌雲閣 (1890年) — A (「電動式」の限定語が必須)。** 「**日本初の電動式エレベーター**」は日本エレベーター協会が「エレベーターの日」(11月10日) の由来として公式認定 ([日本エレベーター協会](https://www.n-elekyo.or.jp/encyclopedia/history/elevator.html))。1890年11月10日完成、設計は藤岡市助 (後の東芝の源流、「日本のエジソン」)。**1階から8階まで** (12階建てだが上までは行かない)。運転停止はB: 「故障が相次ぎ、安全性を理由に**当局の命令で**わずか半年で運転中止になった**とされています**」(「警視庁が」と断定する一次資料は未確認)。凌雲閣の最後はA: 1923年関東大震災で8階より上が崩壊し、同年9月23日に**陸軍工兵隊が爆破解体** (映像現存: [関東大震災映像デジタルアーカイブ](https://kantodaishinsai.filmarchives.jp/clips/m01_047.html))。**物語として美味しい対比: オーチスは「信用させて」始まり、凌雲閣は「信用を失って」止まった。**

**(10) 凌雲閣以前の昇降装置 — B。** 1842年、水戸・偕楽園の**好文亭に徳川斉昭が設けた手動の配膳用昇降機** (現存)。「日本最初の昇降機は実は江戸時代。食事を運ぶ手動のリフトだった**とされています**」。歌舞伎のセリ (人力の舞台昇降) も導入ネタに使える。

**(11) 「日本初のオフィスビル用エレベーター」 — C (この表現は使用禁止)。** 確実な事実に言い換える: **1896年、日本銀行本店にオーチス社製の水圧式・貨幣運搬用 (荷物用) エレベーターが設置され、これが輸入第1号** (分速30m)。「本格的なビルへの導入は1896年、日本銀行。アメリカ・オーチス社製の輸入第1号でした——運んだのは人ではなくお金です」まで言えばユーモアにもなる。

**(12) 百尺規制と霞が関ビル — A。** 1919年市街地建築物法で高さ100尺 (約31m) 制限 → 1950年建築基準法に継承 → **1963年改正で容積率制導入・絶対高さ制限撤廃** → **霞が関ビル (1968年、36階、147m) が日本初の超高層ビル** (三井不動産公式も使う表現) ([土地総合研究所](https://www.lij.jp/html/jli/jli_2008/2008winter_p051.pdf) / [三井不動産](https://www.mitsuifudosan.co.jp/corporate/news/2018/0411/download/20180411.pdf))。小ネタ: 搭載エレベーターは日立製・分速300mで当時国内最速。

**(13) 地震時管制運転 — 仕組みA / 導入1970年代A / きっかけの地震はB。** 「**P波 (初期微動) を感知し、S波 (主要動) が来る前に最寄り階に停止して扉を開ける**」は三菱・日立の公式解説どおり ([日立ビルシステム](https://www.hbs.co.jp/products/elevator/disaster/earthquake/eq_operation.html))。1972年に日本エレベーター協会が耐震設計指針を制定し採用を推奨 → 1978年宮城県沖地震を受け1981年に建設省指針 → **2009年施行の法改正で新設機に設置義務**。「1968年十勝沖地震がきっかけ」は裏取りできず使わない。※「直下型では間に合わないことがある」と一言添えると誠実。

**(14) 現代日本の数字 — スカイツリーA / ハルカスA / 「スカイツリーが日本最速」はC。** 東京スカイツリー: 東芝製、**分速600m・40人乗り**。あべのハルカス: 三菱製、**分速360m、16階→60階を約50秒**。**日本最速は横浜ランドマークタワー (三菱製・分速750m)**——スカイツリーを最速と言うと誤り。麻布台ヒルズは確証ある数字が取れず、使うなら要追加確認。

## 項目別判定 (15)〜(23): 仕組みと現代技術

**(15) 「天秤」の核心説明 — B (一語だけ調整)。** おもり=「かご自重+定格積載量の約50%」は業界標準 ([日本エレベーター協会](https://www.n-elekyo.or.jp/encyclopedia/mechanism/elevator.html))。積載が半分のとき釣り合う設計。「天秤」「つるべ式」の比喩は協会・メーカー解説でも常用され許容範囲。ただし摩擦・加減速のぶんもモーターは働くので、**「差額のぶんだけ」→「主にその差のぶんだけ」**に。駆動は綱車とロープの摩擦 (トラクション) であることに一言触れると堅い。

**(16) 「ロープは全部切れない」 — A。** 建築基準法施行令で安全率10以上・複数本 (実製品は3本以上が標準)。「**ロープは1本でも満員のかごを支えられる強さで、それが何本も張られています**」と断定可。「落ちる事故はほぼ起きない」もOK (「絶対」とは言わない)。

**(17) 調速機 (ガバナ) — B (オーチスとの関係の言い方に注意)。** 正確な流れ: ガバナロープで速度を監視 → 定格の約1.25倍で電源遮断 → 約1.4倍でロープを掴み、非常止めがレールを掴んで停止。「遠心力でおもりが開く」は正しい。**オーチスの装置 (切れたら止まる) と現代の調速機 (速すぎたら止まる) は方式が違う**ので、「進化した子孫」とは言えるが「同じ仕組み」はC。

**(18) 世界最速 — A (条件つき)。** 広州周大福金融中心の**日立製・分速1,260m (時速75.6km)、2019年ギネス認定**で2026年現在も最速 ([日経](https://www.nikkei.com/article/DGXLRSP520137_X20C19A9000000/))。2位は上海タワーの三菱電機製 (分速1,230m)。**「世界1位も2位も日本メーカー」と断定可。** ただし通常運転は分速1,200mなので「試験で記録した最高速度」と添える。

**(19) 現代技術の小ネタ — おおむねA。** 回生電力 (三菱「エレチャージ」で消費電力約25%削減)=A / AI群管理 (三菱ΣAI、省電力割当で最大10%削減)=A / 機械室レスが新設の主流=A / KONEのカーボンロープ UltraRope (鋼鉄の約1/5の軽さ)=A / ロープレス・リニア駆動 (TK ElevatorのMULTI) は**商用実績ゼロ**なので「研究中」としてならB。

**(20) 「超高層の限界はロープの自重」 — B (数字に注意)。** 長くなるとロープ自身の重さが支配的になる構図は事実。ただし「500mが限界」はKONEの宣伝由来の数字で、上海タワーは鋼系ロープで昇降行程578mを実現済み。推奨: 「鋼鉄のロープは、およそ500〜600mで自分の重さが限界に近づく。だから軽い新素材の出番」。

**(21) 鏡の逸話 — B (逸話扱い必須)。** 「待ち時間の苦情に、鏡を置いたら苦情が止んだ」は経営学の有名な逸話だが一次資料は未確認 ([検証記事](https://mdalmijn.com/p/why-do-all-elevators-have-mirrors))。「——という有名な話があるほど、エレベーターは退屈との戦いです」の形なら使える。断定テロップは不可。

**(22) スカイロビー方式・ダブルデッキ — A。** 「超高層は電車と同じ。急行 (シャトル) に乗って途中で乗り換える」の比喩は正確。かご2階建てのダブルデッキも確実。

**(23) 「天守に殿様が住んでいた」 — 俗説。使うなら逆向きに。** 実際に天主に住んだのは**織田信長 (安土城) がほぼ唯一**とされる ([城びと](https://shirobito.jp/article/300))。「日本には『上に住むほど偉い』は、もともと無かった。天守に本当に住んだ殿様は信長くらい**だとされています**」——日本章の導入として使うと面白い (B)。

## 追補 (同日): 20分尺化にともなう「ボタンとドア (運転手がいた時代)」章の判定 (24)〜(29)

20分尺への拡張で追加した章のぶん。**この章の収穫: 「技術はあったのに信用が追いつかなかった」がオーチス1854年と1945年以降の自動化で2回起きている——動画の背骨がこの章で2本から3本になる。**

**(24) 運転手がレバーで操縦し、階にぴったり停めるのは熟練の技 — A。** 操作装置は「カースイッチ」と呼ばれるレバー式。床と水平に停めるには熟練とタイミング感覚が必要だった ([Elevator World](https://elevatorworld.com/article/the-history-of-operatorless-elevators-traffic-control-systems-part-one/) / [Wikipedia: Elevator operator](https://en.wikipedia.org/wiki/Elevator_operator))。1920年代にオーチスが自動着床を導入した経緯も裏付けあり。「レバー」で断定可。

**(25) 1945年NYのエレベーターストライキ — 実在はA、数字と因果はB。** 1945年9月24日開始。オペレーター含むビル労働者**約1万5千人**がスト、マンハッタンの商業地区がほぼ麻痺、150万人が出勤不能・損失1億ドル超と報じられ、約1週間で州知事介入の仲裁で終結 ([Time 1945年記事](https://time.com/archive/6772639/national-affairs-elevators-not-running/))。人数・損失額は資料でぶれるため「約1万5千人」「1億ドル以上といわれる」で。**「このストが自動化普及の転機」はB**: NPR等が tipping point と報じる ([NPR: Remembering When Driverless Elevators Drew Skepticism](https://www.npr.org/2015/07/31/427990392/remembering-when-driverless-elevators-drew-skepticism))。推奨: 「このストライキが、無人エレベーターの普及を一気に後押ししたといわれています」。

**(26) 自動化の技術は50年前からあった — A。** 1892年に押しボタン制御の特許出願、1894年実用化 (当初は住宅用)。本格的な無人運転 Otis「Autotronic」は1948年発表・1950年ダラスに初設置、1956年には主要ビルが争って導入 ([Otis公式](https://www.otis.com/en/us/our-company/history) / [FundingUniverse](https://www.fundinguniverse.com/company-histories/otis-elevator-company-inc-history/))。**「ボタンはストライキの50年以上前に発明されていた」と断定可。**

**(27) 乗客が無人の箱を信用せず、安心の工夫で普及 — B (報道レベルの裏付けあり)。** 乗客が乗るのを拒んだこと、業界が子供や老人を乗せた広告キャンペーンを打ったこと、非常停止ボタン・非常電話・録音音声 (「階数ボタンを押してください」— Otis Elevoice は有人時代から先行搭載して慣れさせた) で信頼を獲得したことを NPR (Planet Money, 2015) 等が報道。推奨: 「人々はなかなか乗ろうとしなかったといわれています」。※この話の出典は **99% Invisible ではなく NPR/Planet Money** (取り違え注意)。オーチス1854年との対比構成は解釈なのでそのまま使用可。

**(28) ドアの安全史 — B (段階で語る)。** 初期は手動ドアでシャフト転落事故が「相次いだとされます」。機械式セーフティシュー (挟まれると再び開く) → 光電セル式 (Westinghouse「Safe-T-Ray」等) → 現代の多光軸ライトカーテン、という流れは業界誌の特集で裏付けあり ([Elevator World: Door Reversal Devices 1930-1960](https://elevatorworld.com/article/door-reversal-devices-1930-1960/))。個別の発明年は断定を避け「自動ドア化とともに、挟まれると開く装置、やがて光のセンサーへ」と段階で。

**(29) 閉ボタンのプラセボ — 米国側A、日本側B。** NYT 2016年10月27日の記事が実在: ADA (1990年) 以降に設置された米国の乗用エレベーターでは、閉ボタンは通常運転時には無効 (消防運転では機能)。業界団体幹部の証言付き ([Mental Floss (NYT引用)](https://www.mentalfloss.com/transportation/do-close-door-buttons-elevators-actually-do-anything) / [NY1](https://ny1.com/nyc/all-boroughs/news/2018/07/03/a-closer-look-at-nothin-buttons-in-new-york-city-buttons-that-do-not-do-anything))。日本では主要メーカーとも閉ボタンは実際に機能する仕様で対比は成立するが、網羅調査はないため「日本では、ちゃんと働きます」程度の軽い言い方で。

## 追補2 (同日): エスカレーター分岐ミニコーナーの判定 (30)〜(32)

**(30) 「エスカレーターは遊園地の乗り物として生まれた」 — B (骨格は強い、年と人数に幅)。** ジェシー・リノがコニーアイランドに娯楽用の「傾斜エレベーター」を設置したのは複数資料で裏付けあり。ただし時期は**1895年9月説 (ギネス) と1896年説 (Wikipedia・Hagley博物館) が不一致** → 「1896年ごろ」。「2週間で約7万5千人」は推定扱い → 「〜と伝えられています」。シーバーガー+オーチスの試作機が**1900年パリ万博で一等賞**はA ([Hagley Museum](https://www.hagley.org/research/news/hagley-vault/march-15-1892-american-inventor-and-engineer) / [Guinness](https://www.guinnessworldrecords.com/world-records/first-escalator))。

**(31) 「エスカレーターは元商標 → 普通名詞化」 — A。** シーバーガーが1900年に商標登録、後にオーチスへ譲渡。**1950年の Haughton Elevator v. Seeberger 審決で generic と判定され登録取消** ([審決本文](https://www.pastpaperhero.com/resources/haughton-elevator-co-v-seeberger-85-uspq-bna-80-commr-pat-1950) / [Jones IP](https://www.jonesipl.com/article/genericide-the-story-of-escalator/))。決め手は**オーチス自身がカタログで小文字で使っていた**こと (ユーモア素材)。アスピリン・セロファンの例えは正確だが、アスピリンはドイツ等では今も商標なので「**アメリカでは**」の限定必須。

**(32) 「少人数を高く vs 大人数を低く」の棲み分け — A (数字は幅で)。** ハロッズ1898年設置機に「毎時3,000人」の同時代記録。現代も毎時数千人の連続輸送でエレベーターの約10倍とされる。百貨店の採用は**店名を出すならハロッズ (1898年) が安全** (メイシーズは年代説が混在)。**日本初は1914年3月8日・東京大正博覧会 (上野) が先で、三越日本橋店は同年秋の「百貨店初・常設初」。三越を「日本初」と言うのはC** ([ブルーバックス編集部](https://gendai.media/articles/-/79938))。
