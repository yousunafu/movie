舞台 = 江戸の町。トーン = 笑いの山③・テンポよく。

## 第16条「作り込みの床」この章での敷き方

- 素の方眼 + クリーム地だけの絵は **0枚**。
- 図の床は3種類だけに絞って使い回す:
  1. `WashiSheet` = 机に広げた和紙 (方眼はこの紙に clip する)。硯・筆・文鎮を添える
  2. `EdoWall` = 土壁+板壁+柱+貫。軒下の影と埃
  3. `EdoRoofs`+`EdoSky` = 瓦屋根の遠景と空 (屋外の床)
- 地面はベタ1色にせず、必ず石畳の目地・土の斑・草・下駄の跡を一段敷く。
