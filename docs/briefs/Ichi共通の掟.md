## 1. この動画の背骨 (全章で一本に通す)

> **「勝ちたい気持ちは本能。でも『1位』という仕組みは発明品。だから、作り変えられる」**

順位が意味を持つには「土俵」が要る。成立条件は3つ: **①同じ共同体 ②統一された物差し ③記録して公表する誰か**。
この土俵が人類史で広がっていく一本線で貫く:

**戦場ひとつ (一番槍) → 帝国 (科挙) → 江戸の町 (番付) → 国 (新聞と甲子園) → 世界 (金銀銅) → 同学年の全国民 (偏差値) → 地球全員 (SNS)**

態度は**裁定者ではなく観察者**。「競争は良いか悪いか」は言わない。「この仕組みはいつ誰が作ったのか」だけを描く。

### 抽象軸「育つ土俵マップ」(同じ図が育つ演出)
同心円の図 (中心に小さな人、まわりに「比べる相手の輪」) が節目ごとに1段ずつ広がる。
**序#15 に初出・第2章末 (#47) で1段目**。既出の図なので、**必ず序#15 と第2章#47 の絵を読んでから描く** (IchiB0.tsx の `i_dohyo_map`、IchiB2.tsx の `ib2_dohyo_chiisai`)。輪が広がる以外の部分は変えない。

| 回 | どこ | 言うこと |
|---|---|---|
| ① | 第2章末 #47 (済) | 輪は、まだこんなに小さかった (戦場ひとつ) |
| ② | **第4章末** | 輪は、国の大きさになりました |
| ③ | **第7章末** | 戦場ひとつから帝国へ、町へ、国全体へ。しかも毎年更新 |
| ④ | **第8章末** | 同じ年に生まれた全員が、同じ一本の物差しに乗った |
| ⑤ | **結び** | 輪は地球サイズに。井の中の蛙、ただし池は地球 |

### 裏主人公は「2位」(3点で回収する仕掛け)
1. **序 (済)**: 古代オリンピックに2位の記録はない = 2位は存在しなかった
2. **第6章**: 1904年の金銀銅で**2位が発明される**。「発明されたのは1位ではありません。2位です」
3. **結び**: 銀より銅のほうが幸せそうに見える。**発明されたばかりの2位が、いちばん苦しかった**

**オチ (銅>銀・順位をやめた3実例) は結びまで絶対に出さない。** 途中の章で先出ししない。

## 2. 絵の「格」と配分 ★2026-11-06 改定

| 格 | 中身 | 行数の目安 | 配分 |
|---|---|---|---|
| **山** | 舞台・人・事件・カメラ全部入り。6点法フル適用 | 150〜250行 | **3割** |
| **並** | 舞台はあるが描くのは1つだけ。人は1人、背景3〜4要素 | 60〜120行 | **3割** |
| **図** | 図と札が主役。ただし下の第16条の床を敷く | 50〜120行 | **4割** |

**山3 : 並3 : 図4**。山を置く位置は決まっている — **章扉 / 新しい物の初登場 / 事件が起きる文 / 軸 (土俵マップ) に触る文 / 章の結び**。

### ★第16条「作り込みの床の法 (素肌禁止)」— 今回いちばん大事
作者の言葉: 「方眼背景はやっぱり味気ない」「こっちの方がいいなぁ。ルール作りが甘かった」

- **素の方眼 (GridPaper) + クリーム地だけの絵は禁止 (担当章で0枚)**。方眼を使うなら「何かの紙」(掲示板・和紙・絵巻・新聞・答案) の上に clip して載せる
- 全シーン、主役を**世界の中に置く**。どこで起きているかが1秒で分かる舞台を敷く
- **地面や壁が素のベタ1色で広く残っていたら未完成。** 小物・質感 (小石・草・足跡・板目・棚の中身・観客シルエット・遠景) を一段敷いてから出す
- 図でも世界を敷く。実例: 第1章のグラフは「砂地に枝で引っかいて描いた線」、序の年表は「広げた絵巻の上」
- **ただし主役の明快さが最優先。** 背景は彩度低め・線細め・opacity 控えめ。ごちゃごちゃは失敗
- 密度の手本は `KosoB0.tsx` (約170行/シーン)。**行数は結果であって目的ではない**

### 6点法 (絵が「遠い・簡素・退屈」になるのを防ぐ)
①寄る ②世界を置く ③部品を作り込む ④カメラが動く ⑤事件を起こす ⑥人が反応する。
**設計書を書いた時点で、1文ずつこの6つを確認する。**

## 3. 作風の決まり (破ると検査に落ちる)

- **1文 = 1シーン = 1枚の絵。** 骨組みファイルに `S48` のような空の関数が文の数だけ並んでいるので、そこを埋める
- **必ず `f` で動く。静止画は禁止。** `seg(f, a, b)` の **b は 42 以下** (検品プレビューは f=45 の瞬間を写すため)
- **札 (TagPlate) の下端 = y + size*0.85。これを 830 以下にする** (下の字幕帯に隠れるため)
- **絵の中の文字はラベル・数値・標識だけ。** 台本の文章は字幕が別レイヤーで出るので、絵に文を書かない
- **札の読点の法**: 札・章扉タイトルに読点「、」を使わない。間は半角スペース (例: ❌「サイン、たのむ」→ ⭕️「サインたのむ」)。台本に読点があっても絵では抜く
- **被りゼロ**: 札・軸ラベル・吹き出しが人物・イラスト・他の文字・字幕帯に重ならない。レンダ後に拡大して必ず確認する
- **連番で同じ物を映すときは絵を複製しない。** 1つの部品に `phase` prop を持たせて切り替える
- **motif 名・seed の範囲・SCENESキー・export 群は骨組みのまま変えない。** motif 名だけは仮名 (`ib3_s048`) なので**意味のある名前に直してよい** (ただし接頭辞 `ib3_` は維持し、`SCENES` と `I_B3_MOTIFS` の両方を揃えて直すこと)

### 人物部品 (2026-11-06 に強化済み。これを使う。腕を手描きで足さない)
`KarakuriScenes.tsx` の `Person`:
- `pose`: "stand" | "banzai" | "raise" | "point" (+`pointDir`) | "armsFolded" | "run" | "hold"
- `face`: 既存4種 + "joy" (大笑い) / "angry" / "sad" (涙)
- その他: 服の色・ヘルメット・メガネ・髪・視線・たすき・傾き

`PersonMini` (群衆用の簡略キャラ。縮めても潰れない): `x, y, s, color, f, phase, face("dot"|"smile"|"none"), arms("down"|"up")`
→ 観客・群衆・受験生の列などは必ずこれを並べる。

**人物の画風は共通部品から流用する。章ごとに新しい画風を作らない。**

## 4. 炎上回避 (事実確認済みの言い回し。絵でも破らない)

- 科挙の開始は「隋の時代」とぼかす。「世界最初の実力主義制度**とされる**」
- 箱根駅伝 = **報知新聞** (読売と書くのは誤り)。都市対抗 = 東京日日 (現・毎日)。優勝額 = **時事新報社**
- 偏差値「世界で日本だけ」は誤り。「ここまで浸透したのは日本独特**とされます**」まで
- 天下一禁止 (1682) は事実のみ。「幕府が競争を嫌ったから」という動機を絵でも断定しない
- **知能検査・IQは出さない** (前作の主役なので。ケトレー→偏差値は統計の線だけで通す)
- 相対評価廃止 (2002) を善悪で描かない。ゆとり教育論争に触れない
- 順位が好きな人・受験生・アスリートを**絵で茶化さない・断罪しない**
- 1904年の金は「純金ではなく金張りの銀」。絵で純金の塊のように描かない

## 5. 進め方 (この順番で)

1. **まず読む**: 自分の担当範囲の台本 (`docs/ichiban-script-v1.txt`) と `docs/ichiban-kousei.md` の該当章の行
2. **手本を読む**: `KosoB0.tsx` を2〜3シーン分 (密度の手本)、`IchiB1.tsx` を2〜3シーン分 (この作品の世界観・第16条を適用済みの実例)、`IchiShared.tsx` (使える部品)、`KarakuriScenes.tsx` は grep → 部分 Read
3. **設計書を書く**: `docs/briefs/IchiB<N>.md` に
   - 冒頭の集計表 — `| **山** | 5枚 |` の形
   - 1文ごとの表 — `| 文番号 | 本文 | 格 | 絵の説明 |`
   - ★この2つが揃っていないと `npm run check` の検査6 が空ぶりする。**必ず両方書く**
   - 格の配分が 山3:並3:図4 に近いか自分で確かめる (許容 山20〜35% / 並20〜40% / 図30〜50%)
4. **描く**: 骨組みファイルの `S48` 等を埋める。共通の舞台部品はファイル内のローカル部品にして使い回す
5. **型チェック**: `npx tsc --noEmit` → エラー0
6. **書き出し**: `npx remotion render src/remotion/index.ts IchiB<N> tmp/ichiban/b<N> --sequence --image-format=png`
   - **単発レンダはファイル名が非ゼロ埋め (element-5.png) になるので、必ず `element-05.png` へ mv して統一する**
7. **検品**: 全枚数を Read で目視 + **札・軸ラベル周辺を拡大して被りゼロを確認**
   - 拡大のやり方: `ffmpeg -y -i element-05.png -vf "crop=700:400:1220:620" zoom.png` (ffmpeg が使えない環境なら `npx tsx tmp/crop.ts` を使う)
8. **札の検査**: `npx tsx scripts/koso-plate-check.ts` → 自分の章の NG が 0 件であること (他章・Koso の警告は無視してよい)
9. **書き出しは2巡まで。**
