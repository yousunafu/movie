## 絶対に守ること

1. **1文 = 1シーン = 1枚の絵。** 増やさない減らさない
2. **札 (TagPlate) の y + size*0.85 を 830 以下にする。** 画面の下には字幕の黒帯 (上端854) が別レイヤーで乗ります。検品プレビューには字幕が出ないので目では気づけません。必ず計算で守ること。**画面の下 1/4 (y>830) に大事な物 (顔・主役・札) を置かない** (床や影はOK)
3. **絵の中の文字は、ラベル・数値・標識だけ。** 台本の文章をそのまま絵に書かない (字幕が出るので二重になる)
4. **必ず `f` で何かが動く。** 静止した絵は禁止。人のまばたき (Person に f を渡す)・物のゆれ・ホコリは最低限で、そのうえで**そのシーンの事件**を動きで起こす
5. **f=45 の瞬間に「その文がいちばん伝わる絵」が出ているように。** 検品プレビューは全シーンを f=45 の瞬間で描きます。主役・舞台・その文の事件の「山場」は f=42 までに見えるようにする。そのあと文の尺 (指示書の各行の「★尺」) の最後まで、動きを続けてよい (くり返し・後日談・カメラの寄り)。尺を超える動きは見えないので組まない
6. 色は `KRP` と `MP` と、自分のファイル上部の `C` にある色だけ。足すなら `C` に足す
7. seed は骨組みに書いてある数字を変えない
8. 対応表 `SCENES` と `*_MOTIFS` 配列、部品名・motif 名は**変えない**
9. **人物は共通部品 `Person` で描く** (からくり憲法第7条)。自分で別の画風の人を描かない。座らせるときは `pose="sit"` (座面の高さ = y − 58×s)。足りない姿勢 (寝そべり等) は Person 全体を `rotate` した `<g>` で包む・腕だけ自分で足す、で作る
10. **主役は画面センター** (第3条)。**物の大きさは現実に合わせる** (第4条)。**場所や時代が変わるシーンは「ここはどこ/いつ」が一目で分かる記号を置く** (第6条: 国旗・地名札・年代札)
11. **変身の演出では変身後に元の物を完全に消す** (第5条)。煙や光で「変わった」と分かる記号を添える
12. **背景キット禁止** (第13条)。同じ背景の上で物だけ入れ替える作り方はしない。1文ごとに舞台・構図・カメラを作る。例外は同じ場所・同じ時間の続き (「#7と#8は同じソファ」など、指示書に書いてある場合だけ)
13. **素肌禁止** (第16条)。無地のクリーム地に物を浮かべない。図の格でも「何かの上」に描く (発掘の土壁・巻物・机・掲示板など)

## 絵の「格」

| 格 | 中身 | 目安 |
|---|---|---|
| **山** | 舞台・人・事件・カメラ全部入り。全力 | 150〜300行 |
| **並** | 舞台はあるが、描くのは1つに寄る。人は1人、背景3〜4要素 | 80〜150行 |
| **図** | 図解が主役。人は置かない。ただし「何かの上」に描く | 50〜100行 |

**「図」「並」も品質は落とさない** (作者: 「シンプルとか普通のやつも絵のクオリティは下げちゃだめ」)。線・色・札・フォントは山と同じ。`strokeWidth` を細くしない。**最悪の失敗は「小さい物を画面の真ん中にポツンと置く」**。主役は短辺 (1080) の半分以上を使う。シンプル＝1つを大きく正確に。

## 使える部品

**`MezaShared.tsx` から** (import 済み)
- `<Frame f={f} seed={…} bg={…}>…</Frame>` — 手描きのゆらぎ+バッジ「目覚ましのからくり」+ホコリ。全シーンの外枠。必ず使う。`dark` を付けると夜向けのホコリ
- `<TagPlate x y text size t color fill rot />` — 白い木札。`t` は 0→1 で出てくる。幅 ≈ text.length*size+40
- `<QMark x y s t />` `<XMark x y s t />` `<Arrow x y s rot t />` `<Maru …>` `<MaruBatsu …>`
- `<ChapterDoor num title t left top width />` — 章の題字 (HTML。Frame の `over` に入れる)
- `W`=1920 `H`=1080 `FONT`

**`KarakuriScenes` から** (import 済み)
- `<Person x y s f face pose cloth clothDark hair helmet glasses gaze lean phase />` — x,y は**足元**。頭の中心は (x, y−228s)・半径64s。頭のてっぺんは y − 292*s。手は (x±67s, y−66s)
  - face: "normal" | "worried" | "surprised" | "smile" | "joy" | "angry" | "sad"
  - pose: "stand" | "banzai" | "raise" | "point" | "armsFolded" | "run" | "hold" | "sit" (sit は座面の高さ = y − 58s) (hold は胸の前で両手。手元 y≈−118s)

## ★この動画だけの決まり (必ず守る)

1. **男女はひと目で分かるように** (作者の注文): 台本や絵で性別に意味がある場面 (ロンドンの女性のノッカー・アップ、工場の男女、家族のお父さんとお母さん、起こされる男性と女性 など) は、指示書の「男女の描き分けの決まり」をそのまま守る。男性=短い黒髪 (hair="cap")・紺/青/灰の服・ズボン、女性=**肩まで届く茶色の長い髪 (左右に垂らす) か後ろで結んだ髪の房**・赤/ピンク/えんじ系の服・**スカート** (昔の女性はくるぶしまでの長いスカート+頭巾かボンネット帽)
2. **メインキャラクター「あなた」は全編同じ姿**: 丸頭の Person・水色のパジャマ (`MP.you`/`MP.youDark`)・短い黒髪。男女の記号は付けない。ほかの人と取り違えないよう、同じ場面に水色の服の別人を置かない
3. **腕は必ず2本**。Person の腕に自分で腕を足すときは、元の腕を pose で隠すか消す (暇の回で腕3本の事故が2件)
4. **実在の人物の顔は描かない**: プラトン・ハッチンズ・MITの大学院生 (女性)・ロンドンの豆鉄砲の女性は**後ろ姿・手元だけ**。名前の出ない一般の人 (修道士・工場の人・町の人・ボルトンの老人) は顔を描いてよい
5. **ロゴ・商品名を描かない**: スマホ・目覚まし時計・会社 (GE・ウェストクロックス・セイコー) のロゴや商標の字は描かない。形と色だけで分かるように。札で「精工舎」「クロッキー」など台本に出る名前を書くのはよい
6. **字幕と同じ文章を絵の中に書かない**。札は「ラベル・年・地名・数字」だけ
7. **数字・事実は指示書に書いてあるものだけ**。自分で足さない。とくに: 鶏は日の出ではなく**夜明け前**に鳴く / プラトンの装置の仕組みは「うわさ・復元」として見せる (断定しない) / 豆鉄砲は一部の人だけ (主流は長い棒) / スヌーズが9分などの俗説は描かない
8. **ユーモアは絵の事件で**: 指示書の笑いどころは、**表情と動きで笑える**ように大げさに。ただし下品・残酷にしない。寝坊を責めて怖がらせる絵 (怒鳴る・叩く) にしない。起こし方はコンコン・つんつん・ジリリまで
9. **目覚まし時計・スマホを悪者に描かない**。光や音はきれいに楽しく

## 進め方

1. 自分の指示書と、自分の担当 .tsx を Read する。次に `MezaParts.tsx` を grep -n "^export" で一覧し、自分の指示書で使う部品だけ Read する (この3つを最初に読む)
2. 骨組みの各シーンの `// どこ: // 演出: // 動き:` のコメントを**先に埋めてから**描く
3. 一気に書く。Edit で `{/* TODO */}` を本物の絵に置き換えていく (シーンを `=> (` から `=> { … return (…); }` に書き換えてよい)
4. 型チェック: `node_modules/.bin/tsc --noEmit`
5. 札の検査: `npx tsx scripts/koso-plate-check.ts <自分のファイル名から .tsx を取った名前> (例 MezaA)` — **NG 0件になるまで直す**
6. 静止画をまとめて書き出す (**1枚ずつ `remotion still` を呼ばない**。必ず先頭で TMPDIR を設定):
   ```
   export TMPDIR="$(pwd)/tmp/remotion-tmp/"; node_modules/.bin/remotion render src/remotion/index.ts MezaAll tmp/meza/<置き場> --sequence --frames=<C1>-<C2> --image-format=png --log=error
   ```
   コマ番号 = 文番号 − 1。出力のファイル名は `element-<コマ番号>.png` (桁数は Remotion が0詰めすることがある。`ls` で確かめる)
7. 全部を Read して自分で検品する: 主役が小さくないか / 物が重なって読めなくなっていないか / 画面の下1/4に大事な物がないか / 人の手足や物のつながりが変でないか / 真ん中にポツンでないか / 素肌 (無地背景) がないか
8. 直して、もう1回だけ書き出して確認する
9. 終わったら、各シーンを1行で説明した報告を返す (400語以内)
