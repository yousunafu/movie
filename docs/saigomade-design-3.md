## この巻の役割
舞台が日本とアメリカへ。**第6章で日本の劇場が陥落 → 第7章で映画館が意外な抵抗 → 第8章でヒッチコックが最後の扉に手をかける**。
第7章は全巻でいちばん明るく楽しい谷間 (常識の反転+視聴者への「ようこそ」)。第8章で再び締まる。この明→暗の往復が緩急の芯。

**語らないもの**: 「サイコ世界初」(#168〜169で自ら否定する)、消防法原因説、幕の内弁当語源。
**語るもの**: 途中入場は客のわがままではなく**劇場側の商品設計**だったこと。「最初から観ろ」の言い出しっぺは**作り手**。

## この巻の注意 (ファクト)
- **「世界初」と絵でも言わない**。トロフィー・金メダル等の「初」を連想させる小物をサイコ側に置かない (#168で自ら否定する構成)
- 立て札の文言は英語圏で記録の残る宣伝文の訳。日本語訳の文言は台本の通りに。勝手に足さない
- 震災 (#124) は引きの構図で、被害の直接描写はしない。労作感より「時代の区切り」として
- 消防法・法規制の小物 (条例の紙など) を入替制の理由として描かない (原因説は未確認)
- ヒッチコックの横顔は本人が宣伝に使った様式。茶化しすぎない (実在人物への敬意、kousei の線引き)
