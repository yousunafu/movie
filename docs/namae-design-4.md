## 共有装置の使いどころ (この巻)
- ★`MeijiLock` (明治の名前の錠前・NamaeParts.tsx): **#115〜#125 で使う同じ装置**。木の板に名札が掛かり、その下に**5つの布告の札と5つの錠前の穴**が並ぶ。`stage` (0〜5) と `t` で何段目まで錠前がかかったかを決める。
  - #115: stage=1 (明治3年 許可の札が光る・錠前はまだかからず、名札の「名字」の部分に許可の判がつく)
  - #118〜#119: stage=2 (明治4年 戸籍)
  - #120: stage=3 (明治5年5月 ひとり1つ)
  - #121: stage=4 (明治5年8月 改名禁止)
  - #122〜#123: stage=5 (明治8年 義務)
  - #125: stage=5 全部かかった姿を引きで
  - 装置の引数は NamaeParts.tsx を Read して確認すること。背景 (明治の役所の部屋・机・窓の外の明治の町) は各シーンで描く
- `Nafuda` + `Ito`: **#129〜#133 (リキャップ③)**。`Nafuda text="山田 花子"`、左に耳の糸 (朱) はすでに結ばれた状態 (第3章で一度切れたが結び直されている)。**#129〜#130 で下の結び目 (chobo) から藍の `Ito kind="chobo"` が伸びて役所の名簿 (帳簿) に結ばれる**。#131 で糸の真ん中に錠前 (`lock` 0→1)。#132 で名札が少し引っぱられて逃げられない (`tension`)。右上に `ItoLegend lit={{ mimi: 1, chobo: 1 }}`
- 第6章では名札の装置は**使わない** (現代の書類・封筒・表札で見せる)。ただし #158 だけ、名札を3本の手 (親・子・国) が同時に持っている絵にしてよい (`Nafuda` を使ってよい)
