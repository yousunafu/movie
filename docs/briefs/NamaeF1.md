## 章扉 (ChapterDoor) の描き方
題字の後ろに薄いクリームの帯を敷く (暗い背景で「第N章」が沈まないように)。Frame の `over` に次のように入れる:
```tsx
over={<>
  <div style={{ position: "absolute", left: 970, top: 536, width: 900, height: 196, borderRadius: 18,
    background: "rgba(247, 242, 226, 0.86)", opacity: door, boxShadow: "0 6px 0 rgba(40,28,16,0.18)" }} />
  <ChapterDoor num={N} title="…" t={door} left={1000} top={560} />
</>}
```
`door` は `seg(f, 4, 20)` などで 0→1。題字が絵の主役に被らないよう、主役は画面の左寄りに置く。

## 前の作品の検品で直したこと (同じ失敗をしない)
- 人の顔や大事な物を画面の下 (y>830) に置いてしまい、字幕の帯にかかった → 足元が y=830 を超えるのはよいが、**顔は y<800** に
- 寝かせた人や置いた物が床から**浮いて**いた → 接地面を合わせる (少し沈める)
- 札の文字が画面の左右の端で**切れて**いた → カメラの寄り (scale) をかけるシーンは、端に文字を置かない
- f=45 の瞬間に、いちばん伝えたい絵が写っていなかった → **f=45 で「その文がいちばん伝わる瞬間」**になるように動きの時間を組む
- 木槌のような道具を毎コマ大きく振り回すと「動きすぎて邪魔」と言われた → 繰り返しの動きは**ゆっくり・小さく** (10〜12コマに1回程度)
- 線だけの生き物 (悪魔など) は「色をつけて」と言われた → 生き物・小物は**必ず塗る**
- 首から下げた名札が花や羽のように見えて意味が読めなかった → 小物は**それが何か一目で分かる形**にする
