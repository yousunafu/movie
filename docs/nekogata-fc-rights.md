## 第1部: 権利関係

### 1-1. 名前を「文字として」言及すること → **A（セーフ）**

**著作権はキャラクター名・作品名に及ばない。**
- ポパイ・ネクタイ事件（最判平成9年7月17日）「具体的な漫画を離れた登場人物のいわゆるキャラクターを著作物ということはできない」
  https://chosakukenhou.jp/character/ / https://www.crefe-law.jp/cr_textbook/303.html
- 「リュカ」事件（知財高判令和6年4月23日）「キャラクターの特定のための符号である限り著作物に当たらない」
  https://www.gojo-partners.com/column-ps/6224/ / https://www.businesslawyers.jp/articles/1398
- 題号も「よほど長いものや創意工夫されたものでないかぎり保護を受けない」
  https://topcourt-law.com/intellectual-property/character-copyright

→ 本文・字幕・タイトル・概要欄に文字で書くのは著作権非侵害。**引用（32条）の枠組みを持ち出す必要すらない**（著作物を使っていないため）。

**商標権**: 効力は「商標的使用」（出所表示としての使用）に限られ、平成26年改正で商標法26条1項6号として明文化。
  https://www.publication.law.nihon-u.ac.jp/pdf/property/property_12/each/06.pdf / https://mpip.jp/jp/blog/202007152262
解説本文での言及は自己の役務の出所表示でないため非侵害方向。
ただし**第41類（娯楽の提供・教育情報の提供）に登録第4819932号（権利者＝小学館集英社プロダクションとされる）の存在が二次情報で示されている（B／J-PlatPat要確認）**。
  https://search.toreru.jp/homes/search/ / https://www.shopro.co.jp/license/title/501/

**不正競争防止法**: 2条1項1号（周知表示混同惹起）。公式と誤認させる態様は **C**。参考＝マリカー事件。
  https://www.inpit.go.jp/content/100871117.pdf / https://innoventier.com/archives/2018/11/7313
YouTube実務解説も「公式と関係があると勘違いさせるサムネイルは侵害事件になり得る」と指摘。
  https://legal.cinnamo.co.jp/YouMag-05.html

### 1-2. アウトになるもの

**「似せる」の境界**: 基準は「表現上の本質的な特徴を直接感得できるか」。表現上の創作性のない部分での同一性は翻案に当たらない。
  https://storialaw.jp/blog/7882 / https://www.businesslawyers.jp/practices/304
実務的には「青い球体＋白い腹＋腹のポケット＋赤い丸鼻＋首の鈴＋ひげ＋耳なし丸頭」の**組み合わせ**で成立しており、3〜4要素揃うと直接感得される。**色替え・鈴外しでは回避できない**（本質的特徴は輪郭と要素構成に宿る）。シルエット・パロディ（タヌキ化等）も避けるべき。パロディは引用要件を満たしにくく個別判断。
  https://www.fuhyo-bengoshicafe.com/bengoshicafe-16632.html

| 経路 | 自動照合 | 権利者の手動申請 |
| 著作権警告(strike) | **発生しない** | **発生する**（3回で停止） |

→ **「名前をタイトルに入れただけでContent ID申し立てが来る」ことは仕組み上あり得ない。** 手動削除通知は誰でも出せるが、著作物を使っていなければ法的根拠がなく通る見込みは低い。

### 1-6. 推奨設計 ★これを守れば実質リスクゼロ

1. **タイトルは「猫型ロボットはいつ生まれるのか」のまま。** 固有名ゼロで全員わかる。これが最良。
2. **サムネイルにキャラの絵・シルエット・パロディを一切置かない。** 実在ロボット図解・年表・数字（「2112年」「あと86年」）で構成。**唯一の実質的リスク箇所なので最も厳しく守る。**
3. 本文は第1章冒頭で1回だけ「藤子・F・不二雄『ドラえもん』」と出典明示し、以降は「あの猫型ロボット」で通す。**ひみつ道具の個別名は固有名で言う**（言い換えると技術比較の切れ味が落ちる）。
4. 絵の主役は実在ロボット。「手は来ていない」は実機で語るのが最も説得的。
5. 概要欄に定型文: 「本動画は技術予測の解説・批評です。原作画像・アニメ映像・音声・楽曲は一切使用していません。権利者との関係はありません。」
6. BGMは既存方針どおりPixabay等の商用可素材。**主題歌のオマージュ旋律も不可。**

**残るリスク**: 権利者が不快に思って手動削除通知を出す可能性（法的根拠がないので異議申立で戻る見込みが高いが、ゼロではない）。

**検討した代替案**: (a)固有名ゼロで通す案は言い換えが機能する（タケコプター→「頭に付ける小型プロペラ」、どこでもドア→「どこへでもつながる扉」、タイムマシンは言い換え不要＝一般名詞、四次元ポケット→「体積を無視して物を収める袋」）が、20分で10回以上出ると「ぼかしている」ことが伝わり続けて視聴体験がノイジーになる。(c)実在ロボット主役＋暗示のみ案はリスクゼロで最も自立した講義になるが、オチの刺さりが弱くなる。→ (b)骨格＋(c)構成の折衷を推奨。

## 第2部: 作品設定の正確性

### ★最重要の注意: 『ドラえもん百科』（方倉陽二）由来の設定を原作と混同しない
3mm浮遊・青ざめ説・特定意志薄弱児童監視指導員・どら焼きの成分論は**すべて方倉由来**で原作ではない。「公式設定は〜」の一本化はこの作品では不可能。必ず**どの作品／巻／映画か**を添える。

### 誕生日 2112年9月3日 → **A**
初出は**『ドラえもん大事典』（「小学四年生」1975年4月号、藤子・F・不二雄本人の原作）**。てんとう虫コミックス第11巻（1976年6月30日初版）巻末に収録。以後一度も変更なし（それ以前は21世紀出身だった）。「後付けだが、作者自身の原作エピソードで確定した設定」と言うのが最も正確。
  https://ja.wikipedia.org/wiki/ドラえもん_(キャラクター) / https://note.com/vigna1205/n/n09d46b07cc84
- 身長129.3cm統一＝**A** / 「当時の小学4年生の平均身長から採った」＝**B（公式発表なし）**

### 動力源 ★最も扱いを間違えやすい
「体内の『原子ろ』で何を食べても原子力エネルギーになる」は**半公式の解説漫画『ドラえもん百科』（方倉陽二）で作られた設定**で、単行本のキャラ紹介にも採用されていた。**東日本大震災以降、現行公式表記から「原子ろ」「原子力」の記述が削除され、単に「何を食べてもエネルギーになる」に変更**（『MFBドラえもん 未来の国からはるばると編』で確認と報道）。
  https://www.cinematoday.jp/news/N0047727 / https://hokke-ookami.hatenablog.com/entry/20110704/1309806399

- 「食べたものをエネルギーに変換する」＝**A**
- 「かつて体内原子炉と説明され、現在その記述は消えている」＝**A**
- 「動力源は原子炉である」と現在形で断定＝**C**
- 「原子炉設定が原作本編で語られた」＝**C**

**推奨文**「かつて公式解説では体内の原子炉とされていましたが、現在その記述は消え、『何を食べてもエネルギーになる』という説明に変わっています」
→ 全てAで通り、かつ**この変更自体が「22世紀の技術観が現実の事故で書き換えられた」という企画主題に直結する最良素材**。
