# sekai 冒頭3分 39枚「物の色を入れる」改修 指示書

## 何が起きたか (背景)

「つながる世界史」の冒頭3分39枚を描き終えて作者に見せたら、こう言われた。

> なんか全部をみて思うのはチャンネルの色味っていうのが全てのスライドに出過ぎてるから
> 見ててメリハリがないってことかな。場面が変わってる気がしないというか。
> ちゃんとカラフルな絵遣いにしたいというか。
> で玉音のスライドになったらこのスライドで良いのだけど。

一度、画面全体に `feColorMatrix` を掛けて区間ごとに色相をまわす直し方をやった。**これは却下された。**

> ちがう全然違う、全体の色を変えろってのはそうじゃないんだよ。
> **ちゃんと写真に撮ったように適切なものに適切な色を入れろ**って言ってんの

つまり **色セロハンを貼るな。物に本当の色を塗れ。**

## 今回やること (これだけ)

担当する絵の中の**物**に、その物が実際に持っている色を入れる。

- 夜空は**紺**。茶色の夜空は無い
- 海は**青**。茶色の海は無い
- 炎は**橙と黄**。煙は**灰**
- 畳は**萌黄**。木は茶でよい
- 雪は**白と青灰**
- 現代の書類の紙は**白**。1945年の詔書は**生成りの和紙**
- 看板・速報の画面は**赤・緑・青**
- 血は**赤**

## 絶対に変えないもの (ここを変えると作者が怒る)

1. **構図・物の配置・動き (`f` のタイミング)** — 色だけを直す。絵を作り直すのではない
2. **線の質** — 輪郭は今までどおり暗い線 (`WP.line`)。線を明るくしない
3. **フォント** — `SEKAI_SERIF` / `SEKAI_FONT` のまま
4. **実在の人物は逆光の影のまま**。顔・肌を描き始めない (天皇・ホメイニ・ハメネイ・モジタバ)
5. **逆光という作風** — 光源は1場面に1つ。影は光源の反対に落ちる
6. **#4〜#8 (玉音放送の5枚) は色を変えない。** 作者が「このスライドで良い」と名指しした。座敷・障子・ラジオの琥珀はこの5枚の正解

## 色の取り方

`src/remotion/sekai/world.tsx` の `WP` に**物の色の台帳**を足してある (`nightSky` `seaBlue` `fire` `snow` `paperWhite` `signRed` など)。まずここから取る。
**`world.tsx` は読むだけ。1文字も書き換えない** (4人で同時に触ると壊れるため)。
台帳に無い色が要るときは、**自分のファイルの先頭にローカルの const で定義する**。例:

```tsx
// この枚だけで使う色 (WP に無いもの)
const LANTERN = "#F0A64B"; // 提灯の火が透けた和紙
```

### 配色の約束 3つ
- **光源の色は1場面に1つ。** 夜の街なら街灯の橙、昼の海なら日の白、画面の前なら青白
- **影は真っ黒にしない。** その場の光の反対側に寄せた暗い色にする (夜なら紺寄り、夕方なら紫寄り)
- **一番言いたい物に、いちばん強い色を置く。** 全部を派手にすると結局メリハリが消える。1枚に強い色は1〜2つ

## 作業の仕方

1. 担当のファイルを読む (`src/remotion/sekai/boutou-X.tsx`)
2. 1枚ずつ、下の「担当分の色の指示」どおりに `fill` / `stroke` / グラデーションの stop の色を差し替える
3. `WarmStage` の背景が茶色すぎて夜や昼に見えない枚は、`WarmStage` を使わず**その枚のなかで背景を直接描いてよい** (空のグラデーション→地平→物、の順)。`WarmStage` 自体は書き換えないこと (他の担当と共有しているので)
4. 終わったら `cd /Users/suzukiyuu/Desktop/1005/movie && npx tsc --noEmit` が通ることを確認する
5. 自分の担当分を目で見る:
   `npx remotion still SekaiSheetAll tmp/c<担当>-<文番号>.png --frame=$(( (文番号-1)*60+45 )) --scale=0.5`
   を担当の枚数ぶん回して、全部を実際に見てから報告する。**見ずに「できました」と言わないこと**
