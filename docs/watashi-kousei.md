# 「私は何者?」の4000年史 — 構成案 v2 (karakuri / ずんだもん / 約22分)

自販機2000年史をベースにした設計。です・ます調ナレーション (「なのだ」は使わない)、章扉カード区切り、常時動きの3層 (人物アイドル・図解ループ・ホコリ)。
事実はすべて docs/watashi-factcheck.md の「OK表現」の範囲内。数字は固定8セットのみ使う
(約3300年前 / 紀元前410年 / 1905年 / 約175万人 / 約7万人 / 4.26点 / 1927年 / 1971年)。

## 全体の背骨

「国の運命 → 天の意思 → 頭の中身 → 能力 → 性格 → 自分だけの何か」。
占う対象がだんだん「外の世界」から「自分の内側」に縮んでいく一本線で貫く。
裁定者ではなく観察者 (「当たるか」ではなく「なぜ4000年続くのか」)。

**時代配分はユーザー指定で「昔:現代 ≒ 1:3」**。古代〜17世紀は大きい枠組み (占い=国家事業 / 占い師=公務員) で2.5章に圧縮し、第4章以降はすべて19世紀〜現代。

### 抽象軸「聞く相手の乗り換え」(ユーザー指定・学びの明示)

「私は何者?」を**誰に聞いてきたか**が「神様 → 体 → 数字 → 自分」と乗り換わっていく一本軸。
大きな節目ごとに台本で**累積リキャップ** (それまでの乗り換えをちょっとずつ振り返る) を入れる。挿入箇所は5つ:

1. 第2章末: 「骨も、星も、鳥も、聞き方はバラバラ。でも聞く相手は、ずっとひとつでした。神様です。」
2. 第3章末: 「聞く相手を、神様から、人間の体へ。」(初めての乗り換え宣言)
3. 第6章: 「神様に聞いた時代、体に聞いた時代。そして今、答えは『数字』になりました。」
4. 第8章: 「質問紙の答えを書いているのは、本人です。」→ 自分への乗り換え (いちばん大きい)
5. 結び: 「神様に聞き、体に聞き、数字に聞き、最後は、自分に聞いた。」で全回収

**絵**: 乗り換え路線図 (神様駅→体駅→数字駅→自分駅) が節目ごとに1駅ずつ伸びる「同じ図が育つ」演出。5箇所で同じモチーフを使い回す。

## 仕掛け (この回だけの武器)

**導入でずんだもんが視聴者を「診断」する。**
占い師の芝居 (「うーん……はあっ! 見えました。」水晶玉ポーズ・怪しい照明) でバーナム文を読み上げ、
「最後でタネを明かします」と宣言 → 第12章フォア実験で「冒頭のあの診断、誰にでも当たる文章でした」と種明かし。
視聴者自身がフォア実験の被験者になる。種明かしは「騙された」ではなく「人間の心のかわいい仕組み」として着地させる (断罪しない)。

## 導入 (確定案 / 約1.5分)

```
いきなりですが、この動画を開いたあなたを、診断してみます。
うーん……。
……はあっ!
見えました。
あなたは、まわりから「しっかりしている」と思われがちですが、本当は心配性な一面があります。
人に合わせるのは得意ですが、本当は、自分のペースを乱されたくないタイプ。
……どうでしょう。ちょっと当たっていませんか?
当たっていた方。その感覚、覚えておいてください。
この動画の最後で、タネを明かします。
星座占いに、血液型、93問に答えて出てくるアルファベット4文字。
私たちは毎日、なにかに「あなたはこういう人」と教えてもらっています。
この「私は何者?」という問い、実は記録に残るだけで、およそ4000年続いています。
最初の診断ツールは、スマホではなく、骨でした。
骨のヒビから、頭のデコボコ、インクのしみ、そして4文字タイプまで。
人類4000年ぶんの「自分探し」、さかのぼってみましょう。
```

演出メモ: 「うーん……はあっ!」はずんだもんの占い師ポーズ (水晶玉+紫の怪しい照明)。ここだけ画面の空気を変える。

## 炎上回避 (factcheckのNGリスト遵守)

- IQと人種・民族の数字比較は一切出さない (ゴダードのエリス島は使わない)
- 優生保護法は「存在+違憲判決」の事実一文まで。被害描写なし
- 占い・MBTI愛好層を断罪しない。「インチキ」等の評価語ゼロ。16Personalitiesは「別物」の指摘のみ
- 血液型あるあるネタ (B型は〜等) は使わない
- 晴明神社・宗教には触れない。式神は「後世の伝説」の一言
- 冒頭診断の種明かしは「人間の心のかわいい仕組み」として着地 (視聴者を笑わない)
