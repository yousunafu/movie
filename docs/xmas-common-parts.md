# クリスマス回2本の共通素材と、2本同時に作るときの決まり (2026-11-27 案)

対象: A「サンタクロースは、だれが作ったのか」/ B「日本のクリスマスは、なぜこうなったのか」
※ 部品の最終的な中身は、台本と設計書ができてから確定する。ここは「何を共通にするか」の案。

## 1. 共通部品 `src/remotion/karakuri/XmasParts.tsx` (A・B 両方で使う)

2本で同じ物の見た目がブレないように、両方に出る物だけを先に共有部品にする (柔らかいもの回の型「装置だけ共有、背景は共有しない」)。

- 男女の描き分け・腕は2本・あなた=水色パジャマ (目覚まし回と同じ決まりを `XmasCommon.md` に書き写す)

## 2. A だけ・B だけで使う部品

- A だけ (`SantaParts.tsx`): 北極の工房 / NORAD の作戦室 (レーダー画面・電話) / 郵便の仕分け棚 / 詩の本・雑誌の表紙の枠
- B だけ (`XjParts.tsx`): ケーキ (いちごと生クリーム・バタークリーム・ドライフルーツの焼き菓子) / チキンの骨付きもも・七面鳥 / いちごのハウス / 冷蔵ショーケース / 百貨店の売り場

## 3. 2本を同時に作るときの決まり (★音声の上書き事故の対策)

`src/remotion/scenes-data.json` は1つしかない。別作品の音声を作ると、前の作品の音声と scenes-data が上書きされる (2026-11 に事故あり)。

| | A サンタ | B 日本のクリスマス |
|---|---|---|
| motif の接頭辞 | `st_001`〜 | `xj_001`〜 |
| 音声フォルダ | `public/audio-santa/` | `public/audio-xmasjp/` |
| 絵のファイル | `Santa*.tsx` | `Xj*.tsx` |
| プレビュー | `SantaAll` | `XjAll` |
| scenes-data の控え | `archive/scenes-data/santa-v1.json` | `archive/scenes-data/xmasjp-v1.json` |

- **絵を描く作業 (プレビュー) は scenes-data を使わない**ので、2本同時に進めてよい
- **音声づくりと本番の書き出しは1本ずつ**。作る前に scenes-data.json を、その作品の控えに差し替える。書き出しのスクリプトは最初に「scenes-data が どの作品か」を確かめて、違えば止まる (目覚まし回と同じ)
- 書き出しは A → B の順 (同時に走らせると CPU が足りない。1本約33分)
