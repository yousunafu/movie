## 指示文 (プロンプト)

次の条件で、解説動画の台本を書いてください。

### テーマ・視聴者・尺

- テーマ: **睡眠中の脳は何をしているのか** (身近な科学の図解解説)
- 想定視聴者: **学び直しに関心のある大人の男性**。子ども向けの演出や煽りはしない
- 尺: **10分** (読み上げでおよそ8〜9分) = **約105文**
- チャンネル: おとなの理科室 (濃紺背景・白線画・図解が主役の作風)

### 構成の指定

1. **導入のつかみ** (約9文): 「人生の3分の1は睡眠」という身近な数字から入り、「もしただの休憩ならもったいない。実は脳は働き続けている」と問いを立てる。最後に「今日は4つの章で見ていく」と目次を宣言する
2. **4章立て**: 第1章 眠りのリズム / 第2章 夢を見る脳 / 第3章 記憶の整理 / 第4章 脳の掃除
   - 各章の冒頭は「まず第1章、〜から見ていきましょう」「ここからは第2章、〜の話です」のように**章番号を宣言する1文**を置く (章扉カードになる)
3. **クイズを2問** (第1章の終わりと第3章の終わり): 「さて、ここで問題です。」の宣言1文 → 出題文 → 少し間を置いて答えと解説。**演出は控えめに** (カウントダウンなどはしない)
4. **結論のまとめ** (約10文): 「ここまでをひとつにまとめましょう」から3つの仕事 (感情の整理・記憶の保存・大掃除) を言い直し、「明日のあなたは、今夜の脳が作っています。どうぞ、よい夜勤を。」のような**余韻のある締めの1文**で終える (結論カードになる)

### 文体ルール

- **1文 = 1シーン**。1行に1文ずつ書く。1文は読み上げて3〜6秒の長さ
- 話し言葉の「です・ます」調。専門用語は必ず身近なたとえに言い換える (例: 海馬=一時保管庫、脳脊髄液=洗浄液)
- 次の3種類の文を意識的に混ぜる (絵が自動で付くため):
  - **数字の文**: 「人生のおよそ3分の1」「約90分でひと周期」など → グラフ・円グラフになる
  - **問いの文**: 「なぜ〜でしょうか」「〜とは何でしょうか」 → 問いかけの図になる
  - **結論の文**: 「〜とは、…なのです」「つまり〜」 → カード・うなずきの絵になる
- 「なんと」「実は」(驚き)、「だから」「つまり」(納得) をつなぎに使うと絵に変化が出る
- 科学的な内容は定説の範囲にとどめ、断定しすぎない (「〜と考えられています」)
