## 絶対に守ること

1. **1文 = 1シーン = 1枚の絵。** 増やさない減らさない
2. **札 (TagPlate) の y + size*0.85 を 830 以下にする。** 画面の下には字幕の黒帯 (上端854) が別レイヤーで乗ります。検品プレビューには字幕が出ないので目では気づけません。必ず計算で守ること。**画面の下 1/4 (y>830) に大事な物 (顔・主役・札) を置かない** (床や影はOK)
3. **絵の中の文字は、ラベル・数値・標識だけ。** 台本の文章をそのまま絵に書かない (字幕が出るので二重になる)
4. **必ず `f` で何かが動く。** 静止した絵は禁止。人のまばたき (Person に f を渡す)・物のゆれ・ホコリは最低限で、そのうえで**そのシーンの事件**を動きで起こす
5. **出そろうのは f=42 まで。** 検品プレビューは全シーンを f=45 の瞬間で描きます。`seg(f, a, b)` の b は 42 以下。f=45 の瞬間に「いちばん伝わる絵」が出ているようにする
6. 色は `KRP` と `HP` と、自分のファイル上部の `C` にある色だけ。足すなら `C` に足す
7. seed は骨組みに書いてある数字を変えない
8. 対応表 `SCENES` と `*_MOTIFS` 配列、部品名・motif 名は**変えない**
9. **人物は共通部品 `Person` で描く** (からくり憲法第7条)。自分で別の画風の人を描かない。座らせるときは `pose="sit"` (座面の高さ = y − 58×s)。足りない姿勢 (寝そべり等) は Person 全体を `rotate` した `<g>` で包む・腕だけ自分で足す、で作る
10. **主役は画面センター** (第3条)。**物の大きさは現実に合わせる** (第4条)。**場所や時代が変わるシーンは「ここはどこ/いつ」が一目で分かる記号を置く** (第6条: 国旗・地名札・年代札)
11. **変身の演出では変身後に元の物を完全に消す** (第5条)。煙や光で「変わった」と分かる記号を添える
12. **背景キット禁止** (第13条)。同じ背景の上で物だけ入れ替える作り方はしない。1文ごとに舞台・構図・カメラを作る。例外は同じ場所・同じ時間の続き (「#7と#8は同じソファ」など、指示書に書いてある場合だけ)
13. **素肌禁止** (第16条)。無地のクリーム地に物を浮かべない。図の格でも「何かの上」に描く (発掘の土壁・巻物・机・掲示板など)

## 絵の「格」

| 格 | 中身 | 目安 |
|---|---|---|
| **山** | 舞台・人・事件・カメラ全部入り。全力 | 150〜300行 |
| **並** | 舞台はあるが、描くのは1つに寄る。人は1人、背景3〜4要素 | 80〜150行 |
| **図** | 図解が主役。人は置かない。ただし「何かの上」に描く | 50〜100行 |

**「図」「並」も品質は落とさない** (作者: 「シンプルとか普通のやつも絵のクオリティは下げちゃだめ」)。線・色・札・フォントは山と同じ。`strokeWidth` を細くしない。**最悪の失敗は「小さい物を画面の真ん中にポツンと置く」**。主役は短辺 (1080) の半分以上を使う。シンプル＝1つを大きく正確に。

## 6点法 (これが抜けると「正しいワークシートの挿絵」になる)

| # | やること | 抜けると言われること |
|---|---|---|
| ① | 寄る (主役を画面いっぱいに) | 「遠い」 |
| ② | 世界を置く (白紙に図を浮かせない) | 「精巧じゃない」 |
| ③ | 部品を作り込む (物の内部・質感まで) | 「全部が簡素」 |
| ④ | カメラが動く (1枚の中で寄り/引き/パン。全体を `<g transform>` で包んで f で動かす) | 「単調」 |

| ⑥ | 人が反応する (棒立ちさせない。face と pose と lean で) | 「人形が置いてある」 |

## 使える部品

**`HimaShared.tsx` から** (import 済み)
- `<Frame f={f} seed={…} bg={…}>…</Frame>` — 手描きのゆらぎ+バッジ「暇のからくり」+ホコリ。全シーンの外枠。必ず使う。`dark` を付けると夜向けのホコリ
- `<TagPlate x y text size t color fill rot />` — 白い木札。`t` は 0→1 で出てくる。幅 ≈ text.length*size+40
- `<QMark x y s t />` `<XMark x y s t />` `<Arrow x y s rot t />` `<Maru …>` `<MaruBatsu …>`
- `<ChapterDoor num title t left top width />` — 章の題字 (HTML。Frame の `over` に入れる)
- `W`=1920 `H`=1080 `FONT`

**`KarakuriScenes` から** (import 済み)
- `<Person x y s f face pose cloth clothDark hair helmet glasses gaze lean phase />` — x,y は**足元**。頭の中心は (x, y−228s)・半径64s。頭のてっぺんは y − 292*s。手は (x±67s, y−66s)
  - face: "normal" | "worried" | "surprised" | "smile" | "joy" | "angry" | "sad"
  - pose: "stand" | "banzai" | "raise" | "point" | "armsFolded" | "run" | "hold" | "sit" (sit は座面の高さ = y − 58s) (hold は胸の前で両手。手元 y≈−118s)
  - hair: "cap" (黒髪) | "none"
- `<PersonMini …>` — 小さな人形 (人数を並べる図に)
- `seg(f, a, b)` → 0→1 / `easeOut(t)` / `clamp01(x)` / `pop(t)` (ぽんと弾んで出る)
- `KRP` — 共通の色 (ink, cream, paper, white, red, green, orange, yellow, blue, blueDeep, blueSoft, gray, grayDark, floor, brass, silver …)

**`HimaParts.tsx` から** (この動画の装置と、何度も出てくる舞台。**使う前に該当箇所を Read して引数を確認**)
- `HP` — この回の色 (ものさしの4色 **hi 橙=日 / jikan 山吹=時間 / fun 青緑=分 / byo 藍=秒**、`you`/`youDark` =「あなた」の橙のパーカー、`spark` 火花・光、`screen` スマホの光、`rest`/`restSoft` 休みの赤 など)
- `<Monosashi x y s lit f focus labels tilt />` — **暇のものさし** (この動画の装置)。s=1 で幅1400px。`lit` 0〜4 で刻まれた目盛りの数 (小数で刻んでいる途中・のみと火花が出る)。`focus` で1区画を光らせる。`monoSlot(i, x, y, s)` で i 番目の区画の上の辺の真ん中の座標 (小物を乗せる位置)
- `<Sousa x y s f face pose lean lensAt />` — **捜索係** (緑のベスト・茶のハンチング帽・大きな虫めがねの案内役)。`lensAt=[x,y]` で虫めがねをそこへ向ける。**捜索係は必ずこれで描く**
- `<Sagyozukue f night />` — **作業机** (ものさしを置く机。壁の有孔ボードと工具・ランプ・メモ・コーヒー)。ものさしは (960, 560, s=1) に置くとちょうど収まる
- `<YoruNoHeya f tv />` + `<YoruNoHeyaFront />` — **「あなた」の夜の部屋** (窓と月・時計・本棚・テレビ・観葉植物・ソファ)。座らせるときは YoruNoHeya → `<Person pose="sit" x={860} y={758} s={1.05} …/>` → YoruNoHeyaFront の順
- `<EkiHome f minutes train />` + `<EkiBenchFront />` — **夕方の駅のホーム** (電光掲示・線路・自販機・ベンチ)。`minutes` で掲示の数字、`train` 0〜1 で電車が入ってくる。座らせるときは EkiHome → Person (pose="sit", x=860, y=748, s=1.05) → EkiBenchFront
- `<KyukeiBoard f />` — **会社の休憩室のホワイトボード** (内側 x 360〜1560, y 150〜720)。この中に棒グラフなどを描く
- `<ShockRoom f minutes press lamp empty />` — **電気ショック実験の部屋** (壁・ドア・15分の扇形の壁時計・椅子・机・赤いボタンの箱)。椅子の座面の中心 (720, 640)、ボタンの中心 (1060, 560)
- `<Sumaho x y s rot f screen glow />` — **スマホ** (screen: "off"|"on"|"feed"|"notify")。s=1 で縦300px。ロゴは描かない
- `<YasumiCalendar x y s title days startDow rest half t strike weekHead f />` — **休みのカレンダー** (ひと月。休みの日を赤く塗る。`t` で順番に塗られる)
- ★装置と舞台は**指示書で指定された文でだけ**使う。指定のない文で勝手に出さない。逆に、指定された文では**自分で別の物を描かず、必ずこの部品を使う** (同じ場所・同じ物の見た目を全編でそろえるため)
- ★部品の中に人は入っていない。人・小物・カメラの動き・その文の事件は自分で足す

## ★この動画だけの決まり (必ず守る)

1. **実在の人物の顔は描かない**: コンスタンティヌス帝・ピープス・スミス (新聞屋) など、名前の出る実在の人物は**後ろ姿・横を向いた遠景・手元だけ・本で顔が隠れた姿**で見せる (Person を描くなら背中を向けた姿。後ろ向きの姿勢がないときは、頭を髪の色で塗りつぶした「後頭部」を自分で描いて顔を隠す)。名前の出ない一般の人 (村人・工場の人・乗客・研究者・学生) は顔を描いてよい
2. **ロゴ・商品名を描かない**: スマホ・ウォークマン・ゲームボーイ・iPhone・新聞・本の表紙・キヨスク・店の看板に、実在のロゴや商標の字を描かない。形と色だけで分かるようにする
3. **字幕と同じ文章を絵の中に書かない**。札は「ラベル・年・地名・数字」だけ
4. **数字は指示書に書いてある数字だけ**を使う (ファクトチェック済み)。自分で数字を足さない (例: 「1日150回」「集中力8秒」などの俗説は絶対に描かない)
5. **ユーモアは絵の事件で**: 指示書の冗談の場面 (天気との腕相撲・見張りつきの休み・びっくり箱・黄色い本「そのまま」・表彰台の神奈川・耳を引っぱる吹き出し など) は、**表情と動きで笑える**ように大げさに。ただし下品・残酷にしない。電気ショックは小さな稲妻とびくっとする顔まで (痛そうな描写・苦しむ顔はしない)
6. **スマホを悪者に描かない**。スマホの光は明るくきれいに。説教くさい絵 (スマホにドクロ・依存の鎖など) は禁止

## 進め方

1. 自分の指示書と、自分の担当 .tsx を Read する。次に `HimaParts.tsx` を Read する (この3つを最初に読む)
2. 骨組みの各シーンの `// どこ: // 演出: // 動き:` のコメントを**先に埋めてから**描く
3. 一気に書く。Edit で `{/* TODO */}` を本物の絵に置き換えていく (シーンを `=> (` から `=> { … return (…); }` に書き換えてよい)
4. 型チェック: `node_modules/.bin/tsc --noEmit`
5. 札の検査: `npx tsx scripts/koso-plate-check.ts <自分のファイル名から .tsx を取った名前> (例 HimaA)` — **NG 0件になるまで直す**
6. 静止画をまとめて書き出す (**1枚ずつ `remotion still` を呼ばない**。必ず先頭で TMPDIR を設定):
   ```
   export TMPDIR="$(pwd)/tmp/remotion-tmp/"; node_modules/.bin/remotion render src/remotion/index.ts HimaAll tmp/hima/<置き場> --sequence --frames=<C1>-<C2> --image-format=png --log=error
   ```
   コマ番号 = 文番号 − 1。出力のファイル名は `element-<コマ番号>.png` (桁数は Remotion が0詰めすることがある。`ls` で確かめる)
7. 全部を Read して自分で検品する: 主役が小さくないか / 物が重なって読めなくなっていないか / 画面の下1/4に大事な物がないか / 人の手足や物のつながりが変でないか / 真ん中にポツンでないか / 素肌 (無地背景) がないか
8. 直して、もう1回だけ書き出して確認する
9. 終わったら、各シーンを1行で説明した報告を返す (400語以内)
