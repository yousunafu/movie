# 第5章「島には、土地がない。」設計書 (文#179〜#216 / 38文)

## この章の役割
5本の柱が立ち終わったあと、**「では、なぜ建てたのか」**に答える章。技術ではなく**土地と欲**の章。
軸は変わらず「高さに住むコストを、誰が払っているのか」。
#197「高いビルは、技術の自慢ではなく、地価の結果でした」がこの章で軸に触る文。#216「人の欲は、道具が許したぶんだけ膨らむんです」が章の決着。

**語らないもの**: 開発業者の名前・個別の物件・政治家の人物像。
**語るもの**: 島だから土地が増えないこと / 地価が先で高さが後だという順番 / 止めたのは技術ではなく社会だったこと / 日本の31mの由来。

### ★「図」「並」も品質は落とさない (作者指示)
> 「シンプルとか普通のやつも絵のクオリティは下げちゃだめなんだけどね。だけど、細かい作りこんだ絵が生きるのは、そのバランスがあってこそなんだよね」

短いのは賑やかさを削ったからで、雑に描いたからではない。線・色・札・フォントは山と完全に同じ。必ず `f` で動く。図そのものを作り込む。**大きく置いて画面を使い切る。**

---

## ★この章の色の設計
3章は水色と木の茶、4章は火→白熱球→灰青。**5章は「地図と紙と海」の色にする。**

- #179〜#193 (島と積む) = 海の青灰・島のベージュ・岩盤の茶。**俯瞰と地図の色**
- #194〜#203 (グラフと恐慌) = 紙のクリーム・グラフの赤と青。#202 だけ**暗く沈める**
- #204〜#216 (日本と現在) = 街の灰・赤い制限線・最後に金色

**人の絵が少ない章**なので、#185/#186/#189/#191/#202/#204/#210/#215 の並で必ず人を出す。図が続くと冷たくなる。
