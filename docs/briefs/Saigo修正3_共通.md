## 3. 作風の決まり (破ると検査に落ちる)

- **必ず `f` で動く。静止画は禁止。** `seg(f, a, b)` の **b は 42 以下** (検品プレビューは f=45 の瞬間を写す)
  - ただしゆっくりしたズームや流れる動きは `f` 全体で続けてよい (`easeOut(clamp01(f / 120))` など)。f=45 の瞬間に「動きの途中で見苦しくない」こと
- **札 (TagPlate) の下端 = y + size*0.85 ≤ 830** (それより下は字幕帯に隠れる)
- **絵の中の文字はラベル・数値・標識だけ。** 台本の文章・セリフ・引用を絵に書かない。札に読点「、」を使わない (間は半角スペース)
- **被りゼロ**: 札・ラベル・吹き出し・紐・線が人物の**顔**・他の文字・字幕帯 (y>830) に重ならない。レンダ後に拡大して確認
  - ★今回、売り子の首紐が顔の上に描かれていて作者に「顔に変な線がある」と言われた。**人物の前を横切る線は必ず拡大して確認**
- 線の太さ: 輪郭 6〜8、細部 3〜5。細くして逃げない
- 色はまず `KRP` と `SGP` から。足りなければファイル先頭のローカル `const C = {...}` に足す
- 乱数はローカルの `rnd(seed, i)`。`Math.random()` は禁止
- **同じ構図・同じ背景の絵を2枚続けない** (前後の文の絵を書き出して見比べる)
- **意味のない線を置かない。** ★今回、茶の間の畳の「縁」の線が遠近の向きを間違えて、左から差す謎の斜め線に見え、作者に「これは何？いらない」と言われた。飾りの線は「何を表しているか」が一目で分かるものだけ

### ★ Person に帽子・衣装・小物を乗せるときの契約

`KarakuriScenes.tsx` の `Person` は

```
transform = translate(x, y + bob) scale(s) rotate(lean)
bob = still ? 0 : Math.sin((f + phase * 17) / 13) * 3
```

の順で描かれ、**回転の軸は足元**。人物ローカル座標で 頭の丸 `cx=0 cy=-228 r=64` (てっぺん -292・あご -164)、胴 `x -58..58 / y -160..-52`、肩 `(±67, -148)`、足元 `y=0`。

体に物を乗せるときは**人物とまったく同じ変換をかけた入れ物**を作り、その中で上のローカル座標で描く。
いちばん安全なのは、入れ物が bob を持ち、中の Person には `x={0} y={0} still` を渡すやり方:

```tsx
const Kasane: React.FC<{
  x: number; y: number; s?: number; lean?: number; f: number; phase?: number;
  back?: React.ReactNode; front?: React.ReactNode; children: React.ReactNode;
}> = ({ x, y, s = 1, lean = 0, f, phase = 0, back, front, children }) => {
  const bob = Math.sin((f + phase * 17) / 13) * 3;
  return (
    <g transform={`translate(${x} ${y + bob}) scale(${s}) rotate(${lean})`}>
      {back}{children}{front}
    </g>
  );
};
// 使い方: <Kasane x={..} y={..} s={..} f={f} back={...} front={...}>
//           <Person x={0} y={0} f={f} still ... />
//         </Kasane>
```

座標を少しずつ足して合わせる「ごまかし」は禁止 (傾きが変わると必ず破綻する)。
首から下げる紐・たすき・ストラップは **あご (y=-164) より下から出す**。顔の上を通さない。
