## この巻の役割
第8章: 映画の**2つ目の怖さ「元の自分を忘れる」**を確かめる。使い分けても自分は1人 / 改姓で「違う人になった気がした」は約7人に1人 / 脳は自分の名前に振り向く (約3人に1人が気づく・赤ちゃんも) / 番号で呼ぶ仕組み (★**収容所は絵にしない**: 番号の札と字幕だけ) / 刑務所の「さん」付け / 無戸籍700人 / **直接測った研究はない**、と正直に線を引く。この章だけ**真面目なトーン** (色を少し落ち着かせる・笑いなし)。
