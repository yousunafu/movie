## 3. 作風の決まり (破ると検査に落ちる)

- **必ず `f` で動く。静止画は禁止。** `seg(f, a, b)` の **b は 42 以下** (検品プレビューは f=45 の瞬間を写す)
- **札 (TagPlate) の下端 = y + size*0.85 ≤ 830** (それ以下だと字幕帯に隠れる)
- **絵の中の文字はラベル・数値・標識だけ。** 台本の文章・セリフ・引用を絵に書かない。札に読点「、」を使わない (間は半角スペース)
- **被りゼロ**: 札・ラベル・吹き出しが人物・他の文字・字幕帯 (y>830) に重ならない。レンダ後に拡大して確認
- 線の太さ: 輪郭 6〜8、細部 3〜5。細くして逃げない
- 色はまず `KRP` と `SGP` から。足りなければファイル先頭のローカル `const C = {...}` に足す
- 乱数はローカルの `rnd(seed, i)`。`Math.random()` は禁止
- 群衆は `PersonMini`、主要人物は `Person` を使う。**人物の画風を新しく作らない**
- **同じ構図・同じ背景の絵を2枚続けない**

### ★ Person に帽子や小物を乗せるときの契約 (今回これで事故が起きた)

`KarakuriScenes.tsx` の `Person` は

```
transform = translate(x, y + bob) scale(s) rotate(lean)
bob = still ? 0 : Math.sin((f + phase * 17) / 13) * 3
```

の順で描かれ、**回転の軸は足元**。頭の丸は人物ローカル座標で `cx=0 cy=-228 r=64` (てっぺんが -292)。

帽子を別の `<g>` に置くと、体が傾いた瞬間に頭から外れる。必ず**人物とまったく同じ変換をかけた入れ物**を作り、その中で「頭の丸」基準のローカル座標で描く。`f` `phase` `still` `lean` は人物と同じ値を渡す。

```tsx
const AtamaNo: React.FC<{
  x: number; y: number; s?: number; lean?: number;
  f?: number; phase?: number; still?: boolean; children?: React.ReactNode;
}> = ({ x, y, s = 1, lean = 0, f = 0, phase = 0, still = false, children }) => {
  const bob = still ? 0 : Math.sin((f + phase * 17) / 13) * 3;
  return <g transform={`translate(${x} ${y + bob}) scale(${s}) rotate(${lean})`}>{children}</g>;
};
```

座標を少しずつ足して合わせる「ごまかし」は禁止 (傾きが変わると必ず破綻する)。
