## ① 畳の斜めの深緑の線を消す (#196 ほか)
作者: **「畳にある斜めの深い緑の線達は何を表してるの？いらないんだけど、他のシーンにもあるからチェックして」**

- 原因: ローカル部品 `TatamiRoom` の「畳縁 (奥へ収束する深緑の帯)」(`C.heri`、strokeWidth 13 の5本)。収束の向きがずれていて、**左下から差す謎の光線**に見えている
- → **この5本を消す。** 横の「畳の目」の細い線は残してよい
- `TatamiRoom` を使っている全シーン (grep `<TatamiRoom`) の書き出しで、斜め線が消えたこと・床が不自然に寂しくなっていないことを確認する。寂しければ畳の目の線を整える・座布団や小物で床に「物」を置く (意味の分からない線は足さない)
- ファイル内に**ほかにも同じような斜めの線** (`C.heri` などで描いた遠近の帯) がないか grep で探し、意味が読めないものは同様に消す。**真上から見た畳の縁 (縦の帯) は畳と分かるので残す**
- 報告に「どの文で何本消したか」を書く

## ② #198 「ご飯を食べながら、洗い物をしながら、新聞を読みながら。」(`Sg198`)
作者: **「メインキャラクターを使った分割の説明にした方がいいかも」**

→ いまは3枚の札に**手だけ**が描かれている。**3分割は活かし**、各コマに **`Person` (メインキャラクター)** を入れて「〜しながらテレビ」を見せる。
- コマ1: ちゃぶ台で**ご飯を食べながら**、顔は横のテレビへ (茶碗と箸)
- コマ2: 台所の流しで**洗い物をしながら**、肩越しにテレビを振り返る (泡・水・皿)
- コマ3: **新聞を広げながら**、新聞の上からテレビをちらり
- 3コマとも**小さなテレビ**が映り込み、目線がテレビへ向いていることが分かる
- 人物は前後の文 (#196 #199 #200) の家族と**同じ服の色**で揃えると「同じ家の人」と分かる (#196 の Person の cloth を grep して合わせる)
- コマは f でずらして順に現れる (seg の b ≤ 42)。各コマに短い札「食べながら」「洗いながら」「読みながら」を付けてよい

## ③ #199 「客席が明るいどころか、テレビの前は、生活のど真ん中でした。」(`Sg199`)
作者: **「もっと台本に適した精巧なイラストに変更」**

→ いまは間取り図の上に色線 (動線) が這っているだけで、伝わらない。作り直す。
- 伝えること: 劇場は客席を暗くして観客を黙らせたが、**テレビの前は明るく、生活の真ん中**。家族の生活がテレビを囲んで丸ごと回っている
- 案: 昭和の家の**断面図 (ドールハウスのように壁を切った家)**。真ん中の茶の間にテレビ (光っている)、そのまわりで**同時に**: 台所で料理する人、ちゃぶ台で宿題をする子、晩酌する人、洗濯物をたたむ人、寝ころぶねこ — 全員 `Person`。**部屋の明かりは全部ついて明るい**
- テレビから生活の各所へ**ゆるい光の輪**が広がる、など「ど真ん中」を絵で示す
- #196 (正面から見た茶の間) と**同じ構図にしない**のが断面図にする理由

## ④ リモコンでチャンネルを変えるシーンの速さを落とす (#200 / #201)
作者: **「リモコンでチャンネル変えるシーンはペースが早いから落として」**

- 対象は #200 「1979年には、手元で局を変えられるリモコンが登場します」と #201 「80年代に普及すると、お客はコマーシャルのたびに、よその局へ旅立ちました」のうち、**画面がパッパッと切り替わる方** (たぶん #201)。両方を `SaigoMotion` で確認して特定する
- ★**シーンの長さ (尺) は変えられない** (音声に合わせて固定)。「落とす」= **切り替わりの間隔を長くする**こと
  - 目安: 1チャンネルあたり **0.8〜1.0秒 (24〜30コマ)** 映ってから次へ。いまの間隔を測り、報告に「何コマ → 何コマ」と書く
  - リモコンのボタンを押す手の動き・電波の稲妻も、切り替わりと同じ間隔に揃える。チカチカ点滅させない
- f=45 の瞬間に画面が切り替えの途中 (半透明の重なり) にならないよう調整する
