# つながる世界史・冒頭3分 描き直し指示書 (2026-11-09)

作者が作り込み版の絵を**丸ごと却下**した。言葉はこれ。

> 作り込み版のスライドがなんか基本的に全然ダメな気がするのはなんでなんだろう。
> からくりチャンネルと雰囲気が違うとはいえ、**AIっぽすぎるし、作り込んでないし、なんか違う**んだよなぁ

> あと**人のシルエットもいやだ**から具体的に描いて。**時代検証しながらちゃんとわかりやすい格好をさせよう**

根本原因は「要素が全部それっぽい記号で、固有名詞の細部が無かった」こと。
工場・傘・山・黒い人影 ── どれも**どの国のどの時代でも成立してしまう**。

前回の工程上の失敗も書いておく。**並列の絵師4人に共通の指示書を1枚だけ渡した**ので、
全員が一番安全で一般的な絵を描いた。だから今回は、この共通ルールに加えて
**枚ごとに「この絵に出す物」を名指しした別紙**を渡す。別紙に書いてある物は必ず画面に出す。

---

## 0. 絶対にやってはいけないこと

| 禁止 | 理由 |
|---|---|
| 無貌の黒/灰色シルエットで人を置く | 作者が名指しで却下した一番の原因 |
| 逆光で人を真っ黒に潰す | シルエットに戻るだけ。同じ却下理由に当たる |
| 画面全体に色フィルタを掛ける | 「色セロハンを貼った写真」になる。**物ごとに本当の色を置く** |
| どの国・どの時代でも成立する物だけで画面を作る | 工場・傘・山・ビル・群衆だけ、が前回の失敗 |
| 既存の汎用部品を並べて1枚にする (キット禁止) | 第13条。1文につき1演出を専用に作る |
| 素の背景に文字を浮かせて終わり | 第16条「素肌禁止」。それは暫定であって完成形ではない |

`ShadeFigure` (boutou-a.tsx) と `GhostFigure` (parts.tsx) は**廃止**。使っている箇所は全部
描き直す。各ファイル8行目の「実在の人物の顔は描かない。逆光の黒い影＋金のリムライトで
処理する。」も**嘘になったので書き換える**。

## 1. 人の描き方 (方針④)

### 1-1. 庶民には顔と表情を与える
目・眉・鼻・口・耳を描く。伏せ目なら上に凸の `C` 曲線、見開いた目なら白目＋瞳。
汗・涙・口の開きで**反応**させる (6点法⑥)。顔が小さくて描けない大きさなら、
その人を**もっと大きく描く**か、画面から外す。小さいから省く、は無し。

### 1-2. 実在の著名人は「所作と装い」で見せる。似顔絵にはしない
ホメイニ師なら**黒いターバン＋白い顎髭＋茶のアバ**、ハメネイ師なら**黒いターバン＋眼鏡**、
昭和天皇なら**マイクに向いた背中と肩章**。顔の造作を似せようとしない。
ただし**黒く潰すのも禁止**なので、布と肌にはちゃんと色を入れ、顔はうつむき・横顔・後ろ姿・
画面外への見切れ・前の人の頭で隠れる、といった**構図の都合**で見せない。

### 1-3. 群衆には必ず老若男女を混ぜる
作者の指示 ──「**男女はうまく入れてよせっかくなら**」。
男だけの列、女だけの列は作らない。年齢も散らす (少年・若者・中年・老人)。
服は性別と立場で**必ず変える** (別紙に各枚の服を書いてある)。

### 1-4. 式・放送・儀礼の場面は「整列」と「かしこまり」を描く
作者の指示 ──「**玉音放送は多分整列して聞かないといけないからそろってかしこまってる
様子も必要だ**」。
放送・演説・葬儀・宣誓の場面では、人をバラバラに立たせない。
- 床や地面の**整列線**の上に乗せる
- 気をつけ (脚を閉じ、腕を体側にまっすぐ、手のひらを腿に)
- お辞儀の角度をそろえる。`bow` を数フレームずつずらすと「そろって」動いて見える
- 帽子は脱いで胸に当てる

### 1-5. 手本
`src/remotion/sekai/boutou-a.tsx` の **#6 (軍需工場の前庭で玉音放送を聞く)** が唯一の
承認済みの手本。`Hito` の作りと、2列の並び方、顔の描き方を**読んでから**描き始めること。
ただし **`Hito` を import して使い回すのは禁止**。全部の枚で同じ顔が出ると、作者の嫌う
「AIっぽい」同一性がそのまま出る。**構造を真似て、その枚の人を新しく描く。**

## 2. 寄りと構図の縛り (方針②)

前回は39枚のうち大半が「引きの全景を正面から」だった。これが単調さの正体。

- **全景 (遠景・人が小さい) は3枚に1枚まで。** 自分が担当する枚のうち全景にできる数を
  先に数えて、残りは必ず寄る
- カメラの高さと角度を**枚ごとに変える**。選択肢:
  俯瞰 / 真上 / 真横 / 煽り (下から) / 肩越し / 手元だけの極端な寄り / 断面 / 窓やドア越しの枠
- **人の顔が画面の高さの1/4以上**になる寄りを、担当内に最低2枚入れる
- `Cam` でカメラを動かす (6点法④)。動かすときは背景の矩形を `x={-200} width={W+400}` のように
  広げておかないと端が出る
- 画面を3分割して3つ並べる構図は**1人1枚まで**。前回これが多すぎた

## 3. 具体物 (方針③)

**別紙に名指しした物を必ず出す。** 加えて自分で1つ足してよい。
時代考証は細かくなくてよい (作者の指示)。ただし**アナクロは避ける** ──
1988年にスマートフォン、1701年にガラス窓、1945年8月の煙突から煙、など。

## 5. 作業の作法

1. 担当ファイルの担当シーンだけを直す。他のシーンと他のファイルに触らない
2. `W` `H` `SKP` `WP` `Cam` `YearTag` `easeOut` `seg` などは既存の import をそのまま使う
3. 書き終えたら `npx tsc --noEmit` が通ることを確認する (リポジトリ直下で)
4. 1枚あたり **120〜250行**。12行で済ませたものは廉価版であって作り込み版ではない
5. 報告は「どの枚に何の具体物を入れたか」を1枚1行で。言い訳と前置きは要らない
