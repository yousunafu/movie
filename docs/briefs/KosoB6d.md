## 絶対に守ること

1. **1文 = 1シーン = 1枚の絵。** 11文だから11枚。増やさない減らさない
2. **札 (TagPlate) の y + size*0.85 を 830 以下にする。** 画面の下には字幕の黒帯 (上端854) が別レイヤーで乗ります。検品プレビューには字幕が出ないので、目で見ても気づけません。必ず計算で守ること

7. seed は 883〜893 を1シーンに1つずつ (もう骨組みに書いてあります。変えない)

### ★「図」「並」も品質は落とさない (作者の指示そのまま)

> 「シンプルとか普通のやつも絵のクオリティは下げちゃだめなんだけどね。だけど、細かい作りこんだ絵が生きるのは、そのバランスがあってこそなんだよね」

短いのは**賑やかさを削ったから**であって、雑に描いたからではありません。

- 線・色・札・フォントは山と**完全に同じ**。`strokeWidth` を細くしない。ゆらぎフィルタ (`Frame`) を外さない
- **必ず動く。** 静止した図は禁止
- **図そのものを作り込む。** 物差しなら目盛りの刻み・数字・木口まで。グラフなら軸・目盛り・数字・棒の縁まで
- **大きく置いて画面を使い切る。** 最悪の失敗は「小さい物を画面の真ん中にポツンと置く」。シンプル＝小さい ではない。シンプル＝**1つを、大きく、正確に**。主役の装置は短辺で画面の1/2 (540px) 以上を使う
- 余白は「空っぽ」ではなく「寄り」。余白があるのは、そこに寄っているから

## 使える部品

`import` 行はもうファイルに書いてあります。主なものの使い方:

**`KosoShared.tsx` から**
- `<Frame f={f} seed={883} bg={KRP.cream}>…</Frame>` — 手描きのゆらぎ。全シーンの外枠。必ず使う
- `<TagPlate x y text size t color fill />` — 木札。`t` は 0→1 で出てくる。幅 ≈ text.length*size+40
- `<QMark x y s t />` `<XMark x y s t />` `<Arrow x y s rot t />` `<ChapterDoor ...>` (章扉に使う)
- `W`=1920 `H`=1080 `FONT`

**`KarakuriScenes` から**
- `<Person x y s ...>` — x,y は**足元**。頭のてっぺんは y - 292*s
- `seg(f, a, b)` → f が a〜b の間で 0→1 (範囲外は0か1) / `easeOut(t)` / `clamp01(x)` / `pop(t)`
- `KRP` — 共通の色 (ink, cream, white, red, green, orange, yellow, gray, grayDark …)

**`KosoB2Parts.tsx` から** (**使う前に該当箇所を Read して引数を確認すること**)
`BP` (鉄・真鍮・木などの色) / `lerp` `rnd` `zoomAt` `bobOf` / `Rivets` `HexBolt` / `GridPaper` (図の方眼下地。「図」の下地に使う) / `Rope` / `Balance` (てんびん) / `Maru` `MaruBatsu` / `ForceArrow` / `FloorScale` (階数の目盛り) / `FlowPlates`

**`KosoPillars.tsx` から**: `KPP` (柱の色) / `TowerOnPillars` (5本柱の上にタワマン群) — この範囲では使いません

この範囲で要る物のうち既存部品にないもの (地図・海・グラフ・物差し・パリの建物など) は、**自分のファイルの中にローカルな部品として書いてください** (共用の `KosoB2Parts.tsx` には足さない)。同じ物が2回以上出るときは、ローカル部品に切り出すと形がそろって得です。

## 「図」の見本 (別の章の文#71。これと同じ作りこみ・同じ大きさで描く)

```tsx
const Kb2RopeKasshaHito: React.FC<{ f: number }> = ({ f }) => {
  const SX = 760, SY = 330, SR = 210;          // 綱車の中心と半径
  const LX = SX - SR * 0.82;                   // 荷台側
  const HX = SX + SR * 0.82;                   // 手側
  const pull = (Math.sin((f - 10) / 14) * 0.5 + 0.5) * easeOut(clamp01(seg(f, 4, 28)));
  const handY = 640 + pull * 130;
  const loadY = 790 - pull * 130;
  const rot = -pull * 44 + f * 0.6;
  return (
    <Frame f={f} seed={605} bg={KRP.cream}>
      <GridPaper />
      {/* 吊り元の梁。画面を端から端まで横切らせる */}
      <rect x={-20} y={66} width={W + 40} height={58} fill={BP.wood} stroke={KRP.ink} strokeWidth={7} />
      <Rivets x1={60} y1={95} x2={1860} y2={95} n={14} r={8} fill={BP.woodDark} />
      {/* ロープ: 荷台 → 綱車 → 手 */}
      <Rope x1={LX} y1={loadY - 58} x2={LX} y2={SY} w={22} kind="hemp" f={f} />
      <Rope x1={HX} y1={SY} x2={HX} y2={handY - 24} w={22} kind="hemp" f={f} />
      {/* 綱車。画面の高さの4割を使う */}
      <Sheave x={SX} y={SY} r={SR} rot={rot} spokes={6} groove bracket />
      {/* 荷台と樽 … 吊り鎖・板・樽2つ */}
      {/* 引く手。人は置かない。手だけに寄る … 腕・袖・掌・指4本・親指・握りの皺 */}
      <ForceArrow x={HX + 118} y={handY + 70} len={230} rot={90} w={24}
        color={KRP.red} t={seg(f, 14, 30)} label="引く" labelSize={36} />
      <ForceArrow x={LX - 268} y={loadY - 84} len={230} rot={-90} w={24}
        color={KRP.green} t={seg(f, 20, 36)} label="上がる" labelSize={36} />
      <TagPlate x={1450} y={330} text="滑車" size={56} t={seg(f, 6, 20)} />
      <TagPlate x={1450} y={450} text="溝にロープが乗る" size={32} t={seg(f, 16, 30)} />
      <TagPlate x={1546} y={790} text="人の力" size={46} t={seg(f, 26, 42)} color={KRP.red} />
      <TagPlate x={330} y={790} text="荷物" size={40} t={seg(f, 10, 24)} />
    </Frame>
  );
};
```

要点: **主役を大きく / 画面の端まで使う / 部品の内部まで描く / 矢印と札で意味を言う / 必ず f で動く**。

## 進め方

1. まず `src/remotion/karakuri/KosoB6d.tsx` を Read して骨組みを把握する。次に `KosoB2Parts.tsx` を Read して部品を把握する (この2つだけ最初に読む)
2. 骨組みの各シーンにある `// どこ: // 演出: // 動き:` のコメントを**先に埋めてから**描く
3. **「山」から先に描く。** 章の背骨なので、ここが決まれば残りが決まります。そのあと連番の図、最後に並
4. 書けたら型チェック: `node_modules/.bin/tsc --noEmit`
5. 札の検査: `npx tsx scripts/koso-plate-check.ts KosoB6d` — **NG 0件になるまで直す**
6. 静止画を書き出す (**1枚ずつ `remotion still` を呼ばないこと。1回のビルドで11枚出せます**):
   ```
   node_modules/.bin/remotion render src/remotion/index.ts KosoB6 tmp/koso/kosob6d --sequence --frames=33-43 --image-format=png --log=error
   ```
   出てくるのは `tmp/koso/kosob6d/element-33.png` 〜 `element-43.png`。**element-N の N に 217 を足した数が文番号**です (element-33 = 文#250, element-43 = 文#260)
7. 11枚を Read して自分で検品する。見るところ: 主役が小さすぎないか / 物が重なって読めなくなっていないか / 画面の下1/4に大事なものを置いていないか / 人の手足や物のつながりが変でないか / 真ん中にポツンと置いていないか / 連番の回 (「#○と同じ図のまま」と書いてある回) がちゃんと同じ形・同じ座標になっているか
8. 直して、もう1回だけ書き出して確認する
9. 終わったら、11枚それぞれを1行で説明した報告を返す (400語以内)
