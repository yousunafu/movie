## 全体の背骨

**「黙って、座って、最初から最後まで観る」は人類の伝統ではなく、150年ものの発明品。
倍速・スキップは堕落ではなく、数千年の平常運転への復帰である。**

構成の型は**「犯人のリレー」(年代順に逮捕していく)**:
①パリのブルジョワ (1830〜50年代・沈黙の発明) → ②ワーグナー (1876・客席を暗くした) →
③マーラー (1897〜・遅刻者を締め出した) → ④明治日本 (演劇改良・茶屋の廃絶) →
⑤ヒッチコック (1960・途中入場お断り) → ⑥シネコン (2002頃・全席指定入替制)。
裁定者ではなく観察者 (「飛ばすのは良いか悪いか」ではなく「この規範はいつ誰が作ったのか」)。
若者も倍速派も断罪しない。嘆く側も笑い者にしない。

### 抽象軸「客席の明るさ」(同じ図が暗くなっていく演出)

## 仕掛け (この回だけの武器) — 裏主人公は「客席の照明」

**この動画の隠れた主人公は「客席の明かり」である。** 3点で回収する:

1. **序〜第2章**: 客席が明るい時代 = 主役は客。舞台は社交の背景だった
2. **第4章**: 1876年バイロイトでワーグナーが客席を暗くする = **主役が客から作品に交代した日**。
   しかも計画は「減光」で、ガスの不具合により想定より暗くなったという経緯つき (笑いどころ)
3. **結び**: スマホの画面 = **客席の明かりが150年ぶりに戻ってきた**。手元が明るい客は、また食べ、しゃべり、出入りする

オチ (スマホ=客電の復活、倍速=数千年の平常運転) は結びまで出さない。

## 導入 (たたき台 / 20文・約1.8分)

```
いきなりですが、クイズです。
日本人が映画を「必ず最初から」観るようになったのは、いつからでしょうか。
答えは、およそ20年前です。

ところで、いま動画を倍速で観たことのある人は、調査で47パーセント。
10秒飛ばし、スキップ、切り抜き。「最近の人は作品を最後まで観ない」と嘆かれています。
ですが、歴史を見ると、話は逆かもしれません。
江戸の芝居見物のお客さんは、上演の真っ最中に弁当を広げ、酒を飲みました。
気に入らなければ、敷いていた座布団を舞台に投げました。
ナポリのオペラハウスでは、客はしゃべりっぱなし。
作曲家は「どうせ聴かれない時間」のための曲まで書いていました。
人類は、ほとんどの時代、最後まで観ていないのです。
では、「黙って、座って、最初から最後まで」は、いつ、誰が決めたのか。
調べると、犯人には名前と顔がありました。しかも複数犯です。
今日は、その犯人たちを、年代順に逮捕していきます。
最初の現場は、朝六時の江戸です。
```

演出メモ: 冒頭クイズは静かな問題カード (§13-2 準拠)。「座布団を投げました」は土間客が半畳を放る並の絵で最初の笑い。

## 炎上回避 (factcheck 断言可否一覧の遵守)

- **「サイコが世界初」は禁止**。「米国で初めて大々的に途中入場を断った」「定時入場文化の象徴的起点」まで。1955年『悪魔のような女』の先例は余談として自分から出す (ツッコミ封じ)
- **「バイロイト1876=遅刻者入場禁止」の混同禁止**。暗転=1876ワーグナー、遅刻者締め出し=1897〜マーラー、楽章間拍手禁止=20世紀初頭、の3点を必ず分ける
- 江戸の寄席の出入り自由は一次史料未確認 → 本編では芝居小屋 (裏付けあり) を主役にし、寄席は**現代の公式案内** (断言可) で語る。「江戸の寄席も〜だったとされます」まで
- 木戸銭の数字 (36文→48文) は断言可。「いつでも帰れる権利の料金」は史料用語ではないので「いわば〜」の解釈として
- グローブ座の「客が物を投げた」は証拠なし・禁止 (飲食・野次までは可)。半畳投げは**江戸の話**として言う (混同しない)
- 「18世紀の客は誰も聴いていなかった」は禁止 (Weberが否定)。「聴き方が違った」まで
- 幕の内弁当の語源は使うなら「〜という説が有力 (諸説あり)」。本筋に不要なら出さない
- 「ラジオ/テレビで客が静かになった」は禁止。放送が強制したのは「速度と順序」の言い方を守る
- 入替制の「消防法が原因」説は裏取りできず禁止。「全国一斉に何年から」の一点特定もしない
- 倍速デー タは調査主体・年を添える (クロス・マーケティング2021/2024、SHIBUYA109 lab. 2022、を台本では「2024年の調査で」程度に軽く)
- 19世紀の規律化は「都市のエリート文化圏の現象」の限定を落とさない (発明は19世紀のホール、大衆への浸透は20世紀のスクリーン、の二段ロケットを崩さない)
- 倍速視聴を「正しい」とも「堕落」とも裁定しない。観察者で通す
- 画面に出す前に原典確認が要る残リスク: 渡辺裕『聴衆の誕生』の頁単位引用 / クロス・マーケティング2021調査のサンプル数 / NHK「漠然視聴」の時系列% (使うなら要再確認)
