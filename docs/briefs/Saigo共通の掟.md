## 1. この動画の背骨 (全巻で一本に通す)

> **「黙って、座って、最初から最後まで」は人類の伝統ではない。たかだか150年の発明品。倍速とスキップは反逆ではなく、数千年の普通への復帰である**

- 縦糸は**犯人の逮捕劇**: 客席の自由を奪った犯人たち (静けさ/ワーグナー/マーラー/演劇改良会/ヒッチコック/シネコン) を手配書 (`Tehaisho`) で指名手配し、章末ごとに「御用」の朱印を押していく
- 軸は**客席の明かり**: 劇場断面図 (`Danmen`) のランプ5灯が巻を追うごとに消えていき (A→B→C→D)、結び#228でスマホの光として戻る (E)。**オチ (断面図E=150年ぶりの客電) は結びまで絶対に先出ししない**
- 態度は**裁定者ではなく観察者**。倍速・スキップを茶化さない・持ち上げない。「この習慣はいつ誰が作ったのか」だけを描く

## 2. 絵の「格」について ★作者指示 (2026-11-12)

「割合は気にしなくていい。ちゃんと作り込めるなら全部こだわる」。
格は手間の等級ではなく**画面の設計の区別**: **山**=舞台・人・事件・カメラ全部入りの引き / **並**=1つに寄る / **図**=図解が主役。
**並・図も線/色/札/動きの品質は山と同一。** 手を抜いてよい枚は1枚もない。

### 第16条「作り込みの床の法 (素肌禁止)」— いちばん大事
- **素の方眼 (GridPaper) + クリーム地だけの絵は禁止 (担当分で0枚)**。方眼を使うなら「何かの紙」(掲示板・和紙・絵巻・新聞・切符) の上に clip して載せる
- 全シーン、主役を**世界の中に置く**。どこで起きているかが1秒で分かる舞台を敷く
- **地面や壁が素のベタ1色で広く残っていたら未完成。** 小物・質感 (提灯・座布団・板目・棚の中身・観客・遠景) を一段敷いてから出す
- 指示書の表の「絵」欄は**概念**。そこに書かれた主役を、6点法 (①寄る ②世界を置く ③部品を作り込む ④カメラが動く ⑤事件を起こす ⑥人が反応する) で1枚の世界に育てるのがあなたの仕事
- **ただし主役の明快さが最優先。** 背景は彩度低め・線細め・opacity 控えめ
- 密度の手本は `KosoB0.tsx` (約170行/シーン)。**行数は結果であって目的ではない**
- **最悪の失敗は「小さい物をポツンと置く」**。主役は画面の主面積を使う

## 3. 作風の決まり (破ると検査に落ちる)

- **1文 = 1シーン = 1枚の絵。** 骨組みファイルに `Sg001` のような仮の関数が文の数だけ並んでいるので、そこを埋める。各関数の上のコメント (台本文・格・seed・絵) は残し、「どこ:/演出:/動き:」の行をあなたの設計で埋めてよい
- **必ず `f` で動く。静止画は禁止。** `seg(f, a, b)` の **b は 42 以下** (検品プレビューは f=45 の瞬間を写すため)
- **札 (TagPlate) の下端 = y + size*0.85。これを 830 以下にする** (下の字幕帯に隠れる)
- **絵の中の文字はラベル・数値・標識だけ。** 台本の文章は字幕が別レイヤーで出る。セリフ・引用・年号の断定を勝手に書かない
- **札の読点の法**: 札・章扉タイトルに読点「、」を使わない。間は半角スペース
- **数字は指示書にある固定セットのみ。** 表にない数字を画面に描き足さない
- **被りゼロ**: 札・軸ラベル・吹き出しが人物・イラスト・他の文字・字幕帯 (y>830) に重ならない。レンダ後に拡大して確認する
- **連番で同じ物を映すときは絵を複製しない。** 1つのローカル部品に `phase` prop を持たせて切り替える
- **単調禁止 ★作者指示**: 同じ構図・同じ背景の絵を2枚続けない。連続する文で同じ舞台を使うときも、**カメラ (引き⇄寄り・正面⇄斜め)・時間帯・光・配色の差し色のどれかを必ず変える** (phase 切替だけで済ませない)。担当分を描き終えたら並べて見て、似た画面が隣り合っていたら構図を変える
- **motif 名 (`sg_001` 形式)・seed・SCENESキー・export 群は骨組みのまま変えない** (全体の取りまとめが番号で繋いでいる)
- 色はまず `KRP` と `SGP` から。足りなければファイル先頭のローカル `const C = {...}` に追加してよい (KRP/SGP と重複させない)
- 乱数が要るときはファイル内にローカルの `rnd(seed, i)` を書く (毎フレーム違う値になる `Math.random()` は禁止)
- 線の太さは山も図も同じ (輪郭 6〜8、細部 3〜5)。細くして逃げない

### 人物部品 (これを使う。腕を手描きで足さない)
`KarakuriScenes.tsx` の `Person`:
- `pose`: "stand" | "banzai" | "raise" | "point" (+`pointDir`) | "armsFolded" | "run" | "hold"
- `face`: 既存4種 + "joy" (大笑い) / "angry" / "sad" (涙)
- その他: 服の色・ヘルメット・メガネ・髪・視線・たすき・傾き

`PersonMini` (群衆用の簡略キャラ): `x, y, s, color, f, phase, face("dot"|"smile"|"none"), arms("down"|"up")`
→ 客席の群衆・行列は必ずこれを並べる。**人物の画風は共通部品から流用し、章ごとに新しい画風を作らない。**

### 共有装置 (SaigoParts.tsx。読むのは可・変更は禁止)
骨組みに import 済み: `Danmen` `Tehaisho` `SaiseiBar` `NenpyoEmaki` `Fuda3` と色 `SGP`。
**指示書の表で指定された文でだけ使う。それ以外の文で勝手に出さない。**
- `<Danmen f={f} state="A".."E" x? y? s? t?>` — 劇場断面図。s=1 で幅約1700

## 4. 炎上回避 (全巻共通。絵でも破らない)

- 実在人物 (ワーグナー/マーラー/ヒッチコック) は**敬意をもって描く**。茶化し・悪魔化・泣き顔にしない。「犯人」はあくまで芝居の体
- 断定禁止事項を絵の小物でも破らない: 幕の内弁当の語源 / 「本日は帝劇 明日は三越」 / 「サイコ世界初」。この3つは**画面に出さない**
- 倍速・スキップをする人を嘲る絵・英雄化する絵の両方を避ける
- あなたの指示書の「この巻の注意 (ファクト)」を必ず守る

## 5. 進め方 (この順番で)

1. **まず読む**: 自分の指示書 (`docs/briefs/Saigo◯◯.md`) の1文ずつの表
2. **手本を読む**: `KosoB0.tsx` を2〜3シーン分 (密度の手本・部分Read)、`SaigoShared.tsx` (使える部品)、`SaigoParts.tsx` (共有装置の絵柄)、`KarakuriScenes.tsx` は grep → 部分 Read (**丸ごと読まない**)
3. **描く**: 骨組みの `Sg◯◯◯` を埋める。共通の舞台部品はファイル内のローカル部品にして使い回す
4. **型チェック**: `node_modules/.bin/tsc --noEmit` → エラー0 (**自分のファイル以外のエラーは無視してよい**。並行作業中の他ファイルのエラーに手を出さない)
5. **書き出し** (担当が文#26〜#37 なら frames は 25-36。**コマ番号 = 文番号 − 1**):
   ```
   node_modules/.bin/remotion render src/remotion/index.ts SaigoAll tmp/saigo/<小文字の担当名> --sequence --frames=<開始>-<終了> --image-format=png --log=error
   ```
   出力は `element-25.png` など (0詰め桁数は ls で確認)。他の絵師のファイルが壊れていてビルドが失敗したら、**5分待って1回だけ再試行**。それでも駄目なら書き出しを諦めて報告にそう書く (自分で他ファイルを直さない)
6. **検品**: 全枚数を Read で目視 + 札の周辺を拡大して被りゼロを確認
   - 拡大: `ffmpeg -y -i element-25.png -vf "crop=700:400:1220:620" zoom.png`
7. **札の検査**: `npx tsx scripts/koso-plate-check.ts` → 自分のファイルの NG が 0 件 (他ファイルの警告は無視)
8. **書き出しは2巡まで。**
