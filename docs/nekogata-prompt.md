## ③ 文体ルール

- **1行=1文=1枚の絵。** 行の順番を入れ替えない
- **10字未満の行を作らない** (前の文に結合され、絵が1枚消える)
- 数字は半角アラビア数字 (既存作と同じ)。数式は出さない。仕組みは「体の納得」で終わらせる
- 断定してよい所とそうでない所を混ぜない。「〜とされています」「〜と論じています」「〜と伝えられています」は意図的に置いてあるので外さない
- ご視聴挨拶は書かない (`channel.ts` の closingLine と重複する)
- 最終行は結論。`enforce.ts` が最終シーンを結論カードに強制するので、一番効く図 (埋まらない表) は最後から2番目に置く

## ⑥ 台本に入れてはいけないもの (ファクトチェック 使用禁止38項目のうち、台本で踏みやすいもの)

- 「不気味の谷は実証済み」「動物型のほうが受容されやすい」「機能を削るほど愛着が増す」
- 「食物分配がヒトの始まりだった」の断定 / 「共食が信頼・好意を高める」
- モラベックの有名な定式化を**直接引用の形で**出すこと (後世の要約であり本人の言葉ではない)
- 「タイムマシンは物理的に不可能」/「エキゾチック物質は存在しない」
- 「タケコプターで首がもげる」/ 反重力場式に触れずに空力計算を出すこと
- 「暗記パンはググれるから不要になった」(Sparrow 2011 は追試2回失敗) /「糸なし糸電話は予言だった」
- 「ハードウェアは安くならない」(逆。ただし台本では誤りとして訂正する形で使用)
- 「猫型ロボットが生まれるのは○年」という単一の年号 (必ず下限として出す)
- 「動力源は原子炉である」の現在形断定 / 足の浮遊を原作設定とすること・「3mm」の数値
