# 別紙B ── boutou-b.tsx (#11〜#20)

担当は **#11〜#20** の10枚。全部直す。
**手本は `boutou-a.tsx` の #6 (1080行〜)。** 人の描き方の正本なので読んでから始める。

全景にしてよいのは **#11 と #16 の2枚だけ**。残り8枚は寄る。
顔が画面の高さの1/4以上になる寄りを、#12 と #17 で必ず作る。

このファイルは**1988年イラン**と**2026年イラン**をまたぐ。混ぜないこと。
1988年に出してはいけない物: スマートフォン / 液晶 / ペットボトル / LED / SUV。
2026年に出してよい物: スマートフォン / 監視カメラ / 衛星アンテナ / LED看板。

## #11 山「最後まで『勝つまでやめない』と言い続けた最高指導者ホメイニが、停戦を受け入れたのです。」(全景可)

現状は「演台に立つ逆光の影＋群衆の後頭部」。**影を全部やめる。**
**構図** 夕方。演台を**斜め後ろ下から煽る**。ホメイニ師は演台にはいない ──
声はラジオから流れている、という形にする (本人はこのとき公の場に出ていない)。
**出す物** 街頭に据えられた**拡声器つきの鉄柱** / ホメイニ師の巨大な肖像幕 (黒いターバン・
白い顎髭・茶のアバ) / ペルシア語の横断幕 (緑地に白文字) / 緑白赤の三色旗 (中央に赤い
アッラーの意匠) / 殉教者ポスターの壁 / 停戦決議「598」の数字が入った号外
**人 (老若男女)** 黒いチャードルの女性数人 / 襟なしシャツの中年男 / 軍服でない動員兵
(カーキのフィールドジャケット・緑の鉢巻) / 父の肩に乗った男の子 / 松葉杖の若い傷痍兵。
全員が**同じスピーカーを見上げている** (視線をそろえる＝かしこまり)。
**事件** 鉢巻の若者が**手にした小旗をゆっくり下ろす**。歓声ではなく沈黙の絵にする。

## #12 山「そのとき読み上げられた言葉が、『私は、毒の杯を飲み干した』。」

**構図 顔の寄り。** 室内、明かりは天井の一灯だけ。
ラジオの前で**読み上げを聞いている老齢の聖職者の横顔**を大きく。黒いターバンと白い顎髭、
頬の皺、伏せた目、喉のあたり。**顔を黒く潰さない。** 肌にはちゃんと色を入れる。
**出す物** ペルシア絨毯 (幾何学の赤と紺) / 床に置いた真鍮の盆 / estekan (チャイグラス) /
壁の漆喰の剥がれ / 木枠のラジオ / 開いた書物と書見台
**事件** グラスの茶が**最後の一口まで減る**。「飲み干した」を物で言う。杯は手に持たせない
(持たせると演説台にめり込んだ前回の失敗が再発する)。

## #13 図「一番強気だった人が、最後に負けを引き受けてる……」(反応・通知カードが出る)

**出す物** 開いたノート (日本語の走り書き・矢印・「ホメイニ」「玉音放送」) / ボールペン /
積んだ資料のコピー / 蛍光ペンの線 / ノートPCの端 / 冷めたコーヒー
**事件** ペン先が2つの名前を**1本の線で結ぶ**。

## #14 並「そうです。戦争は、負ける側の誰かが『ここでやめる』と言わなければ、終わりません。」

綱引きの比喩は残してよいが、**比喩だけで終わらせない**。
**構図** 真横。綱の**中央の結び目に寄る**。
**出す物** 麻縄の**撚り** (3本撚りを描く) / ほつれた繊維 / 土と砂利 / 手の豆とマメの皮 /
片側は国民服の袖、もう片側はカーキの袖 (どちらの国かを袖で言う)
**事件** 片側が**手を離す**。綱がたわむ。離した側の手の指が開いている。

## #16 山「イランは、その最高指導者を、戦争で殺されました。」(全景可)

**構図** 夜のテヘラン。1117行の「黒い影として抜く」をやめる。**火の側から照らして、
建物にちゃんと色を入れる** (砂色の壁・水色のタイル・白い窓枠が火あかりで橙に寄る)。
**出す物** 公邸の崩れた壁 / 曲がった鉄筋 / 割れた水色のタイル / 消防の放水 /
停電した街区と、通電している街区の境目 / 衛星アンテナ / 救急車の青い灯
**人** 毛布をかけられた住民 (男女) / ヘルメットの消防士 / 携帯で撮る若者 /
抱えられた老人。**全員の顔が見える明るさにする。**
**事件** 消えかけた街灯が**一本だけ点いている**。

## #17 山「後を継いだ息子は、8か月たった今も、公の場に姿を見せていません。」

**構図 顔の寄り…ではなく「顔が無いことの寄り」。**
壁にかかった歴代最高指導者の肖像が2枚。3枚目の額だけ**布が掛かったまま**。
その布の縁と、額の金の縁に寄る。冷たい青白の光、窓の一灯だけ。
**出す物** 額縁の金 / 掛かった白布の皺 / 釘と針金 / 壁の日焼けの跡 (前の額の四角い跡) /
床のペルシア絨毯 / 空の椅子
**人** 布を掛け直している係の男性の**手と袖だけ**を入れる。人がいることは示す。
**事件** 布の端がめくれ、**何も描かれていない下地**が見える。
