なぜ序章だけ良くなったのか

序章の修正でやったことは、結局この6つでした。2章・4章にはこれがほぼ全部ないです。

① 寄る（主役を画面いっぱいに）
序章#4は、タワマンの「足元だけ」を画面いっぱいに描きました。全体像を見せたのは#1の1枚だけです。
→ 対して4章#1は、真っ白な紙の真ん中に人が小さく立っているだけ。4章#15はクリップボードが1枚ぽつん。2章#32は地球儀がぽつん。「遠い」の正体はこれです。

② 世界を置く（白紙に図を浮かせない）
序章は全カットが同じ夜景のなかで起きています。だから10枚が「ひとつの街の話」に見える。
→ 2章・4章はクラフト紙の上に図が浮いているだけ。どこなのかが描かれていないので、ワークシートの挿絵に見えます。「精巧じゃない」の正体はこれです。 線が下手なのではなく、背景がないから情報量が足りない。

③ 共通部品を作り込む
序章ではタワマン（28階・セットバック・バルコニー・航空障害灯・足元のロビー）と古アパート（マンサード屋根・ドーマー窓・鉄柵バルコニー・ガス灯）を1個ずつだけ本気で作って、5枚で使い回しました。1個に手間をかけても5枚ぶん効くから、作り込めた。
→ 2章・4章は1枚ごとに新しい物を描いているので、1枚あたりの手間が薄まって、全部が簡素になりました。

④ カメラが動く
序章は、引き→寄り（#1）、上へスクロール（#3）、スポット→ズーム→室内（#7）と、1枚のなかで視点が移動します。
→ 2章・4章は全部が同じ距離・同じ正面からの図。14枚／32枚ずっと同じ構えなので単調です。

⑤ 1枚に1つ「事件」を起こす
序章#5は建物が上下にひっくり返って人が尻もちをつく。#3は家賃が20万→101万に増えていく。#9は扉が開いて人が出てくる。
→ 2章・4章は「①ロープ ②かご ③滑車」と札を貼って説明しているだけ。説明は正しいけれど、何も起きていない。「面白みに欠ける」の正体はこれです。

⑥ 人が反応する
序章#5の「いたっ」、#4の素通りする通行人。
→ 4章の仕組み図に出てくる人は、かごの中で棒立ちしているだけです。

まとめると

序章で効いたのは「寄る・世界を置く・部品を作り込む・カメラを動かす・事件を起こす・人が反応する」の6つ。2章と4章は、正しい図解ではあるが、この6つが抜けた「説明」になっている。

図解の中身（コロッセオの人力ウインチ、おもりと天秤の関係）自体は間違っていないので、捨てずに、この6つを足して描き直すのが正しいと思います。

ただ、ロープが切れれば落ちてしまう。

その後、動力には電気のモーターが使われるようになります。
そして、高いビルで広まったのが、今にもつながるロープ式です。
ここには、少し面白い工夫があります。
人が乗る箱を「かご」と呼びますが、ロープの反対側には、重いおもりが付いています。
かごが上がると、おもりが下がる。
かごが下がると、おもりが上がる。
井戸のつるべと同じ仕組みです。
おもりが重さを釣り合わせるので、モーターは、かごの重さを全部引き受けずに済みます。
ロープを掛けた滑車をモーターで回し、その摩擦でロープを動かす。
こうして、効率よく人を運べるようになりました。²
ただ、電気で動くようになっても、最初から全自動だったわけではありません。
昔は、かごの中に係員がいて、レバーで動かしたり、止めたりしていました。
それが、ボタンで行き先を選べば、自動で目的の階に止まるようになります。
さらに、モーターの速度を細かく調整して、発進も停止もなめらかになりました。³
今では、何台ものエレベーターをまとめて制御しています。
どのかごを向かわせれば、待ち時間を減らせるか。
混雑する時間に、どう動かせば大勢を運べるか。
そこまで考えて動く仕組みです。⁴
安全に乗れて、高くまで運べて、大勢が毎日使える。
その積み重ねで、上の階も、普通に通える場所になったんです。
