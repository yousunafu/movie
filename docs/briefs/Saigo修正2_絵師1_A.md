## 作業A — 文#3 に「寄り」のカメラと効果音「ドドン」

> #3 「冗談に聞こえるかもしれませんが、本気です。」

作者の指摘: **「少しズームになるような演出があるといいかも。あとハンコ押す瞬間にドドンみたいな効果音入れられる?」**

### A-1 寄りのカメラ

`Sg003` は `SaigoShared.tsx` の `Frame` を使っている。**`Frame` にはカメラの prop がない (変更も禁止)**。
だから `Sg003` の中で、絵の中身を `<g transform="...">` で包んでゆっくり寄る。

```tsx
// ゆっくり寄るカメラ。画面中央 (960,540) を軸に 1.0 → 1.085 倍
const zoom = 1 + easeInOut(seg(f, 2, 40)) * 0.085;
...
<g transform={`translate(960 540) scale(${zoom}) translate(-960 -540)`}>
  {/* 既存の中身をここへ移す */}
</g>
```

- 倍率は **1.085 まで**。これ以上寄せると端が切れる
- 判子が「ドン」と落ちる瞬間だけ、**+1コマだけ 0.004 ほど余分に縮める**ような小さな手ぶれを足すと効く (入れなくてもよい)
- 札や文字が入れ物の中にあると一緒に拡大されるので、**拡大して字幕帯 (y>830) にかからないか**必ず書き出して確認する。かかるなら札だけ `<g>` の外に出す

### A-2 効果音の配線 (この動画で初めて作る仕組み)

いま `Video.tsx` はBGMとナレーションしか鳴らしていない。効果音の仕組みがないので新設する。

**`public/se/` に効果音ラボの mp3 が1,143本入っている (商用可・クレジット不要)。**
使うのは `se/anime/drum-japanese2.mp3` (和太鼓でドドン)。

**① 新規ファイル `src/remotion/karakuri/saigoSe.ts`**

```ts
// 「人類は、昔から飛ばして観ていた」の効果音表。
// motif 名 → そのシーンの何コマ目で何を鳴らすか。
// scenes-data.json は生成物なので、この表はコードの側に置く。
export type SaigoSeCue = {
  file: string;    // public/ からの相対パス
  at: number;      // シーンの先頭から数えたコマ
  volume?: number; // 既定 0.55
};

export const SAIGO_SE: Record<string, SaigoSeCue[]> = {
  // #3 判子が落ちる瞬間に和太鼓のドドン
  sg_003: [{ file: "se/anime/drum-japanese2.mp3", at: 0, volume: 0.5 }],
};
```

**② `Video.tsx`** — `<Series.Sequence>` の中、`<Audio src={staticFile(scene.audio)} />` のすぐ下に足す。

```tsx
{(SAIGO_SE[scene.motif] ?? []).map((cue, i) => (
  <Sequence key={`se${i}`} from={cue.at} name={`se-${scene.index}-${i}`}>
    <Audio src={staticFile(cue.file)} volume={cue.volume ?? 0.55} />
  </Sequence>
))}
```

- `Sequence` と `SAIGO_SE` の import を足す。`Sequence` がまだ import されていなければ `remotion` から足す
- **この作品以外に影響を出さないこと。** `SAIGO_SE` に `sg_003` 以外のキーがなければ他作風では空配列になるので自然に無害だが、心配なら `data.preset === "karakuri"` などの条件で包んでよい。既存の行は消さない
- `scene.motif` というプロパティ名が違っていたら、`Video.tsx` の中で scene の型を確認して正しい名前にする

**③ `at` の値を判子に合わせる**

`Sg003` の中で判子が紙に当たるコマを読み取り (`seg(f, a, b)` の b 付近)、その値を `at` に入れる。
太鼓は鳴り出しが速い音なので **当たるコマちょうど、または1コマ前**。

## 作業B — 文#4 の家系図を「観かた」の系図に描き直す

> #4 「歴史をたどると、そちらのほうが、よほど由緒正しい観かたなのです。」

作者の指摘: **「飛ばし家系図はこの動画の要素 (シネマ・映画とか) の家系図にして」**

いまは人物の家系図のようになっている。これを**「観かたの系図」**に描き直す。人の顔を並べるのではなく、**観る場所・観る道具**を並べた系図にする。

系図の形 (上が古い → 下が新しい):

```
          寄席・芝居小屋 (江戸)          オペラハウス (西洋)
                  └──────┬──────┘
                    活動写真・映画館
                          │
                    テレビ (放送)
                          │
                 ビデオ (巻き戻せる)
                          │
              配信・スマホ (倍速とスキップ)
```

- 各ノードは**四角い木札や額ではなく、その場所・道具の小さな絵**にする (提灯のさがった木戸 / 柱と緞帳のある舞台 / 映写機と銀幕 / ブラウン管 / カセットのビデオテープ / スマホ)
- ノードの下に短いラベル (「寄席」「芝居小屋」「オペラハウス」「映画館」「テレビ」「ビデオ」「配信」)。**年号は書かない**
- 線は細い罫ではなく**墨の筋**。古い世代から新しい世代へ `seg(f, …)` で順に描かれていく
- 「由緒正しい」が主題なので、**いちばん古い段 (寄席・芝居小屋) をいちばん立派に・大きく**描く。新しい段は小さくてよい
- 系図を**何かの紙の上に載せる** (巻物・和紙・古い掛軸)。クリーム地に線だけ浮かぶ絵は禁止
- ★この動画では**倍速・スキップが「先祖返り」**という筋なので、いちばん下のスマホから**いちばん上へ戻る細い矢印**を1本だけ、最後 (f=32〜42) に薄く走らせるとよい

## 作業C — 文#12 を**別の絵に差し替える**

> #12 「映画は最初から最後まで観るもの」。この常識、実はかなりの新顔です。

作者の指摘を確認したところ、はっきり **「別の絵にして、もっとその場を表して」**。
→ **設計書に忠実に描き直すのではなく、新しい絵を一から作る。**「その場」が映っていることが条件。

「この常識は新顔です」をどう絵にするか、方針:

- **場所を描く。** いまの映画館の客席を、後ろの席のあいだから覗いた構図。暗い場内・スクリーンの光・整然と前を向いた頭の列・ひじ掛け・段々になった床・非常口の緑の光
- そこに**「新顔」であることを一点だけ差し込む**。たとえば
  - 客席の最前列に、**まだ値札やビニールのついた新品**のような妙に真新しい一画がある
  - あるいは入口の壁に、**まだ糊が乾いていない貼りたての掲示**が1枚あり、そこに短く「おねがい」程度のラベル (本文は書かない)
  - どちらか**一つだけ**。両方やると主役がぼける
- 禁止: 商品棚・値札がずらっと並ぶ構図 (前の案。作者が却下した方向)
- 禁止: 「新顔」を文字で説明すること
- 暗い場内なので、**人の輪郭はリムライト (スクリーン側からの縁の光) で分離**する。真っ黒のシルエットだけにしない
- カメラは**寄り〜中寄り**。小さい物をポツンと置くのが最悪の失敗
