### C-1 「水道の圧力で届くのは、だいたい5階か6階まで」 → 国を分けて言う
- 日本の水道法上の保証圧力は **0.15MPa**。これで上がるのは実質 **2〜3階**。
- 「5〜6階」は米国の数字。NYCの道路本管は 40〜80 psi (約0.28〜0.55MPa) あるため6階程度まで届く。
- 出典: 厚労省 水道施設の技術的基準 / NYC DEP "Water Pressure" ページ
- **v7**: 「日本の水道が保証する圧力は、2階か3階まで。」「ニューヨークでも、だいたい6階が限界です。」

### C-2 「木製のものが、いまも5千基以上あるそうです」 → 木製だけの公式統計は存在しない
- **木製タンクの基数を数えた公的統計はない。**
- よく出回る「5,600」は Vital City の**材質を問わない**推計。Economic Times の見出しが "wooden" を付けて変質させたもの = 典型的な数字の伝言ゲーム。
- 調査担当が NYC Open Data (データセットID `gjm4-k24g`) から独自に再集計 → **全材質で約6,000基**。
- **v7**: 「市が把握している給水タンクは、約6千基。」「木の桶は、いまも何千基も現役で働いています。」(基数は全材質、木製は「何千基」と幅で言う)

### C-3 「あの豪華な天井飾りは、煤の跡を隠す道具でした」 → 俗説
反証3つ:
1. 当時の意匠書にその機能の記述がない
2. 電化後も天井飾りは作られ続けた
3. 天井メダリオンの意匠は家庭用ガス灯より **1世紀古い**
- ただし**救える事実**があった → G-4へ
- **v7**: 「煤隠し」の断定を削除し、炎の向きと換気穴の実物に差し替え

### C-4 「そして1960年代。エアコンが来ます」 → 家庭普及は1980年代後半
- 日本の家庭用エアコン普及率: **1970年で5.9%**、50%超えは **1985年**。
- 一方で**ビルの空調**は1960年代で正しい (霞が関ビル 1968年竣工)。
- 出典: 内閣府 消費動向調査
- **v7**: 「ビルに、空調が入ります。」「家庭に行き渡るのは、1980年代の後半です。」と二段に分ける

### C-5 「いまのタワーマンションの窓は、ほとんど開きません」 → バルコニー側は開く
- 開かないのは主に高層部の非バルコニー面。バルコニー側の引き違いサッシは開く。
- **v7**: 「全開にできません。」に修正

### C-6 「玄関のドアが重い日があるのは、これ(煙突効果)のせいです」 → 原因が違う
- 住戸の玄関ドアが重いのは **住戸内の負圧**。換気扇の排気量に給気口が追いつかないため。
- 出典: 日本鋼製軽量ドア協議会
- 煙突効果は**実在するが作用先が別**: 建物全体のエントランスとエレベーター扉。41階建ての実測研究あり (30Pa超で笛のような音)。
- **v7**: 負圧の説明 → そのうえで煙突効果を「建物の玄関とエレベーターの扉」に向け直す (2段構成)

### C-7 「最初の17年で54棟」 → 出典が見つからない
- 不動産経済研究所のデータから逆算すると 17年で約63棟、15年で約40棟。**どの区切りでも54にならない。**
- **v7**: 出典のある数字に総入れ替え → 「首都圏の完成は、1997年に10棟。」「2000年には、1年で31棟。」「いまは、1000棟を超えています。」

### C-8 「基礎にゴムを挟み、建物の中に重りを入れる」 → 日本の制振は主にダンパー
- マスダンパー (重り) は**風揺れ**対策。地震対策の主流は**油圧・粘性ダンパー**。並べると誤解を生む。
- **v7**: 「建物の中に油の筒を仕込んで、揺れを熱に変える。」「硬くして耐えるのではなく、逃がして捨てるんです。」

### C-9 「だから高い建物には、空気用の管が別に走ります」 → いまは一本の管
- 現代の日本の超高層は **特殊継手排水システム**。継手の形で管の中心に空気の芯を作り、**一本の立管**で水と空気をすれ違わせる。別系統の通気立管は古い方式。
- **v7**: 「昔は〜別に走らせていました。」「いまは、継手の形で管の中心に空気の芯を作ります。」と時系列で書く

## G判定 (新たに得た使える事実) → v7に追加

- **G-1 超高層の水槽は現役**: ポンプ1台で押し上げられるのは約16階。だから15階ごとに水槽で縦に区切る (ゾーニング)。「屋上タンクは過去のもの」は言い過ぎだった。
- **G-2 木桶に釘がない理由の続き**: 鋼のたがで外から締め上げるだけ。**水を入れると、はじめは漏れる。**木が吸水して膨らみ、すきまが自分で閉じる。(「はじめは漏れる」が入って初めて絵になる)
- **G-3 高さと風速**: 地上10mと100mで風速は約2倍。
- **G-4 ガス灯の炎は上向きだった**: 1897年の改良まで炎は上を向いていた → **天井がまっさきに黒くなる**。そして天井飾りの奥の窪みには**換気の穴が隠されていた** (実物がある)。「煤隠し」(俗説) より強い事実。
- **G-5 1997年の容積率改正**: 共用廊下が容積率算定から除外された。同じ土地に売れる部屋をもっと作れる = タワマン急増の制度的引き金。1997年10棟 → 2000年31棟。
