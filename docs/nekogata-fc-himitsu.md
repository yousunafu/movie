## 最重要の前置き：3つの「不可能」を混ぜないこと

この章の値打ちは区別にあるので、まず語彙を固定しておく。

| 区分 | 意味 | 該当例 |
|---|---|---|
| **(i) 物理法則が禁じている** | 既知の保存則・不等式に正面から反する。技術進歩では動かない | 四次元ポケット（質量エネルギー保存）、スモールライト（原子サイズ・質量保存）、ほんやくコンニャクの「万能性」ではなく道具の質量側 |
| **(ii) 工学的に無理（法則違反ではない）** | 法則は許すが、必要な数値が実現可能値から桁で外れている | タケコプター（プロペラ説。空気力学＋電池） |
| **(iii) 原理が未解決** | 現在の物理学で可否が決着していない | タイムマシン、通過可能ワームホール、どこでもドア |

**タイムマシンを「物理的に不可能」と言うと嘘になる。**（§10参照）これは本章で最も踏みやすい地雷。

# ① もう追い越した組

## 1. ほんやくコンニャク vs 現実のリアルタイム翻訳

### 作中設定・初出

- 道具: 食べると外国語が理解でき、話した言葉も相手に通じる。
- 初出: **「ゆうれい城へ引っこし」（てんとう虫コミックス12巻）／雑誌初出は『週刊少年サンデー』1976年6月増刊号、原題『古城のゆうれい』** とされる。
- **判定: B（初出年は要注意）** 複数の二次資料（pixiv百科事典、Wikipedia、ファンサイト）で一致はしているが、小学館の公式資料や『藤子・F・不二雄大全集』で直接確認はできていない。**「1976年」と断定で言うなら作者側で大全集の収録情報を確認してほしい。**「1970年代半ば」程度にぼかせば安全。
- 出典: https://ja.wikipedia.org/wiki/%E3%81%BB%E3%82%93%E3%82%84%E3%81%8F%E3%82%B3%E3%83%B3%E3%83%8B%E3%83%A3%E3%82%AF / https://dic.pixiv.net/a/%E3%81%BB%E3%82%93%E3%82%84%E3%81%8F%E3%82%B3%E3%83%B3%E3%83%8B%E3%83%A3%E3%82%AF / 雑誌掲載日の網羅的書誌: https://qden.my.coocan.jp/ff/doraemon/book/tc1.html

### 現実が「上回っている」点

**(a) テキスト翻訳の品質は、すでに職業翻訳者の訳を上回る水準に達した（WMT25, 2025年）— 判定: A**

WMT25 General MT タスクの人間評価（Error Span Annotation プロトコル、プロの注釈者）で：

- 最優秀は **Gemini 2.5 Pro**。評価対象15言語対のうち **14言語対でトップクラスタ**に入った。
- **人間のリファレンス訳（official human translations）がトップクラスタに入ったのは15言語対中わずか6つ**。
- 仕様（specification）を与えたLLM訳は、公式の人間訳を人間評価で一貫して上回った。

出典: https://aclanthology.org/events/wmt-2025/ / 速報ランキング https://arxiv.org/pdf/2508.14909 / 仕様準拠翻訳 https://aclanthology.org/2025.wmt-1.7.pdf

→ 台本で使える強い事実。「コンニャクはのび太の国語の点数を上げなかったが、現実の翻訳機はプロの翻訳者の点数を超えた」。

**(b) 音声認識は2017年に人間パリティを達成 — 判定: A**

Microsoft の会話音声認識システムが Switchboard 2000 評価セットで **単語誤り率 5.1%** を記録。これは複数書き起こし者プロセスで測定された人間の 5.1% と同値で、会話音声で人間パリティが報告された初の事例。

出典: https://arxiv.org/abs/1708.06073 (The Microsoft 2017 Conversational Speech Recognition System) / 前段論文 https://arxiv.org/pdf/1610.05256 / 解説 https://www.microsoft.com/en-us/research/wp-content/uploads/2017/08/ms_swbd17-2.pdf

**(c) 遅延（同時性）: イヤホン型で0.2〜2秒台 — 判定: B**

- Timekettle W4 Pro クラスの翻訳イヤホンで**遅延 約0.2秒**、同時通訳モード対応との製品側主張。
- クラウド処理型は一般に **1〜3秒**。
- Google Pixel の Live Translate は **Pixel 8 Pro で平均0.9秒、Pixel 7a で1.3秒**（レビュー媒体の実測値）。Pixel Buds 経由では **1往復2〜4秒**。
- **2026年9月以降、Live Translate がオフライン動作に対応**（Pixel 9/10/11系。NPU・メモリ増強が条件）。

出典: https://www.soundguys.com/best-translation-earbuds-2-152438/ / https://cybernews.com/reviews/best-ai-translation-earbuds/ / https://www.androidpolice.com/google-translate-offline-live-translate-release/ / https://www.androidauthority.com/google-pixel-live-translate-3221949/

**判定を B にした理由**: これらはメーカー公称値とレビュー媒体の実測で、査読を受けた独立測定ではない。「0.2秒」は特にメーカー主張。「99.8%の精度」という製品宣伝文句は**C（使用禁止）**。台本では「数百ミリ秒から数秒」と幅で言うのが安全。
※ 学術側の同時音声翻訳の遅延指標そのものに測定の落とし穴があるという指摘もある（Computation-Aware Latency）: https://arxiv.org/pdf/2410.16011

### 現実が「まだ負けている」点 ← ここが章の面白みになる

**(d) 小言語・方言 — 判定: A**

- IWSLT 2025 は「方言・低資源音声翻訳」を7つの主要課題のひとつとして独立トラック化している。つまり**まだ課題**。
- 方言音声処理には「多言語性の呪い（Curse of Multilinguality）の方言版」が存在し、**複数方言を同時学習すると単一方言の性能が下がる**。
- 低資源言語は文芸・ニュース・会話など領域ごとに性能が崩れる。**自動評価のランキングが人間評価と一致しないため、人間評価が最終審判であり続ける**と明記されている。
- 「データ可用性が真に言語包摂的な音声翻訳の鍵となる障壁」として、IWSLT 2025 はデータトラックを新設した。

出典: https://aclanthology.org/2025.iwslt-1.44.pdf (Findings of the IWSLT 2025 Evaluation Campaign) / https://aclanthology.org/2025.wmt-1.22.pdf (WMT25 General MT Findings) / https://aclanthology.org/2025.wmt-1.29.pdf (低資源インド諸語) / 取り残される言語 https://arxiv.org/pdf/2508.20511

**(e) 話者の意図・敬語・社会的距離（語用論） — 判定: B〜A**

- 語用論は話者の意図・文化的ニュアンス・感情のトーン・社会的適切さを担うが、ここが依然大きな課題。文脈固有の文化スキーマへの感度を欠くと**話者の意図を反転させる**出力が出る。
- **日本語の敬語は、そうした体系を持たない英語などからの翻訳で中核的な難所**。敬意・謙譲・改まり・社会的距離の層が、他言語より広範な発話全体の書き換えを要求する。
- 最新の評価研究でも、**とくに敬語の次元でLLMは人間の判断に及ばない**。
- 文単位の性能が飽和した一方、**文書単位（代名詞の一貫性、未訳セグメント）の評価は未成熟**。2025年時点でも、深い理解と言い換えを要する翻訳問題では、トップMTシステムも人間の初心者同様につまずく。

出典: https://www.ijscl.com/article_727173_927fc7617b203fde62de5847994b0b2b.pdf (Pragmatic and Cultural Challenges in MT) / https://arxiv.org/pdf/2311.11976 (英日ビジネス対話の文脈考慮NMT) / https://aclanthology.org/2025.wmt-1.10.pdf / 意図・聞き手適合 https://arxiv.org/pdf/2606.03259 / 会話の伝達成功度評価 https://arxiv.org/pdf/2609.19885

**(f) コンニャクに原理的に負けている点（台本向けの対比軸） — 判定: A（論理的指摘として）**

現実の翻訳機が構造的に持てないもの：
1. **「全言語」ではない**。コンニャクは未知の言語・動物の言葉にも効く設定。現実は訓練データのある言語だけ。
2. **双方向の装着が不要**。コンニャクは自分が食べれば相手にも通じる。現実は相手側の機器か自分の発話の再生が必要。
3. **遅延ゼロ**。原理上、現実の同時翻訳は語順の違う言語対で「待ち」が消えない（これが simultaneous translation 研究の中心課題そのもの）。

→ **章の着地点に直結**: 現実は「品質ではコンニャクを超え、万能性と同時性では負けている」。そして我々はその超えた部分に、のび太ほど喜んでいない。

## 2. 糸なし糸電話・テレビ電話 vs スマートフォン・ビデオ通話

**判定: C（この道具での「予言」構成は使わないほうがよい）**

理由：**現実のほうが先行しているか、ほぼ同時期である。**

- **糸なし糸電話**: 二個一対の筒型で、片方からもう片方に通話できる道具。初出情報が二次資料間で食い違う。「てんとう虫コミックス1巻105ページ」説、「『小学一年生』1985年12月号」説、「てんとう虫コミックススペシャル『ドラえもん カラー作品集』第1巻収録」説が並立。**初出年は確認できず。**
  - 出典（いずれも二次）: https://dic.pixiv.net/a/%E7%B3%B8%E3%81%AA%E3%81%97%E7%B3%B8%E9%9B%BB%E8%A9%B1 / https://www.doraemondb.com/ddb/index.php?item=%E3%81%84%E3%81%A8%E3%81%AA%E3%81%97%E3%81%84%E3%81%A8%E3%81%A7%E3%82%93%E3%82%8F / https://ja.wikipedia.org/wiki/%E3%83%89%E3%83%A9%E3%81%88%E3%82%82%E3%82%93%E3%81%AE%E3%81%B2%E3%81%BF%E3%81%A4%E9%81%93%E5%85%B7_(%E3%81%84%E3%81%82-%E3%81%84%E3%81%A8)

- **現実側はドラえもん連載開始（1970年1月号）とほぼ同時 — 判定: A**
  - **1970年の大阪万博**で、電電公社（現NTT）の電気通信館が**「ワイヤレステレホン」＝携帯電話の原型**を展示。重量660g。約400m²の部屋に約100ブース、**約65万人**が実際に手に取って場内・全国通話を体験した。1回の充電で9時〜21時の約12時間使用可能。親指で押す人が多い等の知見がのちのPHS・携帯開発に反映された。

## 3. 暗記パン と「デジタル・アムネジア／Google効果」

### 作中設定・初出

- 道具: スライスされた食パン。ノートや本のページに押しつけると内容が表面に写り、食べると**完璧に暗記できる**。効力は**消化・排便されるまで**という設定。
- 初出: **「テストにアンキパン」（てんとう虫コミックス2巻 第1話）／雑誌初出は『小学三年生』1972年5月号** とされる。
- **判定: B** 道具の機能・排便オチの設定は複数資料で一致し信頼できる。初出号は二次資料のみ。
- 出典: https://dic.pixiv.net/a/%E3%82%A2%E3%83%B3%E3%82%AD%E3%83%91%E3%83%B3 / https://doraemon.fandom.com/ja/wiki/%E3%82%A2%E3%83%B3%E3%82%AD%E3%83%91%E3%83%B3 / 小学館公式: https://dora-world.com/sp/tencomi_detective/zannen/zannen_vol001.html

### ★★ Google効果の学術的強度 — 厳しく判定した結果：**C（「Google効果で暗記が不要になった」という使い方は禁止）**

ご指示どおり厳しく見た。**この論点は便利に使われすぎており、中核実験は2回とも再現に失敗している。**

**(1) 原論文**
Sparrow, B., Liu, J., & Wegner, D. M. (2011). *Google Effects on Memory: Cognitive Consequences of Having Information at Our Fingertips.* **Science**, DOI: 10.1126/science.1207745。4つの実験から、(a) 難問に直面すると人はコンピュータを想起するようプライミングされる、(b) 将来その情報にアクセスできると期待すると**情報そのものの再生率が下がり、保存場所の再生が向上する**と主張。
出典: https://www.semanticscholar.org/paper/52efd857b500531e040a9366b3eb5bb0ea543979

**(2) 再現失敗 その1 — 大規模プロジェクト**
Camerer et al. (2018), *Evaluating the replicability of social science experiments in Nature and Science between 2010 and 2015*, **Nature Human Behaviour**。Science/Nature掲載の社会科学実験21本を直接再現。**13/21（62%）が再現成功、8本が失敗。Sparrow et al. 2011 の Experiment 1（「Google Stroop」プライミング課題）は失敗した8本の側**。再現の効果量は原論文の約半分、サンプルは平均で約5倍に増やしてなおこの結果。失敗した8本の平均相対効果量は**ゼロにきわめて近い**。
出典: https://www.nature.com/collections/nfkchhxllx / 本文PDF https://pure.eur.nl/ws/files/37359856/Camerer_et_al._2018_Evaluating_the_replicability_of_social_science_experiments_in_Nature_and_Science_between_2010_and_2015.pdf / 事前登録レポート http://www.socialsciencesreplicationproject.com/src/pre-reports/Sparrow%20et%20al%20(2011)%20-%20Pre-Data%20Collection%20Replication%20Report.pdf

**(3) 再現失敗 その2 — 専用の追試**
Hesselmann, G. (2020). *No conclusive evidence that difficult general knowledge questions cause a "Google Stroop effect". A replication study.* **PeerJ**。Sparrow本人の後年の助言を取り入れた設計で追試。十分な検定力下で有意な効果なし。逐次ベイズ因子分析で **N=89 時点で BF01 = 5.07（帰無仮説を約5倍支持）**。語頻度を予測子に含まないモデルが含むモデルより16倍好まれた。
出典: https://pmc.ncbi.nlm.nih.gov/articles/PMC7651475/

**(4) 概念そのものへの批判**
「Google効果は transactive memory（交換記憶）か」という点に疑問が出ている。**人とコンピュータの間に「取引（transaction）」は起きていない**し、従来の交換記憶と違い**インターネットがなくても情報は失われず、ただ遅く面倒になるだけ**だ、という指摘。
出典: https://en.wikipedia.org/wiki/Google_effect

**(5) 「誇張されている」という整理**
McGill大学 Office for Science and Society「Digital Amnesia Has Been Exaggerated」。
出典: https://www.mcgill.ca/oss/article/critical-thinking-technology/digital-amnesia-has-been-exaggerated
総説レベルでも、デジタルメディアの認知成績への集約的効果はしばしば些少で、「デジタル認知症」の恐怖は大幅に過大評価という評価が出ている。

**(6) ただし「認知的オフロード」自体には再現性のある効果がある — 判定: B（こちらは使える）**

Google効果（プライミング）はダメだが、**別の現象は再現されている**。
- **Saving-enhanced memory（保存による記憶増強）**: Storm & Stone (2015)。一時的に不要な情報を外部に保存（オフロード）すると、**保存しなかった新しい情報の記憶成績が上がる**。認知資源の解放／干渉の低減によると説明される。
- これは**追試で再現されており（robust）**、さらに無関係な認知負荷課題の成績まで上がる「saving-enhanced performance」も確認された。
- 境界条件: **保存が信頼できるときにのみ効果が出る**。
- 出典: https://pubmed.ncbi.nlm.nih.gov/31418314/ (Saving-enhanced performance) / https://link.springer.com/article/10.3758/s13421-024-01545-4 / https://onlinelibrary.wiley.com/doi/full/10.1002/acp.4067 / https://escholarship.org/content/qt0tk0k8zf/qt0tk0k8zf_noSplash_b48964ec9fa8341b55dc93aab4cc5f86.pdf
- 2024年のメタ分析レビューでは、Google効果は「存在するが、外部ストアの信頼性・デバイス種別・認知負荷に強く調整される」と整理されている（**B**）。
  出典: https://www.researchgate.net/publication/377493989_Google_effects_on_memory_a_meta-analytical_review_of_the_media_effects_of_intensive_Internet_search_behavior / 2025年の系統的レビュー https://www.researchgate.net/publication/398155009_REVISITING_THE_GOOGLE_EFFECT_A_HYBRID_SYSTEMATIC_REVIEW_AND_BIBLIOMETRIC_MAPPING_OF_INTERNET-DRIVEN_MEMORY_OFFLOADING

### 台本への推奨（書き換え案）

- ❌ **使うな**: 「研究によれば、人はスマホがあると覚えなくなる（Google効果）」
- ❌ **使うな**: 「暗記の必要性は外部記憶で消えた」（学術的裏づけなし。かつ価値判断を事実に偽装している）
- ✅ **使える**: 「『検索できると人は覚えなくなる』という有名な2011年の研究があります。ただしこの研究の中心的な実験は、2018年の大規模再現プロジェクトと2020年の専用追試で、**2回とも再現に失敗しました**。にもかかわらずこの話は今も引用され続けています」
  → **これ自体が章の逆説と噛み合う。** 我々は暗記パンを手に入れたと思い込みたがっている。思い込みのほうが研究より強い。これは「持っているのに喜んでいない」の裏返しの良い素材。
- ✅ **使える**: 「ただし別の効果は再現されています。**保存できると、保存しなかったことをよく覚える**。暗記パンは、暗記の代わりではなく、暗記の前処理だった」

## 7. タケコプター — 自前の計算

### ★★ まず最大の落とし穴（これを知らずに語ると批判される）

**判定: B（だが台本では必ず触れること）**

**公式設定上、タケコプターはプロペラで飛んでいない可能性が高い。**

- 1980年『ドラえもんひみつ全百科』では**揚力発生タイプ**として紹介され、揚力は**100kg型と200kg型**の設定があった。プロペラは「スーパーウイング」と命名されていた。
- **1986年以降の各種百科本では、反重力場を発生させるタイプの図解に変更**された。
- 藤子・F・不二雄の発言として「**上のプロペラが回るのは正常に動いているというパイロットランプで、あれで飛んでいるわけではない**」が伝えられている。
- 出典（いずれも二次。**一次確認できず**）: https://ja.wikipedia.org/wiki/%E3%82%BF%E3%82%B1%E3%82%B3%E3%83%97%E3%82%BF%E3%83%BC / https://dic.pixiv.net/a/%E3%82%BF%E3%82%B1%E3%82%B3%E3%83%97%E3%82%BF%E3%83%BC

**台本上の正しい扱い（推奨の構成）**:
1. 「見た目どおりプロペラだとしたら」→ 以下の計算で**工学的に桁違いに不可能**。これは A ランクで断定できる。
2. 「公式設定は反重力だとされている」→ 不可能の理由が**別物に変わる**。負の質量／反重力は観測されていない（§11）。これで**③に残る**が、理由は「空気力学」ではなく「未発見の物理」。
3. この2段構えが、章のテーマ（3つの不可能を混ぜない）の最良の実演になる。

### 7-1. 前提と式

ホバリングの運動量理論（アクチュエータ・ディスク理論）。前提：
- 空気密度 ρ = 1.225 kg/m³（ISA 海面）
- 重力加速度 g = 9.81 m/s²
- 人の体重 m = 60 kg → 必要推力 **T = mg = 588.6 N**（装置自体の質量は当面無視）
- ローター面積 A = πD²/4

| 量 | 式 |
|---|---|
| ディスク荷重 | DL = T / A |
| 誘導速度（吹き下ろし） | v_i = √( T / (2ρA) ) = √( DL / (2ρ) ) |
| 理想誘導パワー | **P_ideal = T · v_i = T^(3/2) / √(2ρA)** |

**最重要の関係**: T 一定のとき
**P_ideal ∝ 1/√A ∝ 1/D**
→ **直径を半分にすると必要パワーは2倍になる。** これがこの節の背骨。

実機換算には2段の効率を掛ける：
- ホバー効率（Figure of Merit）FoM ≈ 0.7 → 軸出力 = P_ideal / 0.7
- モーター＋ESC 効率 ≈ 0.85 → 電気入力 = 軸出力 / 0.85
- 合計 η ≈ 0.7 × 0.85 ≈ **0.60**

### 7-4. ★ さらに硬い壁：ブレード荷重と翼端マッハ数（判定: B、ただし論旨は強い）

パワーを用意しても解決しない壁がある。**小さな円盤から大きな推力を出すには、ブレードを超音速で回さなければならない。**

推力係数（ロータークラフト標準定義）: C_T = T / (ρ A (ΩR)²)
→ 必要翼端速度 **ΩR = √( T / (ρ A C_T) )**

C_T の上限は失速で決まる。ブレード荷重 C_T/σ の実用上限 ≈ 0.12–0.14。σ（ソリディティ）を非常に大きく 0.25–0.3 に取っても **C_T,max ≈ 0.035 程度**。
（検算: 5インチ3枚ペラのレーシングドローン実測相当 — D=0.127 m, 推力1.5 kgf, 25,000 rpm で C_T ≈ 0.034。実機はまさにこの限界で回っている。）

## 8. 四次元ポケット

### (a) 余剰次元は「仮説として存在するが、物を入れる場所ではない」 — 判定: A

カルツァ=クライン理論やひも理論のコンパクト化で余剰次元は真剣に研究されている。**が、実験が許す余剰次元の大きさは、物を入れられる寸法から20桁以上離れている。**

**実験的上限（2つの独立な系統）**

1. **LHC（高エネルギー側）**: 普遍的余剰次元（UED）模型で、コンパクト化スケールの下限 **R⁻¹ ≳ 715 GeV**、第2KK粒子の質量 **M ≳ 1.4 TeV**。KKグルーオンでは HL-LHC で5.7 TeV まで到達見込み。
   - **換算（自前）**: R ≲ ħc / 715 GeV = 1.97×10⁻¹⁶ GeV·m / 715 GeV = **約 2.8×10⁻¹⁹ m**。
   - 比較: 陽子の半径は約 0.84×10⁻¹⁵ m。→ **余剰次元は陽子の約3,000分の1より小さい。**
   - 出典: https://arxiv.org/abs/1302.6076 / https://web.mit.edu/8.882/www/material/lecture_24.pdf / レビュー https://indico.fnal.gov/event/1965/contributions/53382/attachments/33212/40735/080818_Ponton.pdf

2. **卓上重力実験（低エネルギー側／「大きな余剰次元」仮説の検証）**: Eöt-Wash のねじれ天秤で、**52マイクロメートルから3ミリメートルの距離でニュートンの逆二乗則を検証**。95%信頼度で**長さスケール39マイクロメートル超の重力強度湯川型相互作用を排除**、8–90マイクロメートルの範囲に新たな制限。**→ 余剰次元があっても30マイクロメートル以下**（髪の毛の太さ以下）。

### (b) ワームホール（アインシュタイン=ローゼン橋） — 判定: B

- **理論的位置づけ**: Morris–Thorne（1988）が通過可能ワームホールの概念を導入。維持には**負のエネルギー密度をもつ「エキゾチック物質」**が必要で、標準的なエネルギー条件を破る。
- **量子不等式（Ford–Roman 1995）**: 「エネルギー密度と固有時間の量子不確定性型の関係」。**負のエネルギー密度が大きくなるほど、持続時間は短くなければならない**。
- **帰結**: Ford–Roman の制約により、仮にマクロなワームホールを作れても**旅行には使えない**可能性が高い。場の量子論が「マクロなワームホールに対する宇宙検閲官」として振る舞う。エキゾチック物質は**極端に薄い帯状領域に限られるか、大きな赤方偏移を伴う**ことになり、巨大な潮汐力などの重大な困難が生じる。
- 出典: https://arxiv.org/abs/gr-qc/9510071 (Ford & Roman, Quantum Field Theory Constrains Traversable Wormhole Geometries) / レビュー https://arxiv.org/pdf/0710.4474 (Lobo, Exotic solutions in GR: Traversable wormholes and 'warp drive' spacetimes) / https://link.aps.org/pdf/10.1103/PhysRevD.72.044023 (任意に小さなエキゾチック物質量でのワームホール)

- **負のエネルギーは「存在しない」のではない**。カシミール効果やスクイーズド状態で局所的な負のエネルギー密度は現れる。Ford–Roman が問うたのは**「存在するか」ではなく「どれだけ、どのスケールで許されるか」**。→ **ここを「エキゾチック物質は存在しない」と断言すると誤り。「量のオーダーが許されない」が正しい。**

### (c) エネルギー保存：「ポケットに入れた質量はどこへ行くのか」 — 判定: A（論理として）

- 一般相対論において、ワームホールは**時空の2領域を結ぶ**。物を通したなら、質量エネルギーは**消えずに向こう側に移動している**。つまり四次元ポケットは「無限の収納」ではなく「別の場所への輸送」でしかなく、**どこかに同じ質量が存在し続ける**。
- 「ポケットが物を小さくして収納している」と解釈すると、§11 のスモールライトと同じ**質量エネルギー保存の問題**に戻る。
- ポケットが口の面積に関係なく大きいものを吸い込む描写は、入口の断面積と内部体積の整合という幾何学の問題（通過可能ワームホールでは入口のサイズ以上の物は通せない）。
- **判定理由**: これは既存の法則からの演繹であり、固有の論文を要しない。ただし「質量が消えるとエネルギー保存に反する」を断定するのは A、「だからポケットは物理的に不可能」は **(i)** に分類して A でよい。

**→ 判定: 「物理学はタイムマシンを完全に禁じていない。未解決である。」= A**
**→ 「物理法則が時間旅行を禁じている」= C（使用禁止）。**

### (c) パラドックスと整合性原理 — 判定: A

**ノビコフの自己整合性原理**
- 因果ループ上の力学に対して**自己整合的な解のみが起こる**とし、局所的な物理は変わらないままとする。
- **過去を変える事象は確率ゼロで起こる**。自己矛盾的な出来事をすべて排除すれば、**タイムトラベルのパラドックスは消える**。
- → つまり「親殺しのパラドックス」は、**論理的に時間旅行を不可能にするのではなく、起こりうる出来事の集合を制限する**。

**ブートストラップ・パラドックス（因果ループ）**
- **ある情報や物体が CTC 上にのみ存在し、したがって無から生じたように見える**ときに生じる。「どこからともなく来た」自己存在的な物体や情報。
- **現代の扱い**: ブートストラップ的な状況は、時空と物質を支配する方程式の**特定の解として理解され、大域的整合性を認めればパラドックスはない**。
- **量子版（Deutsch の CTC モデル）**: CTCが整合的であるには各ゲートの発展作用素が**不動点**を持つ必要があり、**量子の場合は不動点が常に存在する**（古典では存在しないことがある）。固定点密度行列によって自己整合的な状態が許され、それが情報ループに対応しうる。
- 出典: https://en.wikipedia.org/wiki/Quantum_mechanics_of_time_travel / https://arxiv.org/pdf/1911.11590 (Time-Travel Paradoxes and Multiple Histories) / https://arxiv.org/pdf/2004.12921 (祖父パラドックスと情報アンチノミーの等価性) / https://philarchive.org/archive/SFECLI (Causal Loops in Time Travel) / https://arxiv.org/pdf/2205.05399 (量子波束の billiard-ball パラドックス)

### (d) 企画の結び「先に生まれると、生まれる理由が消える」について — 判定: B（言い方に注意）

これは**ブートストラップ・パラドックスそのもの**ではなく、やや違う。整理すると：

| 言い方 | 正確さ |
|---|---|
| 「ブートストラップ・パラドックス＝情報や物体が因果ループ上にのみ存在し、無から生じたように見える」 | **A** |
| 「ブートストラップ・パラドックスは論理矛盾だから時間旅行は不可能」 | **C** — 現代の扱いでは、大域的整合性を認めればパラドックスではない |
| 「猫型ロボットが先に生まれると、それを作る動機（＝未来から来た理由）が消える」 | **B** — これは因果ループ構造の比喩として成立する。ただし「パラドックスだから矛盾する／不可能」とは言わないこと。「自己整合的な解しか起こらない」（ノビコフ）というのが物理側の答えで、**矛盾が消える方向に世界が整う**という、むしろ怖い結論になる |

→ **推奨の言い方**: 「因果ループは論理矛盾ではない、というのが今の物理の立場です。矛盾しそうな出来事は**起こらない**。つまり『先に生まれると生まれる理由が消える』のではなく、**生まれる理由が消えるような生まれ方は、そもそも起こらない**。物理は辻褄を合わせる側に回る。」

### (e) タイムマシン総合判定: **③ に入れてはいけない — A**

**これは「永久に来ない」ではなく「(iii) 原理が未解決」。** ③を「物理法則の側が禁じている道具」と定義しているなら、**タイムマシンはその定義に合致しない**。
**構成上の推奨**: ③の中に「**④ 物理学もまだ答えを出していない**」という第4の箱を一瞬だけ作るか、③の最後に「ところが1つだけ、物理学が『禁じた』と言えない道具がある」と置く。**そのほうが章の格が上がり、かつ正確。**

### 11-1. ★ スモールライト（物体の縮小） — 判定: A（ただし作中設定は B）

**作中設定**
- 懐中電灯型。光を当てた物体を縮小。当てる時間が長いほど小さくなり、縮小率を調節できる。
- 初出は「ねずみこわーい」（『小学一年生』1970年4月号）とされる（**二次資料のみ。B**）。
- **質量についての公式設定は見つからなかった（確認できず）。** 小さくなった人や物を軽々と運ぶ描写があるため「軽くもなっている」と推測されるが、描写は一貫していないとされる。
- 出典: https://ja.wikipedia.org/wiki/%E3%82%B9%E3%83%A2%E3%83%BC%E3%83%AB%E3%83%A9%E3%82%A4%E3%83%88 / https://dic.pixiv.net/a/%E3%82%B9%E3%83%A2%E3%83%BC%E3%83%AB%E3%83%A9%E3%82%A4%E3%83%88

**→ 設定が曖昧なので、質量の2分岐で攻めるのが最も強い（これが丁寧な説明になる）**

#### 分岐A：質量が保存される場合 → 縮退物質になる

```
1/100 に線形縮小 → 体積は 1/10⁶
人体の平均密度 ≈ 1,000 kg/m³（水とほぼ同じ）
縮小後の密度 = 1,000 × 10⁶ = 10⁹ kg/m³
```
**10⁹ kg/m³ は白色矮星の密度領域。** そこでは化学結合は存在せず、電子は縮退し、原子は潰れている。**「小さくなったのび太」ではなく「縮退物質の塊」。**

#### 分岐B：質量も減る場合 → 質量エネルギー保存の破れ

```
60 kg が 1/10⁶ の質量（60 g）になるなら、消えた質量は約 59.99994 kg
E = mc² = 60 × (3.0×10⁸)² = 5.4×10¹⁸ J
TNT換算: 5.4×10¹⁸ / 4.184×10⁹ = 1.29×10⁹ トン = 約1.3ギガトン
広島型（約15キロトン）換算で 約86,000発分
```
→ **「軽くなった」ぶんのエネルギーは、消えるのではなくどこかに出なければならない。のび太が消しゴムサイズになるたびに広島8万6千発ぶんのエネルギーが解放される。** **判定: A（計算）**

#### 分岐C：原子の数を減らす（スケールダウンの正攻法）→ 原子の大きさの壁

**★ここが「原子より小さくはできない」の丁寧版**

1. **原子の大きさは基本定数で固定されている。** ボーア半径 a₀ = ħ²/(m_e e² k_e) ≈ **5.29×10⁻¹¹ m**。これは ħ（プランク定数）、m_e（電子質量）、e（電気素量）だけで決まる。**物を小さくしても原子は小さくならない。**縮小とは原子の個数を減らすことにしかなりえない。

2. **細胞の下限**: 米国National Research Council（1998–99）の報告書 *Size Limits of Very Small Microorganisms*。専門家パネルは **250 ± 50 nm が「我々の知る生命」の合理的な下限サイズ**と合意。DNA/RNA鎖、リボソーム等を収めて代謝を営むには直径約200 nmの球の体積が必要。単一ポリマー系の原始的微生物でも下限は直径50 nm。
   - 出典: https://nap.nationalacademies.org/read/9638/chapter/2 / https://www.ncbi.nlm.nih.gov/books/NBK224757/ / https://astrobiology.nasa.gov/news/how-small-can-life-be/
   - → **ヒトの細胞（典型10–30 µm）を1/100にすると100–300 nm。生命の下限に到達する。** つまり「のび太を1/100」は**細胞1個が成立しないサイズ**に細胞を押し込むことになる。

3. **恒温動物の下限（表面積体積比）**: 現生最小の哺乳類トガリネズミ（Suncus etruscus, チチュウカイカヤネズミ／Etruscan shrew）は**成体で1.8–3 g、体長35–48 mm**。表面積体積比が恒温動物にきわめて不利で、**極端に速い代謝がなければすぐ凍死する**。日々**体重の1.5–2.0倍**を食べる。頻繁に休眠（torpor）に入る。
   - 出典: https://en.wikipedia.org/wiki/Etruscan_shrew / https://www.nature.com/articles/laban.981 / https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9633763/
   - → **1.8 g が哺乳類の実質的下限。** 60 kg を 1/100 に縮めれば 60 g で、これは下限の30倍。1/1000 なら 60 mg で**完全に不可能**。小さくなったのび太は、まず凍える。

4. **目が見えなくなる（回折限界）— 自前計算、判定: B**
```
瞳孔径 3 mm を 1/100 → 30 µm
レイリー条件 θ ≈ 1.22 λ/D = 1.22 × 550×10⁻⁹ / 30×10⁻⁶
                       = 0.0224 rad ≈ 1.28°
```
→ 視野全体で**百数十画素相当**の解像度しかない。**縮小したら世界はぼやける。** これは法則（光の波長）による壁で、技術では越えられない。
（※ レイリー条件自体は標準的な光学で A だが、人体に当てた上の概算は自前計算なので B）

### 11-2. 通り抜けフープ（壁をすり抜ける） — 判定: A

量子トンネルで人がすり抜ける確率は、**透過確率が障壁の幅・高さ・粒子質量の平方根に対して指数的に減衰する**ため、天文学的に小さい。
- 1 g の10セント硬貨が約1 cmの壁を抜ける確率は**およそ exp(−10²⁸)**。
- 人間では **1/10^(10³⁰) 未満**。
- **宇宙の年齢の間、毎秒1回試しても1回も起きると期待できない。**
- 出典: https://www.physicsforums.com/insights/you-will-not-tunnel-through-a-wall/ / https://www.physicsforums.com/threads/probablity-of-walking-through-a-wall.43077/

→ **ただし分類に注意**: これは**(i) 禁じられている**ではなく、厳密には「**確率がゼロではないが、ゼロと区別できない**」。台本では「禁じられてはいない。ただし宇宙の年齢を何度繰り返しても起きない」と言うのが正確で、しかもそのほうが面白い。**判定: A**

### 11-3. タンマウォッチ（時間停止） — 判定: B（論理的演繹。文献未確認）

**この項目は固有の文献を見つけられなかった（確認できず）。** 以下は第一原理からの演繹なので、台本では「考えてみると」の形で。

1. **「全てが止まる」なら観測者もいない。** 時間が一様に止まれば、何も起きていないことと区別できない（観測可能な差がない）。これは物理の主張ではなく定義の問題。
2. **「自分だけ動く」なら、自分は周囲に対して無限倍の速さで動くことになる。** 相対論的に、他者の時間が0で自分の時間が有限なら、相対的なローレンツ因子が発散する。
3. **何も見えない。** 光も止まるので、網膜に光が届かない。止まった世界を見て歩くことはできない。
4. **呼吸できない。** 空気分子が止まれば拡散も圧力も生じない。
5. **熱が捨てられない。** 自分だけ代謝しているのに、周囲の熱浴が応答しない。

→ **③ に入れてよいが、「物理法則が禁じている」ではなく「定義が自己矛盾している」に近い。** 使うなら短く。

### 11-4. 重力を操る道具（反重力） — 判定: A

**反重力・負の質量は観測されていない。**
- **ALPHA 実験（CERN, 2023, Nature）**: 中性反水素原子に働く重力の向きと大きさを測定。**地球への重力的「引力」と整合**し、反物質に対する弱い等価原理の検証となった。
- **反水素は下に落ちる。上に押し上げられない。** 現在の精度（g の約20%）で、反水素原子の加速度は通常の引力的重力と整合。
- → **反重力や負の質量効果の証拠はない。**
- 出典: https://home.cern/alpha-experiment-at-cern-observes-the-influence-of-gravity-on-antimatter/ / https://www.nature.com/articles/s41567-023-02292-0 (Gravity is attractive) / https://ep-news.web.cern.ch/content/alpha-experiment-cern-observes-the-influence-of-gravity-on-antimatter / https://www.nsf.gov/science-matters/down-goes-antimatter-gravitys-effect-matters

→ **これは §7 のタケコプター（公式設定＝反重力型）に直結する。** 「反重力で飛ぶ」と言い換えた瞬間、空気力学の問題は消えるが、代わりに**存在が確認されていない物理に依存することになる**。

# 章の着地点（逆説）について

企画の狙い「**我々はすでにひみつ道具を何個か持っているのに、のび太ほど喜んでいない**」に、調査で出てきた一番強い素材：

2. **音声認識**: 2017年に人間パリティ（WER 5.1%）。**ニュースにはなったが、翌年にはもう当たり前になった。**（A）
3. **医療AI**: FDA承認のAI機器は**1,614件**。2018年にはすでに**医師を介さない自律型AI診断**が承認されている。**それでも「AIが医者になる日」はまだ来ていないと皆が言う。**（A）
4. **★最も効く素材**: ランダム化比較試験で、**AIは未支援の医師より当てた**（top-10 精度 59.1% vs 33.6%）。にもかかわらず、**医師にAIを渡しても臨床推論は有意に改善しなかった**。**道具を持つことと、道具で得をすることは別。**（A）
5. **★逆説の裏面**: 「スマホがあると人は覚えなくなる」という有名な研究（Sparrow et al. 2011, Science）は、**2018年の大規模再現プロジェクトと2020年の専用追試で、2回とも再現に失敗している**。それでも引用され続ける。**我々は暗記パンを手に入れたという物語のほうを、研究より信じている。**（A）
