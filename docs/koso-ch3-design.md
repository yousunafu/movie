# 第3章「水は、勝手に上がらない。」設計書 (文#113〜#146 / 34文)

## この章の役割
5本柱のうち **「水」** の柱が、どうやって立ったのかを見せる章。
軸は変わらず「高さに住むコストを、誰が払っているのか」。
#132「ポンプが働き続けている、その結果です」が、この章で軸に触る文。
**上の階に水があるのは建物の性質ではなく、機械が働き続けている結果**——これがこの章の背骨。

**語らないもの**: 会社名・発明者・個別の物件エピソード。
**語るもの**: 仕組み (なぜ上がらないのか / どうやって上げるのか / なぜ木の樽で漏れないのか)。

### ★「図」「並」も品質は落とさない (作者指示)
> 「シンプルとか普通のやつも絵のクオリティは下げちゃだめなんだけどね。だけど、細かい作りこんだ絵が生きるのは、そのバランスがあってこそなんだよね」

短いのは賑やかさを削ったからで、雑に描いたからではない。線・色・札・フォントは山と完全に同じ。必ず `f` で動く。図そのものを作り込む。**大きく置いて画面を使い切る。**

## ★木の給水桶の決まり (#119/#123/#124/#125/#127/#128/#130 で同じ物に見せる)
複数のファイルに分かれて出てくるので、**形を固定する**。

- 縦板を円筒に並べたもの。板は**28枚**前後、板の間の線を必ず描く
- **鋼のたがが3本** (上・中・下)。たがの合わせ目にターンバックル (ボルトで締める金具)
- 上に**円錐の屋根**、頂点に小さな通気の突起
- 下は**4本脚の木の台座**。脚には筋交い
- 側面から下へ**給水の立管**が1本降りる
- 色: 板 = `C.wood` / `C.woodDark`、たが = `BP.iron`、屋根 = `C.woodDark`
- 寄りで描くときは板の木目・節・濡れた色の差まで描く
