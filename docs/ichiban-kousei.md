# なぜ人は1番を目指すのか — 構成案 v1 (karakuri / ずんだもん / 約21分)

watashi回 (253文=23分07秒) と同規模の設計。です・ます調ナレーション (「なのだ」は使わない)、章扉カード区切り、常時動きの3層 (人物アイドル・図解ループ・ホコリ)。
事実はすべて docs/ichiban-factcheck.md (44項目) のOK表現の範囲内。数字は固定13セットのみ使う
(前776年とされる / 1682年 / 1757年 / 1904年 / 1909年 / 1912年 / 1915年 / 1922年 / 1930年 / 1957年 / 2002年度 / 5がもらえるのは約7% / 英200万人)。

## 全体の背骨

**「勝ちたい気持ちは本能。でも『1位』という仕組みは発明品。だから、作り変えられる」。**

順位が意味を持つには「土俵」が要る。土俵の成立条件は3つ:
**①同じ共同体に属していること ②統一された物差し ③記録して公表する誰か**。
弥生時代の稲作名人は「おれは世界一だ」とは言わない — 隣の村のことすら知らないから。

この土俵が人類史でどんどん広がっていく一本線で貫く:
**戦場ひとつ (一番槍) → 帝国 (科挙) → 江戸の町 (番付) → 国 (新聞と甲子園) → 世界 (金銀銅・世界記録) → 同学年の全国民 (偏差値) → 地球全員 (SNS)**。
裁定者ではなく観察者 (「競争は良いか悪いか」ではなく「この仕組みはいつ誰が作ったのか」)。

### 抽象軸「育つ土俵マップ」(同じ図が育つ演出)

同心円の図 (中心に小さな人、まわりに「比べる相手の輪」) が節目ごとに1段ずつ広がっていく。
watashi回の乗り換え路線図と同じ「同じ図が育つ」方式。累積リキャップの挿入箇所は5つ:

1. 第2章末: 「一番槍が通じるのは、この戦場ひとつだけ。輪は、まだこんなに小さかったのです」
2. 第4章末: 「首席の名前が新聞に載る。輪は、国の大きさになりました」
3. 第7章末: 「戦場ひとつから、帝国へ、町へ、そして国全体へ。しかも毎年更新されるようになりました」
4. 第8章末: 「ついに、同じ年に生まれた全員が、同じ一本の物差しに乗りました」
5. 結び: 「輪は、地球サイズになりました。井の中の蛙、ただし池は地球」で全回収

## 仕掛け (この回だけの武器) — 裏主人公は「2位」

**この動画には隠れた主人公がいる。「2位」である。** 3点で回収する:

1. **序**: 「古代オリンピックに、2位の記録はありません」— 2位は存在しなかった
2. **第6章**: 1904年の金銀銅で**2位が発明される**。「この年、発明されたのは1位ではありません。2位です」(1位は大昔からいた。2位・3位に名前と色を与えたのが近代の発明)
3. **結び**: 銀メダリストより銅メダリストのほうが幸せそうに見える (1995年・追試2本で再現済み)。**発明されたばかりの「2位」が、いちばん苦しいポジションだった** — で幕

オチ (銅>銀と「順位をやめた3実例」) は結びまで出さない。序では「2位がいなかった」事実だけ見せる。

## 導入 (確定案 / 20文・約1.8分)

```
いきなりですが、クイズです。
古代オリンピックで2位になった人の名前は、何人わかっているでしょうか。
答えは、ゼロ人です。
名前が残っていないのではありません。
そもそも「2位」という記録自体が、存在しないのです。
古代ギリシャのオリンピア。優勝者は彫像が建ち、詩人が歌をつくり、故郷の英雄になりました。
では、負けた選手はどうなったのか。
詩人ピンダロスは書いています。敗者は母親に会うのも恥ずかしくて、裏通りをこそこそ帰った、と。
勝者がひとり。あとは全員、ただの敗者。
2位も、3位も、入賞もありませんでした。
ところで、ちょっと想像してみてください。
弥生時代の村に、稲作がいちばんうまい人がいたとします。
その人は「おれは世界一だ」と言ったでしょうか。
言わないですよね。隣の村のことすら、よく知らないのですから。
「何位か」に意味が生まれるには、同じ土俵の仲間と、同じ物差しと、記録する誰かが要るのです。
つまり「順位」は、勝ちたい気持ちとは別の、人間が作った仕組みでした。
金銀銅のメダルが生まれたのは、たった120年前。
3段の表彰台にいたっては、96年前の発明です。
勝ちたい気持ちは大昔から。「1位」の仕組みは、驚くほど最近できた。
人類が「順位」を発明していく歴史、さかのぼってみましょう。
```

演出メモ: 冒頭はオリンピアの神殿+月桂冠の勝者 (山の絵)。「裏通りをこそこそ」は敗者が壁沿いに小さく歩く並の絵で笑いの入口に。弥生の村は俯瞰の世界図。
注意: コロイボス (最初の優勝者) の職業は factcheck 未確認のため出さない。

## 緩急の設計

- 笑いの山: 第2章 (一番槍=書類仕事) → 第4章 (木のスプーン) → 第5章 (何でも番付) → 第7章 (第1号優勝者は平幕) と約4〜5分間隔
- 真面目の谷は第9章後半 (英200万人) の1カ所だけ。BGM・話速もここだけ落とす
- 第6章は「驚きの山」(笑いではなく、年号の若さで驚かせる)。96年前の表彰台はこの回いちばん強い断定
- クイズカード候補: ①序「2位の名前は何人わかっている?」②第5章「江戸の相撲に無かったものは?」③第6章「金銀銅はいつから?」

## 炎上回避 (factcheckのC判定・注意リスト遵守)

- 「2位の記録がない」は**オリンピア限定**の言い方を厳守 (ホメロスの葬礼競技には複数入賞がある)。「古代オリンピックに」で言う
- 前776年は「記録に残る最初の大会は〜**とされます**」。コロイボスの職業は出さない
- 科挙の開始は「隋の時代」とぼかす。「世界最初の実力主義制度**とされる**」
- 箱根=報知新聞 (「読売」はC)。都市対抗=東京日日・現毎日 (「毎日新聞主催」と裸で言うのはC)。優勝額=時事新報
- 偏差値「世界で日本だけ」はC (韓国に類似指標)。「ここまで浸透したのは日本独特とされます」まで
- 天下一禁止は事実のみ。「幕府が競争を嫌ったから」という動機の断定はC
- ジュホアンシを「謙虚な民族」と性格づけしない。習慣の記述のみ。「人類史の大半は平等だった」と断定しない (学術論争中)
- 相対評価廃止 (2002) は善悪で描かない。ゆとり教育論争には触れない
- 知能検査・IQは前作「私は何者?」の主役なので出さない (ケトレー→偏差値は統計の線だけで通す)
- 順位が好きな人・受験生・アスリートを断罪しない。裁定者ではなく観察者
- winner effect (ファンのテストステロン)・Zink・最下位回避・アンダーマイニングはカット済み。復活させない
