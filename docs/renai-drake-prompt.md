# 台本作成プロンプト: 恋愛版ドレイク方程式 (運命の人は東京に何人?)

この文書は `docs/renai-drake-script.txt` を再現するための指示書 (§13-2 の決まりごと)。

## ①テーマ・想定視聴者・尺

- テーマ: 宇宙人を探すドレイク方程式 (フェルミ推定) で「運命の人が東京に何人いるか」を本気で計算する。元ネタはピーター・バッカスの実在論文「なぜ僕に彼女ができないのか」(2010)
- 想定視聴者: 大人の男性・インテリ層の高齢者。**ユーモアたっぷり** (ユーザー指定 2026-10)。方向は「乾いた・上品・少し自虐」。例:「いいねは来るのに、いい人は来ない」「素敵な人には、だいたい先約があります」「もし座っていたら、それはもう家族です」。笑いは必ず絵の見せ場とセットで設計する
- 尺: 約12分 (約150文。1分≈12文換算)
- プリセット: suuri (おとなの数理室)

## ②構成の指定

- つかみ (約17文): **昨今の恋愛市場・婚姻の低迷を嘆く世相ネタから入る** (20代男性の7割に恋人なし / デート経験なし4割 / 婚姻数戦後最少 / 結婚の4組に1組はアプリ)。「道具は増えたのに、出会いは減っている」のねじれを提示 → 数学で解くと宣言 → **舞台が「日本でいちばん人が多い東京都1400万人」であることを強調** (後の「40人」の衝撃を倍にする仕込み) → 4章の地図
- 第1章 宇宙人の数え方: ドレイク方程式の分解の思想。余談=シカゴのピアノ調律師。クイズ=この式のいちばんの発明は何か。章末の引き=「なぜ、僕に彼女ができないのか」
- 第2章 運命の人を数える: バッカス論文の紹介 → 東京版の掛け算を「条件 → 残りは、◯◯人です。」の短い往復でテンポよく絞る (1400万→700万→105万→52万→16万→8000→400→**40人**)。40人は読み上げの瞬間までネタバレ禁止。東京ドーム6回のたとえ → 「出会いがないは数字として本当」で前半のピーク → 章末の引き=「美しい抜け道があります」
- 第3章 掛け算の抜け道: どれか1項目を2倍にすると答えも2倍。クイズ=±10歳なら何人? (80人)。緩めると300人超 / 条件を足すと逆戻り → 「運命の人の数は定数ではなく変数」。余談=バッカス本人はイギリス全土で26人。章末の引き=「続きは第4章で」
- 第4章 確率は動かせる: いるだけでは確率ゼロ (宝くじは買わなければ当たらない) → 分母=年間に出会う人数の話 → 試行回数は自分で増やせる → バッカスが実際に結婚した実話で回収 (確認できる事実のみ。誇張しない)
- 結論 (約10文): 運命の出会い=条件と分母を自分で選べる計算問題。「掛け算をひとつ緩めてみませんか」で締め

## ③文体ルール

- 1文=1シーン。改行と句点で区切る。見出し・話者表記なし
- 10字未満の文は前の文に結合される。「残りは、◯◯人です。」のカウントダウン文は10字以上を保つこと (絵の切り替えと同期させる重要文)
- クイズは「さて、ここで問題です。」→問い→「答えは、〜、です。」→解説1文。演出は静かに
- 余談は「ちなみに、」で始めて6文以内
- 数字の文・問いの文・「つまり」の結論文を各章に入れる
- 統計は実在のものを「およそ」付きで使う。バッカスの結末は確認できる事実 (結婚した) だけに留める

## 制作メモ (モチーフ設計の方針)

- **つかみ17文だけ「恋愛モード」背景** (ユーザー指定 2026-10): 白ベース (`#FDF9FA` 目安) + ピンクの装飾 (淡`#F2C4D0`/中`#E68FA8`/最強調`#D6487A`)。文字・線はチャコール。最強調色1画面1要素ルールはピンクで継続。和紙モード (§7-4) と同じ場面切り替えの型で実装し、「それでは、まいりましょう。」で黒背景に暗転して第1章 (宇宙・黒板) へ
- 第2章の絞り込みは「人の点の群れがどんどん消えていき、残る人だけ色付き」の連続演出 (ガイド§9-4 原則11: 消える側モノクロ・残る側カラー)
- つかみ: 日本地図→東京がドンと出るシーン / 婚姻数半減の下りグラフ (ピンクの世界の中に嘆きの数字、のギャップを狙う)
- **ユーモア演出の柱** (ユーザー承認済み): ①かわいい宇宙人を全編のマスコットにして要所で再登場させる (第1章初登場→天秤→結婚式の祝福) ②第2章のカウントダウンは点の群れがポポポンッとテンポよく消え、傍らの棒人間の表情が「余裕→汗→真っ白」と育つ ③第3章「はい、消えました」は吹き出し→群衆ゴソッの連打 ④ソファに座る「家族」⑤どんぶりに星が盛られた「どんぶり勘定」
- 第1章: 黒板の式・星空 (suuriの黒背景と相性よし)
- 40人の瞬間は splitPunchline 型でネタバレ防止
