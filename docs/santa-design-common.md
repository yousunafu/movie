## 軸 (すべての絵はこの軸のどこかを担う)
**「サンタは、200年分の大人たちが、少しずつ付け足して作った」**。
画面の背骨は**「サンタの組み立て台」= 作業台の上に、サンタの部品が1つずつ置かれていく**図 (共有部品ではなく A の装置 `KumitateDai`)。部品が足されるたびに、その部品を付けた「容疑者」の札 (年号+人・物の名前) が台の横の**容疑者ボード** (コルク板に写真の代わりの絵の札と赤い糸) に貼られる。
- 部品の順 (台本どおり): 窓から投げる金の袋 (#23) → 名前 (#39) → 太った体とパイプ (#43) → 靴下2本 (#45) → ソリとトナカイ1頭・ムチ (#48〜51) → 8頭のトナカイ・煙突・おもちゃの包み・白いひげ (#54〜56) → 北極の住所・工房・帳簿 (#75〜77) → 赤い服 (#82〜84) → 人間の大きさのおじいさん (#91) → 赤い鼻の9頭目 (#116) → 宛先と郵便番号 (#137〜) → 証拠 (追跡) (#156〜) → 最後の部品 = あなた (#214〜223)
- 組み立て台・容疑者ボードは**章の頭と章の終わり**に出して進み具合を見せる (#16・#37・#67・#101〜105・#112・#155・#178〜180・#219〜221)。それ以外の文は、その時代・その場所の世界で事件として描く
- **犯人探しの語り口**: 探偵ものの小道具 (虫めがね・容疑者ボード・赤い糸・「容疑者」の札・手配書風の紙) を章ごとに少し使う。ただし毎回は使わない

## 登場人物の見た目 (★男女はひと目で分かるように)
- **男女の描き分けの決まり** (性別に意味がある場面は必ず守る):
  - 男性: 短い黒髪 (Person の hair="cap")・紺/青/灰の服・ズボン。年配は白髪・口ひげ
  - 女性: Person に**肩まで届く茶色の長い髪 (左右に垂らす) か、後ろで結んだ髪の房**を描き足し、服は赤・ピンク・えんじ系、**スカート** (腰から膝下まで広がる台形)。昔 (19世紀) の女性はくるぶしまでの長いスカート+ボンネット帽か頭巾
  - 子ども: s を小さく、頭を大きめに。男の子・女の子も上の決まりで描き分ける
  - 「人たち」「大人たち」の場面は**男女を混ぜてどちらもひと目で分かる姿**で
- **あなた** (この回のメインキャラクター・A と B で共通): 丸頭の `Person`、hair="cap"、**緑のセーター (`XP.you`)+ 白い雪の結晶の柄1つ**。性別を決めない人物として男女の記号は付けない。#1〜17・#186〜224 の現代の場面と、最後の部品 (#223) で使う
- **サンタ** (★この回の主役。共有部品 `Santa` の `era` で姿を変える。同じ人物が時代ごとに姿を変えたと分かるように、**どの era でも白いひげと丸い目は共通**):
  - `era="nicholas"` 聖ニコラウス (4世紀の司教): **実在の可能性がある人物なので顔を描かない**。赤い司教の祭服とミトラ (とがった帽子)・杖。後ろ姿・窓の外から手だけ・影ではない (シルエット禁止。色のついた後ろ姿)
  - `era="sinterklaas"` オランダのシンタクラース: 白い馬・赤い司教の服・ミトラ・**やせて背が高い**。言い伝えの人物なので顔あり
  - `era="dutch"` 1809年 アーヴィングの太ったオランダのおじさん: つば広の帽子・パイプ・太った体・ニッカーボッカー
  - `era="1821"` 1821年の小冊子: 小柄・毛皮の帽子・ソリにトナカイ1頭・手に樺のムチ
  - `era="1823"` 1823年の詩: **小人の妖精** (人の半分以下の大きさ)・全身毛皮 (色は**茶色**。詩に色の記述がないので赤にしない)・白いひげ・背中におもちゃの包み・陽気な顔
  - `era="nast"` 1863年ナスト: とても小さい・**星の上着とストライプのズボン** (星条旗柄)。白黒の挿絵の場面は灰色の濃淡だけで描く
  - `era="red"` 1902〜1923年の赤いサンタ: 白い縁の赤い服・白いひげ・普通の大きさ
  - `era="classic"` 1931年以降の今のサンタ: **人間の大きさ・太った温かいおじいさん**・赤い服・黒いベルト・袋。#97 だけベルトのバックルを逆向きに

- **会社のロゴ・商品名の文字は描かない** (コカ・コーラ・炭酸水・デパート・ウイスキー)。コカ・コーラは「赤いラベルの炭酸飲料の瓶」までにして、筆記体のロゴは描かない
