## 絶対に守ること

1. **1文 = 1シーン = 1枚の絵。** 増やさない減らさない
2. **札 (TagPlate) の y + size*0.85 を 830 以下にする。** 画面の下には字幕の黒帯 (上端854) が別レイヤーで乗ります。検品プレビューには字幕が出ないので目では気づけません。必ず計算で守ること。**画面の下 1/4 (y>830) に大事な物 (顔・主役・札) を置かない** (床や影はOK)
3. **絵の中の文字は、ラベル・数値・標識だけ。** 台本の文章をそのまま絵に書かない (字幕が出るので二重になる)
4. **必ず `f` で何かが動く。** 静止した絵は禁止。人のまばたき (Person に f を渡す)・物のゆれ・ホコリは最低限で、そのうえで**そのシーンの事件**を動きで起こす
5. **f=45 の瞬間に「その文がいちばん伝わる絵」が出ているように。** 検品プレビューは全シーンを f=45 の瞬間で描きます。主役・舞台・その文の事件の「山場」は f=42 までに見えるようにする。そのあと文の尺 (指示書の各行の「★尺」) の最後まで、動きを続けてよい (くり返し・後日談・カメラの寄り)。尺を超える動きは見えないので組まない
6. 色は `KRP` と `XM.XP` と、自分のファイル上部の `C` にある色だけ。足すなら `C` に足す
7. seed は骨組みに書いてある数字を変えない
8. 対応表 `SCENES` と `*_MOTIFS` 配列、部品名・motif 名は**変えない**
9. **人物は共通部品 `Person` で描く** (からくり憲法第7条)。自分で別の画風の人を描かない。座らせるときは `pose="sit"` (座面の高さ = y − 58×s)。足りない姿勢 (寝そべり等) は Person 全体を `rotate` した `<g>` で包む・腕だけ自分で足す、で作る
10. **主役は画面センター** (第3条)。**物の大きさは現実に合わせる** (第4条)。**場所や時代が変わるシーンは「ここはどこ/いつ」が一目で分かる記号を置く** (第6条: 国旗・地名札・年代札)
11. **変身の演出では変身後に元の物を完全に消す** (第5条)。煙や光で「変わった」と分かる記号を添える
12. **背景キット禁止** (第13条)。同じ背景の上で物だけ入れ替える作り方はしない。1文ごとに舞台・構図・カメラを作る。例外は同じ場所・同じ時間の続き (「#7と#8は同じソファ」など、指示書に書いてある場合だけ)
13. **素肌禁止** (第16条)。無地のクリーム地に物を浮かべない。図の格でも「何かの上」に描く (発掘の土壁・巻物・机・掲示板など)

## 絵の「格」

| 格 | 中身 | 目安 |
|---|---|---|
| **山** | 舞台・人・事件・カメラ全部入り。全力 | 150〜300行 |
| **並** | 舞台はあるが、描くのは1つに寄る。人は1人、背景3〜4要素 | 80〜150行 |
| **図** | 図解が主役。人は置かない。ただし「何かの上」に描く | 50〜100行 |

**「図」「並」も品質は落とさない** (作者: 「シンプルとか普通のやつも絵のクオリティは下げちゃだめ」)。線・色・札・フォントは山と同じ。`strokeWidth` を細くしない。**最悪の失敗は「小さい物を画面の真ん中にポツンと置く」**。主役は短辺 (1080) の半分以上を使う。シンプル＝1つを大きく正確に。

## ★この動画だけの決まり (必ず守る)

1. **男女はひと目で分かるように** (作者の注文): 性別に意味がある場面は、指示書の「男女の描き分けの決まり」をそのまま守る。男性=短い黒髪 (hair="cap")・紺/青/灰の服・ズボン、女性=**肩まで届く茶色の長い髪 (左右に垂らす) か後ろで結んだ髪の房**・赤/ピンク/えんじ系の服・**スカート**。明治・昭和初期の女性は着物と帯・日本髪、戦後の女性はワンピースとパーマ。子どもも `Kodomo` の girl で描き分ける
2. **メインキャラクター「あなた」は全編同じ姿** (`XM.Anata`): 緑のセーター+白い雪の結晶1つ・短い黒髪。男女の記号は付けない。同じ場面に緑のセーターの別人を置かない。**クリぼっちの場面のあなたは、さみしそうではなく、のんびり満足そうに** (だれも傷つけない自虐)
2b. **サンタの顔はメインキャラクターの顔** (作者の注文「メインキャラクターをサンタにするみたいな」): `XM.Santa` が Person と同じ丸い頭・大きい丸目で描くので、サンタの顔を自分で描かない・別の顔にしない。**`look` prop は渡さない** (元の顔は `look="own"` で部品に残してある。作者 2026-11-27「メインキャラにしようか一応、元のもどっか残しといて、緊急ですげかえられるように」→ 差し替えは部品の既定値1か所で全場面が変わる)
3. **腕は必ず2本**。Person の腕に自分で腕を足すときは、元の腕を pose で隠すか消す
4. **実在の人物の顔は描かない** (1552年の宣教師・ホール兄弟 (1917年の店の店員)・実在の料理番組の講師に似せない)。**体ごと後ろを向いた後ろ姿** (後頭部を髪で塗る) か手元だけ。顔の部品を消しただけの正面向き (のっぺらぼう) は不気味なので禁止。名前の出ない一般の人は顔を描いてよい
5. **ロゴ・商品名・看板の文字を描かない**: フライドチキンのお店 (**赤白の縦じまのバケツ・白いひげのおじさんの人形・店の看板は使わない**。茶色の紙の箱までにする)・不二家・三越・高島屋・ホールマーク・NHK・JR東海・百貨店の包装紙の実物の柄。形と色だけで分かるように。札に台本に出る名前を書くのはよい
6. **字幕と同じ文章を絵の中に書かない**。札は「ラベル・年・地名・数字」だけ
7. **数字・事実は指示書に書いてあるものだけ**。自分で足さない。とくに: 「チキンを食べるのは日本だけ」と見える絵にしない / 戦時中の「クリスマス禁止令」は描かない / 「クリスマスケーキ=25歳」の比喩は絶対に使わない / 半旗や大正天皇祭の場面は茶化さない距離で
8. **ユーモアは絵の事件で**: 指示書の笑いどころは、**表情と動きで笑える**ように大げさに。ただし下品・残酷にしない。酔っぱらいは上品に (吐く・倒れて動かない絵にしない)。ひとりの人を笑いものにしない
9. **明かりは黒い図形を重ねた点滅で表さない** (目覚まし回で「なぞの黒い丸が点滅する」と言われた)。電飾・炎・光は明るさのゆらぎで
10. **音符は口から帯のようにつなげない** (目覚まし回で「吐いてるみたい」と言われた)。歌は頭の上に1つずつ浮かぶ音符で
11. **空の色や昼夜の早回しを速くしない** (目覚まし回で「チカチカする」と言われた)。1日ぶんの変化は 15コマ以上かけて、なめらかに

## 進め方

1. 自分の指示書と、自分の担当 .tsx を Read する。次に `XmasParts.tsx` と `XjParts.tsx` を grep -n "^export" で一覧し、自分の指示書で使う部品だけ Read する (この3つを最初に読む)
2. 骨組みの各シーンの `// どこ: // 演出: // 動き:` のコメントを**先に埋めてから**描く
3. 一気に書く。Edit で `{/* TODO */}` を本物の絵に置き換えていく (シーンを `=> (` から `=> { … return (…); }` に書き換えてよい)
4. 型チェック: `node_modules/.bin/tsc --noEmit`
5. 札の検査: `npx tsx scripts/koso-plate-check.ts <自分のファイル名から .tsx を取った名前> (例 XjA)` — **NG 0件になるまで直す**
6. 静止画をまとめて書き出す (**1枚ずつ `remotion still` を呼ばない**。必ず先頭で TMPDIR を設定):
   ```
   export TMPDIR="$(pwd)/tmp/remotion-tmp/"; node_modules/.bin/remotion render src/remotion/index.ts XjAll tmp/xj/<置き場> --sequence --frames=<C1>-<C2> --image-format=png --concurrency=2 --log=error
   ```
   コマ番号 = 文番号 − 1。出力のファイル名は `element-<コマ番号>.png` (桁数は Remotion が0詰めすることがある。`ls` で確かめる)
7. 全部を Read して自分で検品する: 主役が小さくないか / 物が重なって読めなくなっていないか / 画面の下1/4に大事な物がないか / 人の手足や物のつながりが変でないか / 真ん中にポツンでないか / 素肌 (無地背景) がないか
8. 直して、もう1回だけ書き出して確認する
9. 終わったら、各シーンを1行で説明した報告を返す (400語以内)
