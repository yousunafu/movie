## 章扉 (ChapterDoor) の描き方 (担当に章扉がある場合)
第1章の扉で、暗い背景だと「第N章」の灰色の字が沈んだので、題字の後ろに薄いクリームの帯を敷くことにしました。Frame の `over` に次のように入れる:
```tsx
over={<>
  <div style={{ position: "absolute", left: 970, top: 536, width: 900, height: 196, borderRadius: 18,
    background: "rgba(247, 242, 226, 0.86)", opacity: door, boxShadow: "0 6px 0 rgba(40,28,16,0.18)" }} />
  <ChapterDoor num={N} title="…" t={door} left={1000} top={560} />
</>}
```
`door` は `seg(f, 4, 20)` などで 0→1。題字が絵の主役に被らないよう、主役は画面の左寄りに置く。

## 前の巻で検品のときに直したこと (同じ失敗をしない)
- 人の顔や大事な物を画面の下 (y>830) に置いてしまい、字幕の帯にかかった → 人の足元が y=830 を超えるのはよいが、**顔は y<800** に
- 寝かせた人が草の上に**浮いて**いた → 寝かせた Person の体の下端を、寝床の上面に合わせる (少し沈める)
- 札の文字が画面の左右の端で**切れて**いた → カメラの寄り (scale) をかけるシーンは、端に文字を置かない
- 検品プレビューの f=45 の瞬間に、いちばん伝えたい絵 (握っている・弾んでいる等) が写っていなかった → **f=45 で「その文がいちばん伝わる瞬間」**になるように動きの時間を組む
