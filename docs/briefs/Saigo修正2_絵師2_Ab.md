## 作業A — 文#22 の「?」をどけて、札の下にメインキャラ3人

> #22 「では、『黙って、座って、最初から最後まで』は、いつ、誰が決めたのでしょうか。」

作者の指摘: **「?マークを札からどけて、札それぞれの下にそれに当てはまるキャラを置く。メインキャラで作画して (モブキャラは不可)」**

### やること

1. **`Sg022` の中にある「値札 (大きな ?)」のかたまりを消す。**
   `{/* 値札 (中央の札からぶら下がる。大きな ? ) */}` から始まる `<g transform={`translate(1150 500) ...`}>` のブロックごと削除。`tagT` と `swing` が他で使われていなければそれも消す (使われていれば残す)

2. **`Fuda3` の3枚の札の、それぞれ真下に人物を1人ずつ立てる。** 合計3人。
   - **`KarakuriScenes.tsx` の `Person` を使う** (主要人物の画風)。`PersonMini` は群衆用なので**使わない**
   - 札の位置: `Fuda3` は `x=960 y=420 s=1.1` で呼ばれている。部品のローカル座標で3枚の札の中心は `cx = -415 / -115 / +300`、札の面は `y = -75 〜 +75`。
     → 画面座標では **x ≈ 960 + cx*1.1** なので **約 503 / 833 / 1290**、札の下端は **y ≈ 420 + 75*1.1 ≈ 503**
   - 人物の足元 y は **790 前後** (その下に陳列台 y=800 がある)。`s` は 1.15〜1.3 くらい。3人は少しずつ `s` と `lean` を変え、横一列の並びに見せない
   - **3人が重ならないこと。** いちばん右の札は幅が広い (500) ので、右の人物は x=1290 付近で `s` を少し小さめに

3. **3人は「その札に当てはまる人」**にする。札の意味を体で表す:
   - 「黙って」の下 → 口の前に人差し指を立てて「シーッ」としている人。`Person` に指を立てる pose がなければ、`pose="raise"` などに**ローカルで小さな手の部品を1つ足して**口元へ置く (※人物の変換契約を守る。共通の掟の「★ Person に帽子や小物を乗せるときの契約」を必ず読む)
   - 「座って」の下 → きちんと腰かけている人。椅子ではなく**座布団に正座**でもよい (江戸と西洋のどちらにも寄せない中立な絵がよい)。`Person` は立ち姿前提なので、座って見せるなら腰から下を座布団と膝で隠す形にする
   - 「最初から最後まで」の下 → 正面を向いて腕を組み、身動きせずじっと観ている人 (`pose="armsFolded"`)
   - 3人とも**顔は普通の表情**。しかめ顔・怒り顔にしない (この動画は観察者の態度)

4. 札の下に人が入ったので、**スポットライトの光のあたりが人の上に落ちるよう**に、既存のスポット polygon の下端あたりに人物3人を置く順番 (重なり順) を調整する。人物はスポットより**手前**に描く

5. 既存の板壁・鴨居・陳列台・縄の柵は**そのまま残す**

## 作業B — 演者 (舞台に立つ人) の扮装を直す: 文#17 #18 #19

作者の指摘: **「演者が普通のキャラになっちゃってるから、ちゃんと演者っぽい見た目にして。あとのシーンも全部確認して直して」**

対象の文:

| 文 | 台本 | 直すところ |
|---|---|---|
| #17 | 江戸の芝居見物のお客さんは、上演の真っ最中に弁当を広げ、酒を飲みました。 | 舞台の上の役者が普段着のまま → **歌舞伎の役者**に |
| #18 | 気に入らなければ、敷いていた座布団を、舞台に投げました。 | 投げられている先の役者 → 同じく歌舞伎の役者に |
| #19 | ナポリのオペラハウスでは、お客はしゃべりっぱなし。 | 舞台の上の歌手 → **18世紀オペラの歌手**に |

### 歌舞伎の役者らしさ (#17 #18)

ローカル部品を1つ作って使い回す (例: `KabukiYakusha`)。**人物の画風は `Person` を土台にする**。

- **袖の広い着物** — `Person` の体の上に、肩から袖がゆったり垂れる布を重ねる。色は濃い朱・藍・金茶など舞台映えする色で、**模様 (大きな格子や縞) を1つ入れる**
- **隈取 (くまどり)** — 顔に朱の筋を1〜2本。線は太く (4〜5)。**怖い顔にしない**。茶化しにならない範囲で
- **鬘 (かつら)** — 髷が高く結われた黒髪。前髪の生え際をはっきり
- **片足を踏み出して手を広げた見得 (みえ)** の姿勢を1人に。もう1人は正面を向いて扇を持つなど、**2人の姿勢を変える**
- 舞台の上は**明るく**、客席は暗め。役者が主役に見えるように

### オペラ歌手らしさ (#19)

ローカル部品 (例: `OperaKashu`)。

- **裾の広がった長いドレス**か**丈の長い上着+膝丈ズボン+白い靴下** (18世紀の舞台衣装)。襟と袖口に白いフリル
- 片手を胸に、もう片手を高く差し出して**歌っている口 (丸く開いた口)**
- 頭に**白い鬘** (巻き毛を横に1〜2段)。帽子を乗せるなら共通の掟の変換契約を守る
- 足元に**蝋燭のフットライト**が並び、下から顔を照らしている (この時代の劇場の特徴。やると一気にそれらしくなる)
- 客席はしゃべりっぱなしなので、`PersonMini` の群衆が互いに向き合い、吹き出しの代わりに**小さな波線**を口元から出す (文字は書かない)

### 共通の注意

- **衣装を足しても、人物の画風 (大きな丸い目・線の太さ) は共通部品のまま。** 新しい画風を作らない
- 衣装の重ね方で `Person` の腕が隠れてしまうなら、衣装を**体より奥**に描いて腕を前に出す
- 既存の舞台・客席・小物は残す。**衣装だけを足す**のが原則
