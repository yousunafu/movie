## 1. この仕事は何か

上司に見せる比較見本の動画。台本39文、1文＝1枚の絵。
日本の玉音放送 (1945) と、イランのホメイニの「毒の杯」(1988) と、2026年のイラン情勢を
つなげて見せる。着地は「日本のガソリンが170円なのはこのためです」。

真面目な主題なので、**かわいい絵にしない**。暗く、重く、美しくする。

### 作者の指示 (そのまま)

> 「背景やイラスト動き演出はからくりチャンネルでいくとこの**山**を意識すること」
> 「今回は**並は少なめ山は多め**がいいかもね。あと**世界地図とか場所とか時系列もわかりやすく**」
> 「**無理にこの配分だからって守り切らなくていい**からね。**必要だと思えば必要な絵を描けばいい**から」

つまり、自分のファイルのコメントに書いてある「格」(山/並/図) は**目安**であって縛りではない。
図と書いてあっても、その文に必要なら山の密度で描いてよい。**ただし逆はだめ**。
山と書いてある枚を図の手抜きで済ませるのは失敗。格を上げたら、報告でそう言うこと。

## 2. 絶対のルール 7つ

1. **1つの関数が1文ぶんの絵。`<svg viewBox="0 0 1920 1080">` の中身だけを返す** (型は `SekaiArt`)。
   `div` / `AbsoluteFill` / `useCurrentFrame` は使わない。フレーム番号は props の `f` で来る。
   字幕帯と通知カードは外側の枠が足すので、絵の中に文字の帯を描かない。
2. **背景は必ず敷く。** `WarmStage` か `SekaiMap` か `SekaiGlobe` で画面を埋める。
   素のクリーム地＋方眼は全編0枚 (制作ガイド第16条「作り込みの床の法」)。
3. **主役は短辺の半分 (540px) 以上。** 小さい物を画面の真ん中にポツンと置くのが最悪の失敗。
4. **実在の人物の顔は描かない。** 天皇・ホメイニ・ハメネイ・モジタバ・制裁を受けた日本人、全員
   「逆光の黒い影＋金のリムライト」で処理する。目鼻を描いた瞬間に不正解。
5. **必ず `f` で動く。** 出しっぱなしの静止画は作らない。1枚につき最低ひとつ「事件」を起こす。
6. **色は `WP` だけを使う。** 新しい色を足さない。`#fff` も `#000` も書かない。
7. **`uid` は関数ごとに別の文字列にする。** `defs` の id がぶつかると他の絵が壊れる。
   自分の担当の頭文字＋文番号にすると安全 (例: `"a09"`, `"b17"`, `"c23"`, `"d39"`)。

### 加えて、この題材での禁止事項

- 実在の国旗の意匠・宗教の記号そのものを描かない (旗の形をした**無地**の札、**無地**の丸で代用)
- 実在の人名を画面に書かない (制裁リストの横文字は「読めない粒 = 短い線の列」で表す)
- 血・遺体・爆発の生々しい描写をしない。攻撃は「光」と「輪」と「線」で表す

## 3. 色 (`WP` / world.tsx から import)

障子を光源にした**逆光**がこの作風の土台。光源をひとつ決めて、そこから手前へ暗くする。

| 名前 | 用途 |
|---|---|
| `WP.bg` | 奥の空気。画面の地 |
| `WP.deep` | 周辺減光。四隅を沈める |
| `WP.wall` / `WP.wood` / `WP.woodDark` | 壁・木・家具 |
| `WP.line` | 輪郭 (逆光なので輪郭は**暗い**) |
| `WP.paperLit` | 光を透かした紙・障子 |
| `WP.glow` | 光の帯・光源 |
| `WP.shadow` / `WP.shadowDeep` | 逆光の人物・物のシルエット |
| `WP.rim` | 金のリムライト。影を背景から分離する**命綱** |
| `WP.amber` / `WP.amberLit` | 灯り・いま話している場所 |
| `WP.sabi` / `WP.sabiDeep` | 錆朱。つながり・攻撃・いま・強調 |
| `WP.kinari` / `WP.kinariDim` | 生成り。札の地・文字 |
| `WP.sea` / `WP.land` | 地図の海・陸 |

**暗い背景に黒い影を置いたら、必ず `WP.rim` の細い線で縁を起こす。** これを忘れると影が背景に溶ける
(作者から繰り返し指摘されている点)。

文字は `SEKAI_SERIF` (明朝・札や大きな数字) か `SEKAI_FONT` (ゴシック・小さな注記) のどちらか。
他のフォントを書かない。

## 4. 共通部品の使い方 (world.tsx)

```tsx
import {
  WP, WarmStage, SekaiMap, SekaiChrono, SekaiGlobe,
  SekaiCup, SekaiPodium, CrossMark, mp, MAP_LAND, type SekaiArt,
} from "./world";
```

### `WarmStage` — 逆光の舞台 (いちばんよく使う)

背景・光源・光の帯・舞う埃・周辺減光を一組で焚く。**子要素は光源と帯のあいだに挟まる。**

```tsx
<WarmStage f={f} uid="b17" src={[1380, 150]} srcR={820} motes={34} vig={0.86}>
  {/* ここに絵を描く */}
</WarmStage>
```

| props | 意味 | 既定 |
|---|---|---|
| `src` | 光源の位置 `[x, y]` | `[960, 180]` |
| `srcR` | 光源の広がり | `760` |
| `glow` | 光の色 | `WP.glow` |
| `bg` | 地の色 | `WP.bg` |
| `shafts` | 光の帯を出すか | `true` |
| `motes` | 舞う埃の数 | `30` |
| `vig` | 周辺減光の強さ | `0.8` |

### `SekaiMap` — 世界地図 (#10 / #31 / #37 / #39)

```tsx
<SekaiMap
  f={f}
  uid="d31"
  lit={{ usa: 0, israel: 14, iran: 30 }}       // 灯りはじめるフレーム
  arcs={[
    { from: "usa", to: "iran", at: 40, hit: true },
    { from: "israel", to: "iran", at: 54, lift: 110, hit: true },
  ]}
  focus="iran"      // この土地を画面中央に寄せる (省略可)
  zoom={3.4}        // 寄り倍率 (省略可、既定 1)
  labels={false}    // 名札を出すか (既定 true)
/>
```

土地の名前は `"japan" | "iran" | "israel" | "usa" | "edo"` の5つだけ。
`arcs` の `lift` は弧の高さ (既定 170)、`hit` を `true` にすると着弾の輪が広がる。
`mp(経度, 緯度)` で任意の地点の画面座標が取れる。`MAP_LAND.iran.lon` のように国の座標も引ける。

**地図を出しただけで終わらせない。** 寄る・事件を起こす・手前に何かを置く、のどれかを必ずやる。

### `SekaiChrono` — 年表の帯 (#9 / #15 / #30 / #34)

```tsx
<SekaiChrono f={f} at="1988" from="1945" />                  {/* 上段を走らせる */}
<SekaiChrono f={f} at="2026" month="3月" monthFrom="2月28日" /> {/* 下段の印を動かす */}
```

上段は `"1701" | "1945" | "1988" | "2026"`、下段は `"2月28日" | "3月" | "4月" | "6月" | "11月3日"`。
`y` で帯の高さを変えられる (既定 690)。動きは58フレームで終わるように組んである。

**年表だけだと画面の上半分が空く。** 空いたところに大きな数字 (「43年」など) や小さな影絵を置いて、
画面を埋めるのは**あなたの仕事**。年表を置いただけで提出したら失敗。

### `SekaiGlobe` — 地球の弧 (#1 / #3 / #25)

```tsx
<SekaiGlobe f={f} uid="a01" lightAt={[0, 16, 32, 48]} linkAt={70} fifthAt={30} />
```

灯は4つ (江戸 / 日本 / イラン / アメリカ) で順に灯る。`linkAt` を渡すと灯と灯が錆朱の線で結ばれる。
`fifthAt` は5つ目の小さな灯 (#25 用)。`labels={false}` で名札を消せる。

### `SekaiCup` — 毒の杯 (#12 / #21)

```tsx
<SekaiCup x={960} y={540} s={1.5} f={f} uid="b12" hands reflect="self" />
```

`hands` を外すと差し出す手が消える (#21「持つ手がない」用)。
`reflect` は `"self"` (自分の輪郭が映る) / `"podium"` (演説台が映る) / `"none"`。

### `SekaiPodium` — 演説台 (#11 / #17 / #21)

```tsx
<SekaiPodium x={960} y={860} s={1.6} f={f} uid="b17" mic drape drapeText="…" />
```

`mic` でマイク、`drape` で垂れ幕。人物は**足さない** (#17 は無人であることが意味)。

### `CrossMark` — 錆朱の× (#26 / #35 / #36)

```tsx
<CrossMark x={960} y={520} r={240} f={f} at={30} w={22} />
```

`at` で引かれはじめるフレーム、`w` で線の太さ。2本の線が順に引かれる。

## 5. 絵の格 (行数の目安)

| 格 | 1枚の行数 | 中身 |
|---|---|---|
| 山 | 150〜250行 | 世界が立ち上がる。奥行き3層以上、事件、カメラが動く |
| 並 | 60〜120行 | 主役ひとつを作り込む。背景は簡素でも敷く |
| 図 | 25〜50行 | 図版。**ただし線・色・札・フォントは山と同じ品質** |

図が短いのは賑やかさを削ったからで、手を抜いたからではない。
**図でも背景は敷く。素の地に図形を浮かせたら不合格。**

## 6. 出す前の自己点検 (6点法)

1枚ごとに、声に出して確認する。

1. **寄っているか** — 主役は短辺の半分 (540px) 以上あるか
2. **世界が置いてあるか** — 背景・光源・奥行き。素の地ではないか
3. **部品が作り込まれているか** — 丸と四角の組み合わせで終わっていないか。質感・影・縁
4. **カメラが動くか** — 寄る・流れる・揺れる。止まった絵になっていないか
5. **1枚に1つ事件が起きるか** — 灯る / 切れる / 止まる / 落ちる / 引かれる。何も起きない絵は失敗
6. **人が反応するか** — 影でよい。人の気配があると画が生きる (図は免除)

加えて:

- `uid` は他の関数と重複していないか
- `WP` 以外の色を書いていないか
- `div` を書いていないか
- `f` を使わない定数だけの絵になっていないか

# 1枚だけ見る (#13 = 担当Bの3枚目 → 2*60 + 見たいフレーム)

## 8. 前任者はこれで失敗しました

実際に作者から出た指摘。同じことをしない。

- **素のクリーム地に方眼を敷いて、その上に図形を置いた** → 「背景が素肌」。全編0枚が条件
- **小さい物を画面の真ん中にポツンと置いた** → いちばん多い失敗。主役は540px以上
- **絵が止まっていた** → 「出しっぱなしの静止画」。1枚に1つ事件を起こす
- **汎用の図形キットを作って使い回した** → 制作ガイド第13条違反。1枚にしか出ない物はその場で描く
- **暗い背景に黒い影を置いて、輪郭が溶けた** → リムライトで必ず分離する
- **細い線をたくさん引いて髪や質感を表した** → 「キズに見える」。**面**で作る
- **`uid` を使い回して `defs` の id がぶつかり、他の人の絵が黒く潰れた**
- **勝手に新しい色を足した** → パレットが崩れて全編の統一感が壊れる
- **他の担当のファイルや world.tsx を「ついでに」直した** → 並走している全員の作業が壊れる
