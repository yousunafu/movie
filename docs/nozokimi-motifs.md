## 色の設計 (この回の核)

**全編 黒モード** (黒 `#0A0A0C`+白+赤 `#D63B3B`)。ただしこの回は「色そのもの」が主役なので、**絵の具パレット PC を常設**する:

| 名前 | 色 | 用途 |
|---|---|---|
| PC.yellow | `#E2C44A` | スタートの黄 (公開してよい色) |
| PC.red | `#D6483B` | あなたのひみつの赤 (suuri強調赤とほぼ同じ。絵の具シーンでは赤絵の具が強調役を兼ね、別の赤強調は置かない=1画面1赤) |
| PC.blue | `#4A7FC9` | お店のひみつの青 |
| PC.orange | `#DE8A3C` | 黄+赤 (あなたが送る色) |
| PC.green | `#5FA86A` | 黄+青 (お店が送る色) |
| PC.brown | `#8A5A3B` | ひみつの茶色 (完成した鍵。完成時だけ白いグロー) |

**色の弧 (演出意図)**: つかみ〜第1章=ほぼモノクロ+赤 (暗号の世界は色がない) → 行45「絵の具なら。」で**初めて絵の具のカラーが画面に差す** → 第2章=絵の具フルカラー → 第3章=絵の具が数字に変身して**モノクロ+赤へ戻る** (本物の暗号は数字、という世界の切り替え) → 第4章=鍵マークから絵の具カラーが再び漏れ出す (回収)。和紙モードは使わない (色変換フィルタが絵の具の色を狂わせるため)。

- 混ざり色の整合: オレンジ=黄+赤、緑=黄+青、茶=黄+赤+青 に**見えること** (彩度ひかえめで上品に)。最初の1〜2モチーフ (exchange と no_unmix) を先に静止画確認してから量産 (§9-4 原則5)
- 塗りは必ず塗りつぶし (fill="none"禁止)。絵の具チューブ・チップは面で塗る

## マスコット

- **のぞき見くん (nozoki)**: ほっかむり+大きな丸い目+双眼鏡の憎めない棒人間。怖くしない (小学生が笑えるコソ泥)。再登場ごとに姿が育つ:
  v1 初登場 (双眼鏡でのぞく) → v2 聞き耳 (黄色宣言) → v3 メモ帳にガリガリ → v4 集めた色を並べて腕組み → v5 ガックリ (惜しい) → v6 ひらめき電球 → v7 総当たりで絵の具まみれ → v8 宇宙規模の空ぶり (複数人で疲れ果てる)
- **あなた (you)**: 左側の棒人間。胸に四角い**ポケット** (ひみつの色チップが入る。ポケットは常に体の同じ位置=連続性)
- **お店 (shop)**: 右側、エプロン+店の看板

## 持続レイアウト「交換ボード (exchange)」

第2章の本体。**あなた (左)・バケツリレーのレーン (中央)・お店 (右)・のぞき見くん (中央下で見上げる)** の配置を固定し、同じボードが育っていく (グラフ連続性ルール。SUURI_GROW_MOTIFS 登録):
v1 黄色宣言 → v2 赤をポケットへ → v3 オレンジがレーンを渡る → v4 緑が渡る → v5 あなたの最終混合 → v6 お店の最終混合 → v7 両手元に茶色完成 (グロー) → v8 総集編 (赤と青の軌跡=ポケットから出ていない、を光らせる)
