## #21 山「今のイランに、毒杯を飲むと言える『声』はあるのか。」

現状は「手前で待っている客席の頭と肩」。**頭と肩だけの黒い列をやめる。**
**構図** 空の演壇を**客席側から肩越しに**。手前の客の**顔が見える角度**まで振る。
**出す物** 木の演台とマイク2本 (1988年式の丸い網のマイクではなく現代の細いもの) /
空のパイプ椅子の列 / ペルシア語の垂れ幕 / 天井の蛍光灯 / 床のタイル /
壁のイラン国旗 / 記者の三脚とカメラ
**人 (老若男女)** 黒いチャードルの老女 / マグナエ (かぶりもの一体型) の若い女性 /
開襟シャツの中年男 / 携帯を構える20代の男。全員が**空の演台を見ている**。
**事件** マイクの前に**誰も立たない**まま、赤いランプだけが点く。

## #22 山「それとも始まるのは、主君を討たれた家臣たちの、忠臣蔵なのか。」(全景可)

現状は「笠をかぶった影と提灯」。**影をやめて、装束を描く。**
**構図** 雪の夜。吉良邸の門の前を**真横から**。カメラは低く、積雪の高さ。
**出す物** 武家屋敷の**冠木門/長屋門** (瓦屋根・黒い下見板か海鼠壁・門の両脇に格子窓) /
**かけや (大槌)** ← 裏門はこれで打ち破った。この音が後世「山鹿流陣太鼓」に化けた /
**竹梯子** / かすがい (近隣の門を外から打ち付けて人を出さないため) / 槍 / 弓 /
**柄付きの手提げ提灯** (和紙に墨の家紋・火袋の骨・中の火が黄色く透ける `#E8C679`) /
息の白さ / 雪の踏み跡 / 刀の鞘と下緒

**★装束の考証**
史実は「火事装束を真似た**黒系の小袖・股引で不統一**、袖に**白い晒を縫い付けて味方の
目印**」。芝居の揃いの装束は後世の演出で、模様は**段だらではなく山形 (鋸歯)**。
ここは**史実寄りの黒＋白い晒の目印**で描く。そのほうが「揃っていない集団」になって、
前回の失敗 (全員同じ記号) の逆を行ける。鎖帷子・鉄輪入りの火事頭巾・右肩の名札・
襷・黒の脚絆・わらじ。黒小袖は `#1A1A1A`、雪は `#F2F5F8`。
**禁止** 山鹿流陣太鼓 (一次記録に無い) / 揃いの山形文様 / 刀を差した町人。

**雪** 記録上は**前日までに積もっていた**状態で、降っていたかは不確か。
**降らせない。積もらせる。** 屋根からの垂れ・軒の雪庇・足跡の深さを描く。
白い丸の粒を散らすだけで済ませない。

**人** 全員の**顔を描く** (頬被りの下から目と口が見える)。年齢を散らす ──
白髪混じりの年長者 / 20代の若者 / 緊張で口を結んだ中年。
**事件** 先頭の一人が**提灯の火をふっと消す**。
