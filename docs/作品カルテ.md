# 作品カルテ (2段目ルール: 個別作品の修正事例と作者の好み)

1段目 = `docs/制作ガイド.md` §9-4 の全作風共通原則。このファイルはその**2段目**で、個別作品ごとに「どんな指摘を受けて → どう直して → そこから読み取れる作者の好みは何か」をタイトルごとに収納する。

## 使い方 (運用ルール)

- **新作を作る前に**: ガイド§9-4 を前提に、ここを**全作品ぶんザッと読む**。繰り返し出てくる指摘 = 作者が特に気にするポイントなので、新作では最初から織り込む
- **納品したら**: その作品で受けた指摘・直しの概要と「読み取れた好み」を、下の型で**必ず追記**する
- 書き方の型: タイトル見出し → 「指摘と直し」(箇条書き) → 「読み取れた好み」(1〜3行)。コードの詳細はガイド側に書き、ここは**概要とニュアンス**を残す場所

## 望月の歌・道長回 (suuri / 2026-10)

### 指摘と直し
- 「同じ絵の繰り返しで萎えた」→ 登場回数を variant として絵に渡し、2回目以降は姿が変わる仕組みに (絵が育つ。§9-4 原則1の元)
- 「絵が文と合っていない」→ 台本を1文ずつ照合して専用絵を追加。文中の数字・時代は絵の中に反映 (§9-4 原則2の元)
- ラベルが2行字幕に隠れた (descend_tree / neighbor_merge) → 2行字幕チェックの元

### 読み取れた好み
- 使い回しの絵にとても敏感。「また同じ絵だ」と思わせた時点で負け
- 絵は文の言葉そのもの (「子が3人」なら3人描く) を求める。雰囲気絵で流すのを嫌う

## 寿司37%ルール回 (suuri・和紙モード / 2026-10)

### 指摘と直し
- 「考える人」の体が字幕に刺さった → 字幕セーフゾーン y>840 を数値で確定 (§9-3)
- ラベルが右に見切れた (「旅先のレストラン」) → ラベルは原則絵の真下に中央揃え (§9-3)
- オチ (「…ガリでした。」) が先に見えてしまう → ナレーションがオチを読む瞬間まで絵も字幕も隠す (splitPunchline + tailReveal。§9-4 原則の元ではなく §9-3 項目9の元)
- 前向きな文に後ろ向きな絵が付いた → 文の内容からバリアントを選び直す (§9-3 項目7の元)
- 「数学者たち」なのに絵が1人 → 複数人版を用意 (§9-3 項目8の元)
- 和紙モードの色変換で後から色修正が多発 → 最初の1〜2モチーフで変換後の見え方を確認してから量産 (§9-4 原則5の元)

### 読み取れた好み
- オチ・ネタバレの管理に厳しい。「言う前に見せる」のは厳禁
- 絵と文の意味のチグハグ (気分のミスマッチ含む) にすぐ気づく
- 尺や同期のズレより先に、まず「意味が合っているか」を見る

## キラキラ画面回 (suuri / 2026-10)

### 指摘と直し
- 「AIで作ると同じ人物のシーンを多用してしまう」→ 人物リアクションのフォールバックに頼らず、専用イラスト9種 (unmask / preview_ch12 / preview_ch34 / photo_flood / camera_roll_sleep / troubles_rain / vanish_posts / pitfall_people / count_only_hand) を新規追加 (§9-4 原則9の元)
- 「色がついていた方がわかりやすいところにまったくなかった」→ 「画面の中のキラキラ=カラフル、現実=モノクロ+赤」の対比ルール + 差し色パレット `KC` を常設 (§9-4 原則6・11の元)
- 落とし穴シーンが浅くて動きが単調 → 「次々と人が落ちていく深い穴、テンポ良く」の指示で、深さ380pxの穴に5人が0.75秒間隔で落ちる演出に全面改修
- 章予告の章ラベルが赤2つ並び → 赤は1画面1要素ルールで黒 (ink) に
- ガチャカプセルの配色が場所によってバラバラ → 同じ小物は全シーン同配色 (上=黄・下=ピンク) に統一。スマホ内ミニチュア・テレビ画面の中も対象 (§9-4 原則6)
- 「濃縮、一段目。」などの掛け声が前の文に吸収された → KEEP_ALONE で独立シーン化し絵の見せ場と同期 (§9-4 原則7の元)
- 決めゼリフは字幕を消して本文を中央に大きくフェードイン (§9-4 原則8の元)
- 作戦会議シーンで答えが先に見えた → showPlan の出現タイミングを遅らせてネタバレ防止

### 読み取れた好み
- 動きのある見せ場は**テンポ重視**。「ゆっくり1回」より「次々と」が好み (0.75秒間隔くらいの連打感)
- 人物絵の連続を嫌う。内容のある文には必ずその文専用の絵
- 色は「あると分かりやすい所」に先回りで置いてほしい。後出しの色直しにがっかりする
- 深さ・規模の表現は大げさなくらいでちょうどいい (浅い穴は「穴」に見えない)

## 運命の人は東京に40人しかいない回 (恋愛版ドレイク方程式 / suuri / 2026-10)

### 指摘と直し
- v1への一括フィードバック66項目で全面改修 (v2)。導入〜第4章+結論まで全章に指摘が入った
- 導入は恋愛の空気 (ピンク PINK パレット) を強め、第1章から和紙調へ切り替える構成に。新規専用イラスト18種を追加 (love_iihito / drake_galaxy / fermi_name / fermi_four / backus_writing / countdown系 / pitfall / commute_10 / fraction系 ほか)
- 「40人」はタイトルで既出なので章予告に出してもネタバレに当たらない (タイトル既出の数字はOK) という判断基準を確認
- グラフをまたぐシーンは軸・スケールを揃えて「同じグラフが育つ」ように見せる (連続性ルール)
- 式の要素名は色分けして毎回同じ色で登場させる (条件=色、の対応を固定)
- 静止画検品で字幕重なり5件 (ラベル・赤キャプション・結論テキストが y>840 に入っていた)。下部テキストは y≤810〜830 までに収めるルールを再確認。2行字幕の上端は約y=855なのでさらに余裕が要る
- 新モチーフは SUURI_GROW_MOTIFS に登録して連続散らしの差し替え事故を防止 (実運用はAI絵づけが毎回失敗し機械割り当てフォールバックで動いている、という生成経路も今回確定)

### 読み取れた好み
- テーマに合わせた空気づくり (恋愛=ピンク導入) を喜ぶ。作風固定ではなく題材に寄せる柔軟さを求める
- 「同じ図が別物に見える」のを嫌う。グラフ・式は前のシーンと連続して育ってほしい
- 検品は静止画→実映像の2段構え+再生成前のユーザー確認ゲートが定着。勝手に再生成しないこと
